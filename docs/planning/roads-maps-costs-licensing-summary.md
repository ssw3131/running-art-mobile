# 도로 공급과 지도 비용 및 라이선스 핵심 정리

정리일: 2026-10-02 (Asia/Seoul)

모바일 앱의 속도 변화, 전국 도로 공급, 갱신과 비용, 지도 교체 및 OSM 이용 조건을 정리한다. **배경 지도 표시, 도로 자료 공급, 휴대폰 코스 계산은 서로 다른 역할**이다. 아래 수치와 확인 상태는 정리일 기준이며 최신 진행 상황은 [현재 상태](../handoff/status.md)를 따른다.

## 속도가 달라진 이유

- 초기 AI Studio·Codex 웹이 약 20~30초였다는 것은 사용자 경험이다. 동일 입력·기기에서 모바일과 직접 비교한 확정 측정값은 없다. 기존 도로 API도 정상 응답 시 약 4~6초였으므로 사전 전국 가공 없이도 빠르게 동작할 수 있었다. 다만 조회만 95초 후 실패한 사례도 있었다. [이전 조회 검증](../quality/road-search-results-verification.md)
- 초기 모바일의 약 1분 대기에는 **개발 모드의 계산 부담**이 크게 작용했다. 같은 휴대폰·계산 코드·서울 하트 5km에서 개발 모드 중앙값 58.44초, 배포용 APK 24.83초를 확인했다. Cloudflare 전환 전의 결과이며, 개발 모드와 배포용 빌드 전체의 차이를 측정한 것이다. [계산 성능 기록](../development/route-engine-performance.md)
- R2 전환은 **외부 서버의 실시간 도로 검색을 미리 가공한 파일 다운로드로 바꾼 개선**이다. 코스 계산은 계속 휴대폰에서 한다. 현재 개발용 `r2.dev`는 Cloudflare CDN 캐시를 제공하지 않으며 운영 도메인/CDN 연결은 후속이다. [Cloudflare 안내](https://developers.cloudflare.com/r2/buckets/public-buckets/)
- 판교 하트 3km의 실제 휴대폰 관측은 첫 수신 **11.71초**(도로 준비 3.10초 + 계산 8.61초), 재시작 후 오프라인 **9.65초**(1.05초 + 8.60초)였다. 위 서울 5km나 전국판 성능과 직접 비교하지 않는다. [판교 검증](../quality/pangyo-roads-verification.md)

**오프라인 저장은 R2 없이도 가능하다.** 기존 외부 API 응답을 휴대폰에 영구 저장해도 받은 지역을 재사용할 수 있다. 영구 캐시의 효과와 전국 자료를 직접 공급하는 효과는 별개이며, 이번 전국 작업의 추가 가치는 처음 조회하는 지역의 공급·버전·갱신·복구를 직접 관리하는 데 있다.

## 전국 도로의 동작과 용량

한국 OSM 원본 → 보행 가능한 도로 추출 → 지역별 분할·압축·검증 → R2 배포 → 앱에서 필요한 파일 수신·저장 → 휴대폰 내부 코스 계산 순서다.

현재 **9월 30일 원본 기준 도로 파일 26,717개**를 R2에 배포했다. 앱은 계산 버튼을 누른 시점의 **지도 중심 주변 2km**에 필요한 파일만 받는다. 경계의 도로 연결을 보존하고 받은 파일을 검사한 뒤 사용한다. 전국 대표·경계 23개 사례의 PC·실제 R2 검증은 완료했으며, 2026-10-02 19:26:52 KST에 휴대폰도 전국 공급을 포함한 최신 통합 APK로 업데이트했다. 앱 실행·기능 테스트는 수행하지 않아 전국판의 실제 휴대폰 검증은 후속이다. [휴대폰 설치 확인](../quality/phone-install-20261002.json). [전국 공급 안내](../development/national-roads.md)

| 용량 범위 | 용량 |
| --- | ---: |
| 최신 전국 도로 파일 한 버전의 gzip 합계 | 약 337MB |
| 위 파일의 압축 해제 후 합계 | 약 1.69GB |
| 이전 버전까지 보관한 전국 파일·목록의 합계 | 약 389MB |

MB·GB는 십진 단위다. 보관 합계는 중복 파일을 공유한 값이며 작은 출처 안내·버킷 메타데이터·기존 표본 경로는 제외한다. 배경 지도 이미지 용량도 포함하지 않는다. [가공 수치](../quality/national-roads-260930-packaging-report.json)·[보관 수치](../quality/national-roads-storage-plan.json)

**다운로드와 기기 저장은 압축 상태, 계산은 필요한 파일만 메모리에서 해제**하는 방식이다. gzip은 손실 없는 압축이며 전국 자료를 한 번에 풀지 않는다. 저장된 범위는 오프라인 계산이 가능하고, 처음 조회하는 지역은 다운로드가 필요하다. 배경 지도의 오프라인 표시는 별도다.

## 갱신 시점

- **서버 자료:** 초기 운영 기준은 주 1회 수동 갱신이다. 최신 원본 확보 → 가공 → 검증 → 업로드를 마친 뒤 최신 버전을 전환한다. 실패하면 기존 정상 버전을 유지한다. 나중에 스케줄러로 자동화할 수 있지만 현재 예약 작업은 설정하지 않았다.
- **휴대폰 자료:** 마지막 확인 후 기본 7일이 지나 해당 지역을 다시 조회하면 최신 목록을 확인한다. 사용자가 ‘새 버전 확인’으로 즉시 갱신할 수도 있다. 서버 배포와 모든 휴대폰의 갱신 시점은 같지 않다.

가공·배포·검증·이전 버전 복구 도구는 준비돼 있다. 자동 실행 환경과 일정은 후속 결정이며 이번 대화에서 구축을 실행한 것은 아니다. [갱신 운영](../development/national-roads.md)

## R2 비용과 계정 확인 상태

2026-10-02 확인한 **R2 Standard** 공식 요금이다. 저장량과 작업 횟수에 과금하며, R2에서 인터넷으로 보내는 전송량 자체는 무료다. [공식 요금표](https://developers.cloudflare.com/r2/pricing/)

| 항목 | 매월 무료 제공량 | 초과 요율 |
| --- | --- | --- |
| 저장 | 10GB-month | 1GB-month당 $0.015 |
| 읽기 등 Class B | 1천만 요청 | 100만 요청당 $0.36 |
| 업로드·목록 조회 등 Class A | 100만 요청 | 100만 요청당 $4.50 |

10GB-month는 10GB를 한 달 내내 보관하는 사용량이다. 청구 사용량은 공식 과금 단위로 올림 처리된다. 도로 보관량 약 0.39GB 자체는 무료 범위보다 작지만 실제 청구는 전체 사용량을 확인해야 한다. 코스 한 번에 파일 여러 개를 받으면 읽기 요청도 여러 건이며, 기기 캐시는 반복 요청을 줄인다.

**R2 결제 설정 완료는 사용자 확인 내용**이다. MapTiler는 앱의 클라이언트 키 연결과 지도 표시까지 확인했고, 현재 요금제·결제 수단·사용량은 미확인이다. 사용자는 MapTiler 계정 확인을 나중으로 미뤘다. MapTiler 지도, 다른 서버 서비스, 도메인 등의 비용은 R2와 별개다.

## 배경 지도 교체

현재는 **MapTiler가 배경 지도 자료를 공급하고 MapLibre가 화면에 표시**한다. R2의 OSM 도로 파일은 계산용이며, 우리가 배경 지도 타일까지 직접 만들어 제공하는 상태는 아니다.

Google 지도나 카카오맵으로 교체하는 것은 기술적으로 가능하다. R2 도로 자료·계산 엔진·저장 코스·GPX는 유지하고, 새 지도 SDK에 경로선·현재 위치·지도 이동·시뮬레이션 표시를 연결해야 한다. 두 SDK 모두 경로선 표시 기능을 제공한다. 키만 바꾸는 작업은 아니며, 도로선 정합성과 각 공급자의 이용 조건을 확인해야 한다. 교체는 선택 가능성만 논의했으며 결정·구현하지 않았다. [Google 지도](https://developers.google.com/maps/documentation/android-sdk/polygon-tutorial)·[카카오맵](https://apis.map.kakao.com/android_v2/docs/api-guide/routeline/)

## OSM 라이선스

전국 도로 원본은 **OpenStreetMap의 ODbL 1.0**이다. 조건을 준수하면 별도 라이선스 사용료 없이 상업적으로 이용할 수 있다. **상업 이용 시 출처 표기만 하면 된다고 이해하면 안 된다.** [OSM 안내](https://www.openstreetmap.org/copyright)·[ODbL 원문](https://opendatacommons.org/licenses/odbl/1-0/)

- 앱과 배포 자료에 OSM 출처 및 라이선스를 안내해야 한다. 계산 엔진을 사용하는 앱도 OSM 출처 표시 대상이다. 배경 지도를 다른 공급자로 바꿔도 계산에 쓰는 OSM의 표시 의무는 남는다. [공식 표시 지침](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines)
- 우리는 원본에서 보행 도로를 선별해 지역 파일로 재구성하므로 실제로 가공하고 있다. 단순 압축 여부와 별개로, 상당한 원본을 추출해 새 데이터베이스로 만드는 것도 ODbL의 대상이다. 공개 이용·배포하는 파생 도로 데이터에는 동일 조건 공유가 적용되며, 이용자에게 데이터 전체 또는 라이선스가 허용하는 변경 내역·재현 방법 등을 기계 판독 가능한 형태로 제공해야 한다. 인터넷 제공은 무료여야 한다. [ODbL 4.4 및 4.6](https://opendatacommons.org/licenses/odbl/1-0/)
- 이 데이터 라이선스가 앱 전체 소스 코드나 독립적인 회원 정보를 공개하라는 뜻은 아니다. 현재 계산 화면·OSM 저장 코스 상세와 배포 자료에는 출처·라이선스 안내가 있다. 전체 준수 여부의 최종 점검은 아직 완료하지 않았다.

현재 남은 관련 항목은 전국판의 휴대폰 검증, 운영 도메인/CDN, MapTiler 계정 확인, 갱신 자동화의 실행 환경 결정, 출시 전 라이선스 안내와 데이터 제공 방식 점검이다. 이 문서는 대화 요약이며 해당 작업을 새로 실행하거나 완료한 기록은 아니다.
