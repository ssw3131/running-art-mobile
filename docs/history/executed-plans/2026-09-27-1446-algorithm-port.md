## 실행 전 계획 원문

## 다음 개발 목표 — v0.2 모바일 코스 계산 검증

설정일: 2026-09-27. 상태: **목표·완료 기준 설정 완료, 구현 미착수**.

**Codex v0.2 알고리즘을 모바일 내부 TypeScript 모듈로 이식하고, 고정 도로 데이터·도형·목표 거리로 원본과 일치하는 코스를 계산해 Android 앱 지도에서 확인한다.**

현재 지도·전경 위치·SQLite 저장 기반의 에뮬레이터 검증을 바탕으로, 다음 핵심 기능인 경로 계산을 검증하는 목표입니다. 사용자 표현의 v2.0은 저장소의 v0.2입니다.

### 작업 범위와 순서

1. **원본 비교 기준 확보:** 독립 소스 묶음과 v0.2 보관본의 출처를 대조하고, 고정 그래프·시작점·도형·목표 거리·탐색 옵션과 원본 결과를 보존합니다. 합성 그래프와 출처가 확인된 고정 OSM 표본을 구분합니다.
2. **계산 모듈 이식:** `src/modules/route-engine/`에 계산 코드를 이식합니다. 도형·점수·탐색 조건과 OSM 노드 ID·연결성을 보존하고 지도·네트워크·저장·화면과 분리합니다.
3. **앱 테스트 화면 연결:** 고정 데이터에서 도형·목표 거리를 선택하고 계산을 실행합니다. 추천 코스·거리·점수를 지도와 목록에 표시하며, 진행률·취소·오류·유효 후보 없음 상태를 확인할 수 있게 합니다. 화면은 핵심 기능 검증용입니다.
4. **회귀·Android 검증:** 원본 결과와 비교하고 Android에서 계산 시간·메모리·화면 반응·취소를 측정합니다. 실행 방식은 측정 결과에 맞춰 결정합니다.

### 완료 조건과 증거

- [ ] 원본 파일 출처와 고정 입력·기준 결과가 보존되어 비교를 재현할 수 있다.
- [ ] 같은 입력에서 후보 경로·순위·반올림 전 점수·총거리가 v0.2 원본과 일치한다. 수치 비교에 허용 오차가 필요하면 비교 기준에 사유와 값을 먼저 기록한다.
- [ ] 도로 연결·출발점 복귀·거리·반복 도로·후보 중복·크기 범위·v0.1 유효 후보 보존 조건이 [이식 기준](../architecture/prototype-migration.md)에 맞는다. 단절 그래프와 후보 없음도 검증한다.
- [ ] Android 앱에서 입력 → 계산 → 결과 지도 표시를 확인하고, 계산 중 진행률·취소·재실행이 동작한다. 취소한 계산의 늦은 결과가 새 결과를 덮지 않는다.
- [ ] 타입·린트·관련 자동 테스트·Android 빌드가 통과하며 기존 지도·위치·저장 기능의 회귀를 확인한다.
- [ ] 데이터 크기·기기·반복 측정 조건과 계산 시간·메모리·UI 응답성 결과를 남긴다. 실제 Android 휴대폰에서도 확인하고, 에뮬레이터 결과와 구분한다. 휴대폰을 확인하지 못하면 해당 항목은 미완료로 남긴다.
- [ ] 사용법·검증 기록·현재 상태·실제 구현 실행 기록을 갱신한다.

### 후속 범위

주변 OSM 지역 파일 다운로드·캐시는 4단계, 실제 코스 저장·GPS 러닝 추적·러닝 기록·시뮬레이션·GPX는 5단계에서 진행합니다. 최종 서비스 기획·디자인은 이후 전달받아 반영합니다. CI/CD는 기존 실행 보류 상태를 유지합니다. 이번 목표 설정은 알고리즘 구현을 시작한 실행 이력으로 기록하지 않습니다.

## 실행 시작 시 세부 계획

1. v0.2 원본·명세·독립 테스트를 모바일 테스트 참조 자료로 보존하고 해시를 대조한다. 합성 격자와 출처가 확인된 서울 OSM 고정 표본의 원본 결과를 확보한다.
2. TypeScript 계산 모듈과 타입을 구현한다. 탐색 순서·계산 의미를 보존하면서 중간에 실행을 양보하는 방식으로 진행률·취소를 연결하고 결과 일치를 검증한다.
3. 고정 데이터·도형·목표 거리를 고르는 테스트 화면, 추천 목록·지도 표시, 취소·재실행·화면 이탈 처리를 연결한다.
4. 원본 회귀·연결성·제약·실패·취소 테스트, 타입·린트·Android 번들·빌드를 확인한다. 에뮬레이터에서 결과와 응답성을 확인하고 계산 시간·메모리를 기록한다.
5. 실제 휴대폰은 연결 상태를 확인해 별도로 검증한다. 현재 에뮬레이터만 연결되어 있어 사용자에게 휴대폰 연결 가능 여부를 요청했다. 미검증을 완료로 바꾸지 않는다.
6. 사용법·구현 구조·검증 기록·현재 상태·실행 기록 목록을 실제 결과로 갱신한다.

## 실행 결과

- v0.2 독립 묶음 9개 파일의 해시를 확인해 테스트 참조 원본으로 보존했다. 원본 엔진·Worker를 v0.2 보관본과 대조했다. 원본 프로토타입은 수정하지 않았다.
- TypeScript 엔진·입력 검증·협력 실행기·작업 교체 보호·GeoJSON 변환·기기 비교를 구현했다. OSM 노드 ID·연결성과 원본 수식·탐색 순서를 보존하며 generator 체크포인트에서 제어를 양보한다.
- 합성 격자와 서울 OSM 4,810개 way 표본, 출처·라이선스·추출 스크립트 및 5개 기준 결과를 보존했다. 앱은 형제 프로젝트나 테스트 원본을 런타임 import하지 않는다.
- 홈에 코스 계산 테스트를 연결했다. 도로·9개 도형·목표 거리, 실제 진행 단계, 후보 지도·거리·점수, 취소·재실행·백그라운드·화면 이탈을 처리한다.
- 개발용 타이머 대기 비용을 확인해 React Native 낮은 우선순위 스케줄러 어댑터를 적용했다. 원본 평가 횟수·수식은 줄이지 않았다.
- 사용법·구현 구조·README·로드맵·현재 상태·검증 기록과 실행 기록 목록을 갱신했다. CI/CD는 보류를 유지했다.

## 검증

- Node 고정 사례 5개에서 모든 결과 필드가 원본과 정확히 일치했다. 알고리즘 최종 25개와 기존 위치·지도·SQLite 29개 검사 통과. 타입·린트, Expo 진단 21/21, 최종 Android JS 번들, APK 빌드·v2 서명 검증 통과.

- 기존 지도·지명·모의 GPS 위치 점과 카메라 이동, SQLite 기존 메모 2개 및 `sqlite-pers-updated` 복원을 확인했다. 기존 저장 데이터는 수정·삭제하지 않았다.
- 최종 실행기의 합성 계산 150.18초·서울 277.44초, 최대 타이머 지연 각각 365.34ms·440.54ms. 서울 계산 전/후 앱 전체 PSS 631,061/648,257 KiB. 기기·측정 조건·메모리 해석·환경 복구·증거 경로는 [검증 기록](../../quality/route-engine-verification.md)에 남겼다.
- 기존 사용자 변경을 보존했고 커밋·푸시·배포는 수행하지 않았다.
- 문서 38개·로컬 링크 149개 검사 통과. 보존한 원문 링크는 명시한 원래 로드맵 기준으로 해석한다. `git diff --check` 통과, 원본 프로토타입 작업 트리 변경 없음.
