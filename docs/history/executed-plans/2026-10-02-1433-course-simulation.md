## 실행 전 계획

저장된 코스를 인터넷·GPS 없이 재생하는 코스 시뮬레이션을 구현한다. 저장 코스 상세에서 시작하며 거리 기준 이동 표시, 재생·일시정지·처음부터 다시 시작, 재생 중 속도 변경, 이동/전체 거리·진행률, 도착 자동 종료를 제공한다. 화면 이탈·앱 백그라운드 전환 시 일시정지한다. 기본 경로 화면에서 저장 좌표만 사용하며 도로 조회·재계산·DB 변경 없이 동작한다.

전국 도로 작업과 병렬 진행한다. 시뮬레이션 전용 모듈·화면·검사·문서를 중심으로 변경하며 도로 가공·R2·공급·캐시 변경은 보존한다. 공용 상태·이력 목록은 종료 시 최신 내용을 읽어 부분 반영한다. 자동 검사·타입·린트·가능한 Android 실행을 확인하고 실제 휴대폰 검증 여부를 구분한다.

## 실행 결과

`modules/course-simulation/player.ts`의 거리 기준 위치·시간 기반 재생 제어, `features/courses/SimulationPanel.tsx`의 오프라인 화면·제어·AppState/포커스 일시정지를 구현했다. 저장 코스 상세에서 패널을 열고, 기존 지도에 `simulationPosition`만 추가했다. 시작 시 온라인 배경 지도를 끄며 기존 GPS 위치·카메라 처리·코스 DB 형식을 유지한다. 6분/km 기준 1·5·10·30배를 제공한다. 재시작은 선택한 속도를 유지하고 정지 상태로 돌아간다.

전국 도로 작업의 소스·도로 공급·가공·캐시 변경은 수정하거나 되돌리지 않았다. 공용 문서는 종료 시 최신 내용을 다시 읽고 시뮬레이션 부분만 반영한다. 휴대폰 설치·R2 배포·커밋은 이번 작업에서 수행하지 않는다.
