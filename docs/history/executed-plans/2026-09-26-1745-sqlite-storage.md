### 실행 시작 시 작성한 구현 계획

1. SDK 57에 맞는 expo-sqlite를 설치하고 앱 내부 DB 초기화·버전별 트랜잭션 마이그레이션을 구현한다. 미래 버전 DB와 초기화 실패는 데이터를 지우지 않고 오류로 처리한다.
2. 테스트 메모 전용 테이블과 저장·조회·수정·삭제 API를 만든다. 사용자 입력은 SQL 바인딩으로 처리한다. 실제 코스·러닝 저장 스키마는 확정하지 않는다.
3. 홈에서 진입하는 저장소 테스트 화면을 추가한다. 초기화·작업 중 상태, 빈 목록, 입력 검증, 실패·재시도, 삭제 확인을 제공한다. 지도 기능은 DB 초기화에 종속시키지 않는다.
4. Node 내장 SQLite로 실제 SQL·마이그레이션·롤백·CRUD·파일 재열기를 검증하고 기존 위치 테스트·타입·린트·Expo 진단·Android 번들·APK 빌드를 확인한다.
5. 연결 가능한 Android에서 테스트 화면 CRUD, 프로세스 강제 종료·재실행 후 데이터 유지, 기존 지도·위치 화면을 확인한다. 실기기와 에뮬레이터 검증은 구분한다.
6. 사용법·검증 증거·아키텍처·로드맵·인수인계와 이 실행 기록을 갱신한다.
