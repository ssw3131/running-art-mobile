## 검증

- 2026-09-27 Windows 로컬 파일 기준으로 `Get-FileHash`와 Node `fs`·`crypto`를 사용했다. v0.2 보관본과 export 엔진·Worker는 바이트 단위로 동일하다.
- export의 `SHA256SUMS.txt` 9개 항목은 CRLF → LF 정규화 후 모두 일치했다. 이식 문서에 적은 핵심 파일 6개 해시도 재검증했다. 줄바꿈 차이를 실제 소스 변경과 구분하도록 문서화했다.
- 변경·추가된 Markdown의 로컬 링크 93개와 이식 소스 경로가 존재함을 확인했다. 현재 계획·지침에서 v0.3은 제외 대상 설명에만 남아 있다. 과거 실행 기록은 당시 결정을 유지한다.
- `git diff --check` 통과. 원본 `running-art` 저장소의 작업 트리는 변경 없음.
- `skill-creator/scripts/quick_validate.py` 실행은 번들 Python에 PyYAML이 없어 완료하지 못했다. 대체로 기존 프로젝트의 Node `yaml` 파서로 스킬 frontmatter·허용 필드·이름·설명·미완성 표시와 UI YAML·자동 선택 정책을 확인해 통과했다. 검증 도구 설치나 의존성 변경은 하지 않았다.
- 문서·지침만 변경했으므로 앱 타입·린트·빌드·알고리즘 동작 테스트는 실행하지 않았다. 모바일 이식 결과 또는 실기기 성능을 검증한 것으로 보고하지 않는다.
