## 실행 전 계획

최신 main `6a72e79`를 기준으로 코스 추천, 탐색 확장 안내, 실시간 러닝의 합류 경로 계산을 함께 개선한다. 유사도 계산식은 유지하며, 처음 길을 찾는 시간과 기존 계산을 다시 사용하는 시간을 구분해 검증한다.

### 1. 확정된 사용자 경험

- 입력한 거리는 **도형 코스 자체의 거리**로 유지한다. 결과에는 `코스 2.0km · 출발지에서 합류까지 300m`처럼 접근 거리를 별도로 표시한다.
- 기본 접근 거리 단계는 **300m → 500m → 1km**다. 초기 버전에서는 목표 거리와 관계없이 같은 단계를 적용한다.
- 가까운 대표 후보와 동일 탐색에서 찾은 연결 가능한 최고점 후보를 비교한다. 원시 유사도 점수 차이가 **5점 이하이면 가까운 후보를 기본 추천**한다.
- 차이가 **5점을 넘으면 ‘가까운 코스’와 ‘모양이 더 닮은 코스’를 함께 표시**하고 사용자가 선택하게 한다. 점수 계산에 접근 거리 감점을 섞지 않는다.
- 합류 거리가 **1km를 넘는 후보는 별도 대안**으로 표시하며 자동 선택하지 않는다.
- 코스 추천의 기준은 **사용자가 선택한 출발지**, 실제 러닝 안내의 기준은 **현재 GPS 위치**다. 두 거리를 혼동하지 않도록 구분한다.

### 2. 코스 탐색과 확장 안내

**코스 전체를 가두는 탐색 반경과 코스까지의 접근 거리를 분리한다.**

- 기존 목표 거리별 도로 조회 범위와 도형 크기·회전·유사도 계산을 유지한다.
- 출발지 주변 도로에 도형의 윤곽점을 맞춘 배치를 추가해 가까운 후보를 확보한다. 기존 상위 5개를 거리순으로 재정렬하는 방식으로 끝내지 않는다.
- 300m·500m·1km 단계마다 최대 40개의 추가 배치 평가 예산을 확보한다. 가까운 단계에서 유효 후보를 확보하면 다음 근거리 단계는 생략하고, 기존 광역 탐색으로 모양 품질을 비교한다. 중복 배치는 다시 평가하지 않는다.
- 하나의 도로망에서 출발지의 도보 거리 정보를 계산해 여러 후보가 공유한다. 직선거리는 사전 선별에만 사용하고 최종 접근 거리는 실제 연결 도로로 확인한다.
- 최종 최대 5개 후보에는 가까운 대표와 최고점 대표를 우선 확보하고 나머지를 유사도순으로 채운다. 기존 경로 중복·거리·반복 구간 제한을 유지한다.
- 출발지의 보행 도로 연결이 불명확하면 접근 거리를 ‘확인 불가’로 표시하고 가까운 추천으로 확정하지 않는다. 임의의 직선 연결은 만들지 않는다.

안내는 실제 탐색 상태에 연결한다.

- `출발지에서 합류 300m 이내인 코스를 찾고 있어요.`
- 해당 단계에서 후보를 확보하지 못했을 때만 `300m 이내에서 조건에 맞는 코스를 찾지 못해 500m까지 넓히고 있어요.`
- 모양 비교 단계에서는 `가까운 후보와 모양이 더 닮은 후보를 비교하고 있어요.`
- 결과에도 탐색을 넓힌 이유를 남긴다.

**서버·앱 인터페이스**

- 기존 v1/v2 계약을 보존하고 근거리 추천 정책을 포함한 `runpen-routes-v3`를 추가한다.
- 기존 생성 엔드포인트에 선택적 진행 스트림을 추가한다. 새 앱은 진행·최종 결과·오류 이벤트를 받고, 기존 앱은 기존 JSON 응답을 유지한다.
- 응답에 접근 거리·합류 경로·도로 자료 버전·추천 구분·확장 이력을 추가한다. 진행 이벤트는 실제 엔진 상태에서 발생시킨다.
- 모든 탐색 단계는 **하나의 생성 작업 ID** 안에서 수행한다. 단계 확장이나 후보 비교로 생성 횟수를 추가 차감하지 않는다.
- 저장 코스 형식과 기존 코스·러닝 기록은 유지한다. 새 접근 정보는 계산 결과와 실행 중 캐시에 보관한다.

### 3. 실시간 러닝의 합류 경로 최적화

**처음 찾을 때**

- 현재 위치에서 코스까지의 직선거리 하한을 이용해 시작 반경을 선택한다. 기존 도로 조회가 지원하는 **1·2·5·10km 중 필요한 최소 단계**부터 시작한다.
- 가까운 코스는 기존 2km 대신 1km 범위에서 먼저 처리한다. 연결 실패나 경계 밖 우회 가능성이 있으면 범위를 넓힌다.
- 코스 도로 참조와 현재 위치 주변 도로를 찾는 색인을 만들어 매번 모든 도로를 훑는 비용을 줄인다.
- GPS 위치 모호성·도로 위 위치 확인 실패와 탐색 범위 부족을 구분한다. 범위를 넓혀도 해결되지 않는 위치 오류로 10km까지 반복 탐색하지 않는다.

**다시 찾을 때**

- 추천→상세→러닝 준비→시작에서 합류 경로를 공유한다. 생성 당시 출발지와 현위치가 다르면 도로망만 재사용하고 실제 경로는 현위치 기준으로 계산한다.
- 도로 자료 버전과 조회 범위를 키로 탐색용 도로망을 재사용한다. 메모리 캐시는 최대 2개·5분으로 제한하고, 노드와 간선 합계 10만 개를 넘으면 오래된 항목부터 제거한다. 한 항목이 한도를 넘으면 계산 후 보관하지 않는다.
- 합류 경로는 코스 내용 해시·합류 목적지·출발 도로 정보를 기준으로 보관한다. 재사용 전 기존 30m 위치 조건과 같은 보행 도로인지 확인한다.
- 선택한 후보를 우선 계산한다. 동일 요청은 하나의 진행 중 작업을 공유하고, 러닝 시작 시 그 작업을 이어받는다.
- 계정 전환·코스 변경·도로 자료 갱신 시 관련 경로 캐시를 무효화한다. 실제 러닝 기록과 오프라인 지원은 유지한다.

**대기와 실패 처리**

- GPS 확인과 경로 계산 상태를 구분한다. GPS는 15초, 유효 위치 확보 후 경로 계산은 10초를 기준으로 각각 처리한다.
- 안내창의 공통 10초 타이머가 정상 계산을 중간에 취소하는 구조를 제거한다.
- 시간 초과는 ‘길이 없음’과 구분해 표시한다. 지도와 재시도를 제공하고, 재시도 버튼이 실제로 탐색을 다시 활성화하도록 한다.
- 유효한 위치와 경로가 준비되기 전에는 기록을 시작하지 않는다. 실패 후 시작 버튼이 동일 계산을 자동으로 반복하지 않게 한다.

### 4. 검증과 완료 기준

**추천 품질**

- 같은 공개 출발지·도로 자료에서 기존 방식과 새 방식을 비교한다. 2·3km를 중점으로 1·5·10·20km와 기본 도형·사용자 도형도 확인한다.

- 300·500·1,000m 및 점수 차이 5점의 경계, 먼 후보만 존재하는 경우, 연결 불명확·후보 없음 상태를 검사한다.

**합류 정확도와 성능**

- 교량·평행 도로·보행 일방통행·단절 도로·범위 밖 우회·코스 중간 합류·마지막 진행 지점 복귀를 검증한다.
- 경로 재사용, GPS 흔들림, 이동 후 무효화, 화면 전환, 취소, 늦은 응답, 시간 초과 후 재시도를 검사한다.
