# 지도 중심 기준 코스 계산과 조회 시간

- 시작: 2026-09-27T18:35:14+09:00
- 상태: 완료 — 에뮬레이터 검증·설치 파일 생성, 휴대폰 설치는 사용자 요청으로 제외
- 종료: 2026-09-27T19:23:05+09:00
- 기록 방식: 실행 시작 시 계획 작성

## 사용자 요청

서울 지도 진입 시 현재 위치를 중심으로 잡고, 지도를 움직이면 중심 좌표를 갱신한다. 코스 테스트는 선택한 중심을 기준으로 계산한다. 계산 후 조회 시간도 확인할 수 있게 한다.

## 실행 전 계획

1. 서울 OSM 화면에 현재 위치 요청, 지도 중앙 표시와 중심 좌표 선택을 연결한다. 위치 실패 시 수동 지도를 사용할 수 있고 늦은 위치 응답이 사용자의 지도 이동을 덮어쓰지 않게 한다.
2. 선택한 중심 주변 도로를 기존 웹 프로토타입의 공개 도로 데이터 API에서 가져온다. OSM ID·연결성을 보존하고 범위가 맞는 메모리 캐시만 재사용한다. 계산은 기존 v0.2 휴대폰 내부 모듈에서 유지한다.
3. 위치 변경·취소·재시작·화면 이탈 시 다운로드와 계산을 취소하고 오래된 결과를 차단한다. 결과의 기준 좌표를 보존하고 고정 표본의 원본 비교와 동적 입력을 구분한다.
4. 결과에 도로 조회 시간·코스 계산 시간·전체 소요 시간을 표시한다. 진행 중 시간과 완료 후 시간을 일관되게 측정한다.
5. 위치 선택·범위 캐시·취소 경쟁·시간 측정의 자동 검증, 기존 회귀 검사와 타입·린트를 실행한다. Android 앱으로 지도 이동과 계산을 확인하고 연결된 휴대폰의 독립 실행 APK를 갱신한다.
6. 사용법·현재 상태·검증 기록·계획 목록에 결과와 확인 한계를 기록한다.

## 결과

지도 중심·주변 도로 조회·메모리 캐시·소요 시간 표시를 구현하고 자동 검사·에뮬레이터 검증·설치용 APK 생성을 마쳤다. 아래 범위 변경에 따라 이번 휴대폰 설치는 수행하지 않았다.

## 재개·범위 변경 — 2026-09-27T19:02:58+09:00

사용자가 진행 상황 확인 후 작업 재개를 요청했다. 휴대폰은 연결하지 않으며 **에뮬레이터 검증과 설치용 APK 생성까지** 이번 범위로 확정했다. 원래 계획 5번의 휴대폰 업데이트 설치·실제 GPS 확인은 이번 완료 조건에서 제외하고 미검증으로 남긴다. 지도 중심 기능에 필요한 주변 도로 조회와 메모리 캐시가 이번 작업에 포함됐음을 설명했고, 사용자가 해당 범위의 마무리를 요청했다. 영구 도로 파일 캐시·오프라인 복원은 후속 단계로 유지한다.

## 최종 결과 — 2026-09-27T19:23:05+09:00

- 서울 OSM 진입 시 일회성 현재 위치 요청, 지도 중심 십자·좌표 표시, 이동 후 중심 선택, 내 위치 재요청을 연결했다. 늦은 GPS 응답은 수동 선택을 덮어쓰지 않는다.
- 기존 웹 도로 API에 선택 중심과 반경 2km를 전달한다. OSM ID·전체 way 좌표를 보존하고 범위를 포함하는 메모리 캐시만 최대 2영역·15분 재사용한다. 실패·부분·손상·취소 응답을 차단하며 고정 광화문 도로로 대체하지 않는다.
- 다운로드부터 기기 내부 v0.2 계산까지 하나의 취소 범위로 처리한다. 시작 당시 중심을 결과에 보존한다. 지도·조건 변경은 이전 결과와 작업을 지우고, 동적 서울 입력에는 고정 원본 비교를 적용하지 않는다.
- 결과에 도로 조회·코스 계산·전체 소요 시간, 캐시 여부, 계산 기준 좌표를 표시한다.
- 변경 코드: `src/modules/road-data/`, `src/features/route-lab/center-controller.ts`·`session.ts`·`fixtures.ts`, `src/modules/map/`, `src/app/route-lab.tsx`, `.env.example`, `tests/route-center-road.test.mjs`. 원본 엔진·회귀 기준 파일은 이번 작업에서 변경하지 않았다.
- `npm test` 69개 통과. 최종 응답 검증·위치 처리 보완 후 관련 11개와 타입·린트를 재통과했다. 기존 알고리즘 전체 결과 회귀를 유지했다.
- 개발 앱의 에뮬레이터에서 모의 GPS, 두 중심의 실제 다운로드·서로 다른 그래프/코스, 캐시 재사용, 지도 이동 취소·재시작, 기준 좌표·시간을 확인했다.
- 최종 릴리스 APK를 arm64-v8a·x86_64 공용으로 빌드하고 에뮬레이터에 업데이트 설치했다. 서명·내장 Hermes·디버그 플래그 없음·설치본 해시 일치를 확인했다. Metro 포트 전달 제거 후 새 프로세스로 독립 실행하고 하트 3km 후보 5개를 확인했다.
- 릴리스 1회 관측은 조회 6.651초, 계산 46.703초, 전체 53.354초다. 후보 변경 시 중심 유지와 화면의 시간·기준 좌표를 확인했다. 정확한 환경과 비교 한계는 [검증 기록](../../quality/route-center-verification.md)에 있다.

## 남은 범위

휴대폰 설치·실제 GPS는 사용자 요청으로 이번 범위에서 제외했다. 영구 지역 파일·오프라인 캐시·서울 밖 기기 검증·야외 사용·장시간 성능·스토어 배포는 후속이다. 에뮬레이터는 최신 릴리스 결과 화면으로 남겼으며 다시 코드 개발을 할 때는 개발 APK를 재설치한다.

## 후속 계획 정리·전체 변경 커밋 — 2026-09-27T19:34:59+09:00

사용자가 변경된 계획 반영과 전체 변경의 한글 커밋 메시지를 요청했다. 다음 순서로 실행한다.

1. 로드맵에 주변 도로 API 조회·메모리 캐시를 앞당겨 구현한 사실과 영구 저장·오프라인 재사용의 남은 범위를 명시한다. 에뮬레이터 검증·설치용 APK 생성 완료와 휴대폰 검증 보류를 구분한다.
2. 미커밋 상태의 v0.2 이식·성능 개선·도로 조회·화면·테스트·사용법·검증·계획 변경을 모두 검토한다. 기존 Git 제외 규칙에 따라 실제 키·서명키·캐시·도구·생성된 APK는 버전 관리에 넣지 않는다.
3. 문서 링크·공백 오류·커밋 대상 파일과 비밀 값 제외를 확인하고 구현 내용과 검증 결과를 한글 제목·본문으로 남기는 로컬 Git 커밋을 생성한다.
