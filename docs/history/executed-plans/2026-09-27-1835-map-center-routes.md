# 지도 중심 기준 코스 계산과 조회 시간

- 종료: 2026-09-27T19:23:05+09:00

## 사용자 요청

서울 지도 진입 시 현재 위치를 중심으로 잡고, 지도를 움직이면 중심 좌표를 갱신한다. 코스 테스트는 선택한 중심을 기준으로 계산한다. 계산 후 조회 시간도 확인할 수 있게 한다.

## 실행 전 계획

1. 서울 OSM 화면에 현재 위치 요청, 지도 중앙 표시와 중심 좌표 선택을 연결한다. 위치 실패 시 수동 지도를 사용할 수 있고 늦은 위치 응답이 사용자의 지도 이동을 덮어쓰지 않게 한다.
2. 선택한 중심 주변 도로를 기존 웹 프로토타입의 공개 도로 데이터 API에서 가져온다. OSM ID·연결성을 보존하고 범위가 맞는 메모리 캐시만 재사용한다. 계산은 기존 v0.2 휴대폰 내부 모듈에서 유지한다.
3. 위치 변경·취소·재시작·화면 이탈 시 다운로드와 계산을 취소하고 오래된 결과를 차단한다. 결과의 기준 좌표를 보존하고 고정 표본의 원본 비교와 동적 입력을 구분한다.
4. 결과에 도로 조회 시간·코스 계산 시간·전체 소요 시간을 표시한다. 진행 중 시간과 완료 후 시간을 일관되게 측정한다.
5. 위치 선택·범위 캐시·취소 경쟁·시간 측정의 자동 검증, 기존 회귀 검사와 타입·린트를 실행한다. Android 앱으로 지도 이동과 계산을 확인하고 연결된 휴대폰의 독립 실행 APK를 갱신한다.
6. 사용법·현재 상태·검증 기록·계획 목록에 결과와 확인 한계를 기록한다.

## 결과

지도 중심·주변 도로 조회·메모리 캐시·소요 시간 표시를 구현하고 자동 검사·에뮬레이터 검증·설치용 APK 생성을 마쳤다. 아래 범위 변경에 따라 이번 휴대폰 설치는 수행하지 않았다.
