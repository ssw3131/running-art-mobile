## 기록 규칙

- 새 기록은 `YYYY-MM-DD-HHmm-topic.md`로 만듭니다. 시간대는 Asia/Seoul, 본문 시각은 ISO 8601 `+09:00`으로 남깁니다.
- 실행 직전 계획과 실제 결과·검증·남은 작업을 나눕니다. 진행 중·부분 완료·중단도 실행 이력입니다.
- 원래 계획은 보존하고 실행 결과에 맞춰 고치지 않습니다. 변경·재개는 날짜를 붙여 덧붙입니다.
- 원문·시각을 알 수 없는 과거 작업은 사후 복원임을 밝힙니다. 날짜를 추정해서 확정 사실로 적지 않습니다.
- 같은 계획은 한 파일에 이어 씁니다. 이 목록과 현재 상태도 함께 갱신합니다.

Codex는 AGENTS.md와 `$running-art-plan-record`로 시작·종료 시 이 절차를 수행합니다. 사람이 직접 기록할 때도 같은 규칙과 [템플릿](../../../.agents/skills/running-art-plan-record/assets/executed-plan-template.md)을 사용합니다. 예약 실행이나 파일 변경 감시 서비스는 아닙니다.
