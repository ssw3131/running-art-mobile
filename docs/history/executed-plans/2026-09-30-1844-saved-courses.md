## 실행 전 계획

1. 계산 당시의 후보 경로·목표 도형·기준 좌표·거리·점수·알고리즘 버전·실제/가상 자료 구분을 고정된 코스 스냅샷으로 정의한다. 이후 지도 이동·입력 조건 변경이 저장 내용에 섞이지 않게 한다.
2. 기존 사용자 SQLite DB에 새 마이그레이션을 추가해 코스를 보존한다. 기존 메모·별도 도로 캐시는 유지한다. 중복 저장·손상·잘못된 데이터·저장 실패를 처리하고 이름 변경·선택 삭제를 지원한다.
3. 계산 후보의 저장, 저장 코스 목록, 개별 상세 화면을 연결한다. 상세는 재계산·GPS·도로 조회 없이 경로를 복원한다. 배경 지도는 별도 온라인 자료임을 표시하고 지도 없이도 경로를 확인할 수 있게 한다.
4. 실제 SQLite에서 기존 스키마 업그레이드·전체 좌표 복원·중복·실패·이름 변경·삭제·프로세스 재시작을 검사한다. 계산 완료 시점의 입력 보존과 실제 엔진 후보의 저장 전후 결과를 대조한다.
5. 타입·린트·전체 회귀·Android 번들을 확인한다. 사용할 수 있는 에뮬레이터가 있으면 새 흐름을 확인하며 휴대폰 연결·설치는 하지 않는다. 결과·한계·다음 작업과 실행 이력을 갱신한다.

서버 배포·회원/동기화·공유·러닝 추적·유료화·CI/CD는 이번 범위에 포함하지 않는다. 직전 커밋 `ac42cc1`에서 시작하며 이번 요청에 커밋·푸시는 포함하지 않는다.

## 실행 결과

- 완료된 계산의 후보 좌표·목표 도형·원점·도형·목표 거리·실제 거리·점수·v0.2 버전·자료 출처를 고정 스냅샷으로 저장한다. 계산 중 입력이 바뀌어도 처음 조건을 보존한다.
- 사용자 SQLite DB에 마이그레이션 2와 코스 저장소를 추가했다. 기존 메모 API와 버전 1 마이그레이션은 유지한다. 저장 트랜잭션·해시 중복 방지·입력 검증·손상 격리·요약 목록 페이지 구분·이름 변경·선택 삭제를 구현했다.
- 계산 화면의 후보 저장, 홈의 저장 목록, 개별 코스 상세를 연결했다. 상세는 기본적으로 배경 지도 없이 저장한 경로·목표 도형을 복원하며 GPS·도로 조회·재계산을 하지 않는다. 실제 OSM 코스만 온라인 배경을 선택할 수 있고 합성 코스는 가상 자료임을 표시한다.
- [사용법](../../development/saved-courses.md), 구현 구조·저장 안내, README·인수인계·로드맵·서버 계획의 현재 상태와 다음 순서를 갱신했다. 의존성·네이티브 패키지는 추가하지 않았다.

- 타입·린트 통과. 전체 자동 검사 **119개 통과**, 신규 코스 검사 10개 포함. 버전 1 메모 보존 업그레이드·실제 엔진 후보 25개의 좌표 전체 대조·중복·손상·쓰기 실패 롤백·별도 프로세스 강제 종료 후 복원을 실제 SQLite로 확인했다.
- Android export 통과: 1,401개 모듈, 약 4.7MB Hermes 번들. 새 독립 실행 APK는 만들지 않았다.
- 기존 `RunningArt_API_36` AVD와 SQLite가 포함된 개발 APK에 최신 JavaScript를 연결했다. 합성 하트 5km 계산·저장·상세 경로·이름 변경·네트워크 차단 후 앱 강제 종료와 재실행·삭제 취소·삭제 완료를 확인했다. 스냅샷은 이름 변경 전후 동일했고 재실행 후 모든 DB 열이 유지됐다.
- 검증 후 Metro·에뮬레이터·임시 ADB 서버를 종료하고 Wi-Fi·모바일 데이터를 원래 상태로 복구했다. 기본 ADB 서버는 다시 시작했으며 연결 기기는 없다.
