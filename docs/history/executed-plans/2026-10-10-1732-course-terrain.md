# RunPen ‘코스 지형’ 표시 기능

## 요약

선택한 코스 후보와 저장 코스 상세에 **‘경사 보기’**를 추가한다. 사용자가 버튼을 누르면 온라인으로 고도를 조회해 지도 색상·고도 그래프·총 오르막을 표시한다. 코스 생성과 후보 순위는 기존 방식을 유지한다.

## 화면과 표현

- **진입:** `경사 보기` → `지형 정보를 불러오는 중…` → **코스 지형** 패널.
- **지도:** 경사의 절댓값으로 구간을 구분한다. 초기 표시 기준은 `완만: 3% 미만`, `경사 있음: 3% 이상~6% 미만`, `가파름: 6% 이상`이며 범례에 색상·명칭·범위를 함께 표시한다. 이는 제품 표시 기준이며 운동 난이도 등급으로 사용하지 않는다.
- **요약:** `총 오르막 ↑35m`처럼 표시하고, 도움말은 “코스에서 올라가는 높이를 모두 더한 값이에요.”로 제공한다.
- **그래프:** 제목은 **고도 변화**, 가로축은 거리(km), 세로축은 고도(m). 그래프를 누르면 해당 지점을 지도에 표시하고 거리·고도·구간 경사도를 보여준다.
- **방향:** 지도에 ‘그래프 기준점’과 진행 방향을 표시하고 `방향 바꾸기`를 제공한다. 방향 전환 시 그래프와 오르막·내리막 표시는 반전하며 실제 러닝 출발 설정은 변경하지 않는다.
- **설명:** “지형 데이터로 추정한 값이에요. 다리·터널 등 실제 도로 높이와 다를 수 있어요.”와 데이터 출처를 표시한다.

## 데이터와 구현

- 기존 MapTiler 키로 앱에서 고도 API를 직접 조회한다. 요청당 최대 50좌표이며 좌표마다 사용량이 계산되므로 선택한 코스만 조회한다. [공식 API](https://docs.maptiler.com/cloud/api/elevation/)
- 약 50m 간격으로 경로를 표본화하되 최대 201지점으로 제한한다. 순환 코스의 중복 시작·종료 좌표는 한 번만 조회한다.
- 인접 3지점의 고도를 이동평균으로 보정하고, 같은 보정값으로 그래프·누적 상승고도·구간 경사도를 계산한다. 순환 코스는 경계에서도 연속되게 처리한다.
- 공통 고도 조회·분석 모듈과 지형 패널을 만들고, 지도 컴포넌트에 경사 구간 및 그래프 선택 지점 표시를 위한 선택 속성을 추가한다.
- 결과는 앱 실행 중 메모리에서 재사용한다. 후보 변경·화면 종료 시 진행 중 요청을 취소하고 늦게 도착한 결과가 다른 코스에 붙지 않도록 한다.
- 조회 실패·한도 초과·오프라인은 패널에서 안내하고 수동 재시도를 제공한다. 불완전한 응답을 평지나 0m로 표시하지 않는다.

## 검증

- 평지·일정한 오르막·내리막·순환 코스에서 경사도와 총 오르막 계산 확인.
- 방향 전환, 색상 경계값, 그래프와 지도 지점 대응 확인.
- 빠른 후보 전환·취소·재조회·오프라인·API 실패 시 잘못된 수치나 중복 요청이 없는지 확인.
- 기존 후보 순위·저장·재열기·러닝 진입 회귀 확인.
- 타입·린트·관련 자동 검사와 Android 에뮬레이터 화면 검증, 기존 ID·서명의 APK 빌드까지 진행한다.

## 확정 범위와 기본값

- 첫 버전은 **후보와 저장 상세의 온라인 표시**까지다.
- 고도 결과의 영구 저장·동기화, 경사 기반 추천, 실시간 러닝 안내는 후속이다.
- 기존 코스 파일·SQLite·Cloud Run 계산 API는 변경하지 않는다.
- 현재 MapTiler 이용 범위에서 연결하며 요금제 변경은 포함하지 않는다. 실제 계정의 API 사용 가능 여부는 구현 초기에 확인한다.
- 휴대폰 설치는 이번 범위에 포함하지 않는다. 구현 시작·종료 시 프로젝트 지침에 따라 실행 기록과 현재 상태를 갱신한다.
