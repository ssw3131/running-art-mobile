# 홈 개편 및 게스트 접근 차단 계획

## 1. 로그인 후에만 서비스 이용

- 비로그인 상태로 앱에 들어오면 **회원가입 화면**을 표시한다. 기존 사용자는 같은 화면에서 로그인으로 전환할 수 있다.
- **게스트로 입장하기** 버튼을 제거한다.
- 가입·로그인·인증 콜백·가입에 필요한 약관 열람만 허용한다. 홈·5탭·상세·운영 안내·개발 화면 등 나머지 앱 경로는 모두 차단한다.
- 앱 공통 진입부에서 접근을 제한해 뒤로 가기·재시작·딥링크로 우회할 수 없도록 한다. 인증 확인 중에는 로딩을 표시하며 서비스 화면을 먼저 노출하지 않는다.
- 로그인 성공 후 홈으로 이동한다. 취소·실패 시 가입·로그인 화면에 머물고, 로그아웃·인증 해제 시 서비스 화면 이력을 비우고 돌아간다.
- **로그인 완료를 서비스 진입 기준**으로 삼는다. 약관 동의 안내는 기존 방식을 유지한다.
- 기존 게스트 자료는 삭제하거나 로그인 계정에 자동 귀속하지 않는다. 이번 차단은 앱 접근 범위이며 공개 공유 웹·계산 서버의 인증 정책 변경은 포함하지 않는다.

## 2. 로그인 사용자의 홈 두 상태

현재 로그인 계정의 자료로 판단한다.

| 상태 | 조건 | 구성 |
|---|---|---|
| 처음 이용 홈 | 저장 코스·러닝 기록 모두 없음 | 인사, 소개 이미지, 하트·물고기·강아지 선택, 전체보기, 생성 버튼 |
| 재방문 홈 | 저장 코스 또는 러닝 기록 있음 | 인사, 통계 3개, 최근 달린 코스, 최근 저장 코스, 생성 버튼 |

- 진행 중·일시정지·중단된 러닝도 자료에 포함한다.
- 모든 자료를 삭제하면 처음 이용 홈으로 돌아간다.
- 별도의 이어달리기 홈이나 복귀 카드는 만들지 않는다.
- 자료 조회 실패는 빈 기록으로 취급하지 않고 오류·재시도를 표시한다.

## 3. 홈 표시와 이동

**처음 이용 홈**

- 기본 선택은 하트. 생성 버튼은 선택한 도형을 코스 생성 화면에 전달한다.
- 전체보기는 코스 생성 화면의 도형 선택 영역으로 이동한다.

**재방문 홈**

- 통계: 최근 종료 러닝 거리·날짜, 현재 연속 러닝 일수, 이번 달 종료 러닝 누적 거리.
- 최근 달린 코스: 진행 중인 러닝을 첫 카드로 배치하고, 나머지는 시작일 최신순으로 최대 3개 표시한다. 실제 거리·활동 시간·날짜와 완주 상태를 보여준다.
- 코스 완주 판정이 있으면 **완주**, 그 외 코스 러닝은 **미완주**로 표시한다. 자유 러닝에는 완주 상태를 붙이지 않는다.
- 러닝 중·일시정지·중단 카드 선택은 해당 러닝 화면으로 연결한다. 자동 재개하지 않는다.
- 종료 기록 선택은 기록 상세로 연결한다. 종료한 미완주는 기존 새 도전 기능을 이용한다.
- 최근 저장 코스: 저장일 최신순 최대 3개, 코스명·거리·저장 날짜 표시. 선택하면 저장 코스 상세로 이동한다.
- 각 더보기는 보관함의 해당 목록으로 연결한다.
- 러닝 기록이 없으면 통계는 `— / 0일 / 0km`, 비어 있는 목록은 안내 문구를 표시한다.

**공통 표현**

- 첨부 시안의 배치와 기존 공통 컴포넌트를 사용한다.
- 카드에는 실제 지도와 경로를 표시한다. 러닝은 GPS 궤적, 저장 코스는 저장 경로를 사용하며 중단 구간을 연결하지 않는다.
- 지도는 조작을 막고 보이는 카드만 활성화한다. 지도 로딩 실패 시 경로 그림으로 대체하고 출처 표기를 유지한다.
- 작은 화면·큰 글씨에서는 카드 열 수를 줄이고 두 테마를 지원한다.
- 상단 로고·메뉴와 하단 5탭은 로그인 후 표시한다. **이용량·한도 수치는 보류**한다.

## 4. 구현·검증과 완료 기준

- 루트 내비게이션에 공통 인증 차단을 적용하고 가입 화면·인증 콜백의 이동을 통일한다.
- 홈 모델은 두 상태로 정리하고 저장 코스 개수·최근 코스·러닝 복귀 상태를 추가한다. 기존 SQLite·계정별 조회를 재사용하며 DB·서버 API 변경은 하지 않는다.
- 게스트의 모든 앱 경로 직접 접근, 뒤로 가기, 인증 취소·실패·성공, 세션 복원·해제와 계정 전환을 검증한다.
- 홈 자료 조합·전체 삭제·미완주 복귀·통계·오프라인 지도·접근성·스크롤 성능을 검증한다.
- 기존 게스트 허용 테스트를 새 정책에 맞추고 PR 필수 CI와 홈 화면 검수를 통과한다.
- 기존 자료·설정을 보존하고 제품 결정·홈 계약·인수인계를 갱신한다. 휴대폰 설치·운영 배포와 코스 생성·배지·공유 개편은 후속 단계로 둔다.
