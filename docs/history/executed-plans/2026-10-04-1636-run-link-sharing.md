## 확정된 사용자 결정

- 추천 코스가 아니라 사용자가 실제 달린 GPS 경로를 공유한다.
- 로그인한 계정별로 기록을 보관하고, 사용자가 선택한 기록만 링크로 공유한다.
- 수신자는 앱 설치·로그인 없이 브라우저의 MapTiler 지도에서 경로를 확인한다.
- 공유 화면에는 GPX 다운로드를 넣지 않는다. 사용자가 파일을 관리할 필요가 없다.
- 이미지 공유는 이번 범위에서 제외한다. 장소 검색은 서비스 계획에서 제외한다.
- 경로 데이터·공유 주소와 지도 표시를 분리한다. 향후 공유 웹의 지도 공급자를 바꾸더라도 기존 링크·경로를 보존한다. 앱 지도 변경만으로 웹 지도가 자동 변경되는 것은 아니다.
- 휴대폰을 연결하거나 설치하지 않고 PC에서 개발·검증한다. 기존 GPX 내보내기, 계정·기록·앱 ID·서명은 보존한다.

## 실행 전 계획

1. 기존 계정별 러닝 저장·동기화를 재사용한다. 로그인한 계정의 종료된 러닝만 공유하며, 서버 원본 저장을 확인한 뒤 공개용 최소 사본과 추측하기 어려운 링크를 만든다.
2. 공유용 사본에는 실제 경로 좌표·거리·활동 시간·표시 제목만 포함한다. 계정 식별자, 인증 정보, 원본 파일 경로, 개별 GPS 시각은 공개 응답에서 제외한다. 일시정지·GPS 공백을 선으로 연결하지 않는다.
3. 서버는 소유자만 공유 생성·조회·해제를 할 수 있고, 수신자는 해당 링크의 경로만 읽는다. 기본 비공개·공유 해제·다른 계정 접근 거부·기록 삭제 동기화·탈퇴 시 공개 중단을 검증한다.
4. 러닝 상세에 링크 공유·공유 중단을 연결한다. 공유 범위를 화면에서 알려 주고 네트워크 실패·중복 요청·계정 변경·취소를 처리한다. 개인 자료 동기화를 임의로 켜거나 비로그인 기록을 자동 귀속하지 않는다.
5. 가벼운 공유 웹페이지를 별도 배포 단위로 구성한다. MapTiler 지도와 전체 실제 경로를 보여주고 모바일 화면·확대/축소·로딩·해제/잘못된 링크·지도 오류를 처리한다. GPX 다운로드·이미지 생성·장소 검색·검색엔진 노출 기능은 추가하지 않는다.
6. 순수 모듈·실제 SQLite·PostgreSQL 권한/함수·웹 요청/구조·타입·린트·Android 번들 등 변경에 맞는 검증을 한다. 기존 사용자 위치 기록은 시험용으로 공개하지 않는다. 합성 자료만 사용한다.
7. 작업 사본에서 검증 후 원래 프로젝트의 변경 유무를 재확인해 반영한다. 실제 서버·웹 호스팅은 이용 가능한 권한을 확인하고 적용 전 결과를 검토한다. 필요한 접근 권한이 없으면 구현·배포 준비본을 보존하고 실제 공개 링크 미완료를 명시한다.
8. 사용법·검증 기록·최신 상태·로드맵·제품 결정을 갱신한다. 실행 전 계획은 보존하고 결과·범위 변경은 별도로 덧붙인다.
