## 실행 전 계획

`running-art-mobile` 하나에서 최신 코드를 수정·빌드·확인할 수 있도록 통합한다. 복구 가능한 로컬 백업을 만든 뒤 임시 작업 폴더를 제거한다. `_archive/정리실행일시/`에 변경 원본·Git 이력·APK·검증 자료·로컬 설정을 보존하고, 기존 웹 테스트 프로젝트 두 개와 `.codex-remote-attachments`는 유지한다. 휴대폰 설치, 운영 서버·DB·약관 게시, 제품 API·데이터 형식 변경은 포함하지 않는다.

1. 실행 직전 원격 main·각 worktree·미커밋 변경을 조사한다. Git bundle, 바이너리 diff, 새 파일 원본, 브랜치·커밋·파일 목록·해시를 보존한다. APK·검증 화면/로그·환경 파일·서명키·로컬 전용 스크립트를 로컬에 백업한다. 재생성 가능한 캐시와 증거 자료를 구분하고, 모르는 파일은 보존한다. junction은 링크와 대상을 구분하며 공유 대상을 재귀 복사·삭제하지 않는다.
2. 최신 main에서 통합 브랜치를 만들어 A10e 설치, 정책 초안 작성, A7 최종 수정 APK 설치/검증, 홈 최종 PR 검증 기록을 원래 날짜와 범위대로 통합한다. 가입·20km·GPS 변경도 재대조하고 대체된 구버전으로 덮어쓰지 않는다. 미확인 차이가 있으면 제거하지 않는다. 문서 검사와 필수 PR 검사를 통과한 뒤 squash merge하며 과거 실패·미검증 기록은 유지한다.
3. 모바일의 미커밋 자료 백업을 확인하고 archive의 main 점유를 해제한 뒤 mobile을 최신 main으로 맞춘다. mobile의 도구를 유지하고 잠금 파일 기준으로 의존성을 설치해 형제 node_modules 의존을 없앤다. 환경을 최신 설치본과 대조하고 앱 ID·서명을 유지하며 `--no-clean`으로 네이티브 설정을 갱신한다. 상위 작업 안내와 현재 상태에 기본 경로·백업 위치를 기록하고 과거 경로는 역사적 기록으로 보존한다.
4. 백업 해시·bundle·복원, main 소스 일치, 타입/린트/빠른 검사, Android 빌드·동일 ID/서명, 전용 에뮬레이터 홈/보관함/상세/뒤로, Metro 연결·새로고침을 확인한다. 그 뒤 archive·signup·distance-20km·home-auth·runpen-domains·.guidance-resume를 Git worktree 절차로 제거한다. 절대 경로와 junction을 확인하고 미커밋 표시만으로 강제 제거하지 않는다. 백업된 완료 로컬 브랜치도 정리하고 기존 원격 브랜치/PR은 유지한다. 남은 폴더·커밋·백업/복원·실행 명령·검증을 안내하며 백업을 자동 삭제하지 않는다.
