## 실행 전 계획

이어달린 구간이 두 번 합산돼 배지가 일찍 지급되는 문제를 먼저 고친다. ‘도전 중’ 탭은 피그마의 6개 그룹으로 구성하고, 사용자가 선택한 대로 **목표가 여러 개인 카드는 목표 목록을 먼저 연다.** [피그마 도전 중 화면](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=494-2460)

### 1. 누적 거리·시간과 배지 지급

- 실제 러닝과 시뮬레이션 모두 이어달리기를 저장할 때, 이전 시도에서 가져온 구간의 ID·거리·활동 시간을 함께 보존한다. 각 기록의 상세에는 이어 달린 전체 경로와 총량을 보여주고, 계정별 누적 통계와 배지 판정에서는 같은 구간을 한 번만 센다. 홈·마이페이지·보관함이 이 계산을 함께 사용한다.
- 같은 코스를 완주한 뒤 새로 달린 기록은 별도 실적으로 센다. 이전 기록을 삭제해도 후속 기록에 남아 있는 구간은 한 번 인정하고, 마지막으로 그 구간을 담고 있던 기록까지 삭제하면 누계에서 빠진다. 재집계 결과 기준에 못 미치는 배지는 다시 미획득으로 표시한다.
- SQLite와 비공개 동기화 기록에 이어달리기 정보를 선택 필드로 추가한다. 기존 기록은 같은 계정·코스·러닝 방식에서 이전 미완주 기록의 좌표·시각·구간 경계가 후속 기록의 앞부분과 일치해 연결을 확인할 수 있을 때 소급 보정한다. 연결이 불분명한 기록은 기존 값을 유지한다. 원본 GPS와 러닝 기록은 보존한다.

### 2. 보관함과 도전 상세

| 도전 카드 | 카드를 누르면 보이는 내용 |
|---|---|
| 누적 거리 달성 | 현재 총거리와 10·50·100·300km의 달성 상태 |
| 누적 시간 달성 | 현재 활동 시간과 5·50·100·500시간의 달성 상태 |
| 카테고리별 작품 완주 | 기하·사물·동물 목표 목록. 하나를 선택하면 필요한 도형별 완주 상태 |
| 다양한 작품 완주 | 서로 다른 도형 3·6·12종 목표 목록과 각 목표의 진행도 |
| 동일 코스 변주 완주 | 거리 변주·장소 변주 목표 목록과 각 조건을 충족한 기록 |
| 동일 코스 반복 완주 | 동일 코스 5회 목표의 현재 완주 횟수와 해당 기록 |

- ‘도전 중’에는 위 순서로 6개 카드를 표시한다. 카드의 `2/4종`은 **획득한 목표 수 / 전체 목표 수**다. 상단의 `현재 도전 N개 진행 중`은 **진척이 있고 미완료 목표가 남은 그룹 수**로 계산한다. 예를 들어 같은 코스를 2회 완주했다면 반복 카드에는 `0/1종`, 상세에는 `2/5회`가 표시되고 진행 중 그룹에 포함된다.
- 보관함은 기존 29종과 획득 개수를 표시한다. 보관함의 ‘50km 배지’는 해당 배지의 획득 상세로, 도전 탭의 ‘누적 거리’는 전체 단계로, 홈 추천은 추천된 개별 도전으로 연결한다. 목록을 보고 돌아오면 선택했던 탭과 스크롤 위치를 복원한다. ### 3. 완료 기준

- 잘못 지급된 10km 배지 — 재현된 4.10km 중단 → 이어서 총 5.99km 완주에서 누계는 5.99km이고 10km 배지는 미획득이다. 이후 독립 러닝으로 합계가 10km에 도달하는 순간 한 번 획득한다. 활동 시간에도 같은 경계 검사를 적용한다.
- 기존 기록과 복원 — 두 번 이상 이어달리기, 독립 재도전, 이전·후속 기록 각각 삭제, 동기화 역순 복원, 계정 전환 후에도 계정별 총량과 배지 상태가 맞는다.
- 화면과 이동 — 빈 계정에서 0개 진행 중과 카드 6개, 누적 50km에서 2/4종, 동물 3종 완주에서 상세 3/5종을 확인한다. 360dp Android 화면에서 피그마와 대조하고, 홈 추천·목표 목록·획득 배지의 이동 및 뒤로가기를 검증한다.

## 구현 결과

- 러닝 SQLite v10에 시도별 계승 정보를 기록하고 비공개 백업·복원에 연결했다. GPS 원본과 각 기록의 총량을 보존하며 홈 월간 거리, 마이페이지 누계, 배지 획득이 같은 구간을 두 번 세지 않게 했다.
- 6개 도전 그룹을 Figma 순서로 구현했다. 다중 목표 카드 → 목표 목록 → 개별 상세와 단일 반복 목표의 직접 진입, 홈 추천과 보관함의 개별 진입을 검증했다.
- 6km 경로에서 4.10km 중단 → 총 5.99km 완주, 두 번 재개, 추가 독립 러닝의 10km 달성, 5시간 경계, 선행·후속 기록 삭제, 새·옛 파일 역순 복원을 검증했다. 기존 GPS 좌표를 보존하며 구간 경계가 없거나 후보가 여럿인 경우 기존 집계를 유지한다.
- UI 전체 44개 스위트의 258개 검사와 Python QA 39개가 통과했다. Android 360dp의 두 단계 뒤로가기와 카드 스크롤 좌표 확인을 기존 에뮬레이터 검사에 추가했다.
