## 실행 전 계획

1. 기존 코스·완료된 러닝을 보존하면서 SQLite 소유권과 전송 상태를 추가한다. 계정 미연결 자료는 앱의 명시적 연결 동작으로 귀속하며 로그인 자체가 자료를 전송하지 않는다. 계정 변경·로그아웃 시 연결된 자료를 분리한다.
2. 모바일 전용 Supabase에 개인 요약·소유 관계·변경 버전·삭제 표시 테이블과 비공개 좌표 파일 저장소를 구성한다. DB 및 Storage의 본인 접근 정책, 중복 재전송과 경쟁 변경을 처리하는 서버 계약을 마이그레이션으로 관리한다.
3. 기기 우선 저장·전송 대기·서버 확인·다른 기기 복원을 구현한다. 네트워크 실패 재시도, 전송 중 변경, 중복, 삭제, 충돌, 계정 변경 중 작업 취소와 손상 자료 거부를 검증한다. 진행 중 GPS 기록은 완료 후 전송한다.
4. 실제 SQLite와 서버 정책·통합 검증, 타입·린트·기존 회귀 검사를 실행한다. Android release 빌드와 가능한 에뮬레이터·기기 범위를 검증하고 실행과 미검증을 구분한다. 실제 개인 좌표를 로그나 공개 저장소에 남기지 않는다.
5. 사용법·서버 계약·검증 결과·현재 상태·로드맵·실행 목록을 갱신한다. 목표의 필수 검증이 남으면 완료로 표시하지 않는다.
