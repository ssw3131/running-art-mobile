# 코스 생성 최대 20km와 거리별 탐색 반경

- 기록 생성·실행 시작: 2026-10-24T18:13:41+09:00
- 상태: 완료 — 소스 구현·로컬/에뮬레이터 핵심 검증 범위. 로컬 커밋까지 승인, 통합·배포·배포 검증은 후속
- 기록 유형: 실행 시작 시 계획 작성
- 요청 출처: 코스 생성 Figma 대조 대화. 사용자 최종 요청: “계산이 커지겠네. 20까지 계산되게금 조건 수정하고 최대 20으로 하자”.

## 실행 전 계획

- 40km 검토를 종료하고 최대 목표 거리를 20km로 제한한다. 기존 정수 km 입력 단위를 유지한다.
- 기본 1~10km는 피그마 기준 슬라이더, 더 먼 거리는 11~20km 숫자 입력으로 제공한다.
- 기존 1~10km의 반경 2km·점수·경로 탐색 알고리즘은 보존하고, 11~20km는 목표 거리에 따라 반경을 최대 5km로 확대한다. 서버와 기기에서 동일한 조건을 사용한다.
- 서버 요청 검증·OpenAPI·화면 안내를 함께 변경하고, 잘못된 거리/반경 조합을 거부한다.
- 실제 공개 도로 자료로 20km 경로 생성·연결·거리/중복 조건·계산 시간을 확인한다. PC 결과와 휴대폰/운영 서버 검증을 구분한다.
- 범위는 거리 입력과 계산 조건이다. 합의된 유사도 표시·경사 난이도·도형 교체 등 전체 Figma 개편은 이 변경에 섞지 않는다. 저장 후 러닝 조건을 유지한다.
- 관련 검사와 필수 검증을 수행하고 결과·한계를 기록한다. 다른 작업 폴더의 변경을 보존한다. 휴대폰 설치·운영 배포는 별도이다.

## 실행 결과

거리·장소검색·도형·추천·저장필수 흐름 소스와 후속 검사 코드를 작성했다. 구체적 구현과 호환 계약은 [새 계약](../../development/course-generation-figma-20261024.md)을 따른다.
