## 실행 전 계획

1. 로그인된 Supabase의 무료 개인 조직을 `Running Art` 이름으로 준비한다. 유료 요금제·결제·초대는 수행하지 않는다.
2. 모바일 개발 프로젝트의 생성 화면에서 이름·지역·요금 조건을 확인하고 준비한다. 비밀번호 등 새 인증정보의 입력이 필요하면 사용자에게 해당 단계만 넘긴다.
3. 실제 생성된 자원과 미완료 항목을 구분해 현재 상태·계정 준비 문서·실행 목록에 남긴다. 비밀 값·개인 GPS 자료는 기록하거나 전송하지 않는다.

## 실행 결과

- 최초 조직 목록은 비어 있었고 `Running Art / Personal / Free($0/월)`로 조직 생성 폼을 준비했다.
- 조직 생성 클릭은 자동 승인 검토에서 거절됐다. 이유는 로그인 완료 안내가 명시적인 조직 생성 승인까지 포함하지 않는다는 것이었다. 같은 생성 작업을 재시도하거나 다른 경로로 우회하지 않았다.
- 이후 현재 화면을 읽었을 때 `Running Art / Free` 조직과 새 프로젝트 생성 화면이 확인됐다. 생성 주체는 확인하지 않았으며 에이전트의 조직 생성 성공으로 기록하지 않는다.
- 프로젝트 생성 폼을 `running-art-mobile-dev`, `Northeast Asia (Seoul) / ap-northeast-2`로 준비했다. Enable Data API는 켜짐, Automatically expose new tables는 꺼짐, Enable automatic RLS는 켜짐이다. 아직 프로젝트에 적용된 설정이 아니다.
- DB 비밀번호는 입력·생성·열람하지 않았고 Create new project를 누르지 않았다. 결제·초대·사용자 기록 업로드·앱 구현은 수행하지 않았다.
- 생성 전 화면을 Git 제외 로컬 `.cache/supabase-setup/project-create-ready.png`에 보존했다.
