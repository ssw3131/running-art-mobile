사용자 최종 요청: “유료는 이후 계획으로만두고 고려해서 우선 서버 정리하자”.

1. 두 테스트 프로젝트는 알고리즘·기능 참고로만 사용하고 모바일 실행·서버·데이터·배포를 독립시키는 결정을 보존한다.
2. 독립 도로 파일 공급과 회원·동기화·공유·커뮤니티의 서버 책임, 권장 구성, 데이터 경계, 운영·검증 조건과 구현 순서를 `docs/planning/server-strategy.md`에 정리한다.
3. 유료화·결제·상품 등급·생성 횟수 제한은 후속 계획으로만 남긴다. 현재 사용자 무료 제공과 인프라 비용을 구분한다.
4. AGENTS.md, README, 제품 결정, 구현 구조, 이식 기준, 로드맵, 현재 상태·문서 목차를 맞춘다. 기존 서버 복구·배포를 모바일 다음 작업에서 제외하며 실제 코드가 아직 기존 API에 의존함을 명시한다.
5. 과거 실행 계획·증거는 보존하고 해당 기록에 후속 결정만 덧붙인다. 문서 링크·공백·변경 범위·문서 간 일관성을 검증한다.

- 변경 대상은 모바일 저장소의 Markdown 12개다. 앱·서버 코드·환경 변수·APK·클라우드 자원·요금제·형제 프로젝트는 변경하지 않았다. 커밋·push·배포는 수행하지 않았다.

- 웹 테스트 저장소의 `git status --short`는 깨끗했다. 다른 테스트 프로젝트에 쓰기 작업을 하지 않았다.
