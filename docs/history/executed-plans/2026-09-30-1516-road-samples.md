## 실행 전 계획

1. 새 한국 OSM PBF의 날짜·출처·해시를 고정한다. 원본·생성물은 Git 제외 경로에 보관하고 모바일 저장소만으로 재현되는 독립 가공 스크립트를 만든다.
2. 서울·부산·지역 경계의 표본과 공급 형식 초안을 만든다. 전체 way geometry와 OSM node/way ID, 엔진에 필요한 속성을 보존한다. 영역을 가로지르는 선분도 포함한다.
3. 지역 분할 크기와 압축 방식을 비교한다. 매니페스트에 자료 릴리스·스키마 버전·기준 시각·영역·크기·해시를 기록한다.
4. 현재 v0.2 엔진에 입력하는 독립 어댑터를 구현하고 동일 원본·동일 영역의 분할 전후 연결성과 전체 계산 결과를 비교한다. 누락·중복·손상·버전 불일치를 자동 검사한다. 엔진의 탐색·보행 규칙은 변경하지 않는다.
5. 로컬 제공 환경의 전송 시간과 연결된 휴대폰의 압축 해제·입력 처리·메모리를 측정한다. 필요하면 별도의 로컬 검증 화면/도구를 추가한다. 기기가 없거나 측정할 수 없는 항목은 이유와 재현 절차를 남기고 미완료로 유지한다.
6. 측정 근거로 공급 형식과 4-2 진입 여부를 결정한다. 타입·린트·관련 테스트 및 필요한 Android 검증을 수행하고 사용법·검증 기록·현재 상태·로드맵·실행 목록을 갱신한다.

실제 클라우드 자원 생성·배포, 앱 운영 주소 교체, 기존 테스트 서버 복구, 전국 배포, 회원·커뮤니티·유료화·CI/CD는 이번 범위에 포함하지 않는다. 기존 사용자 문서 변경을 보존한다.

## 실행 결과

1. `scripts/road-data/source-lock.json`에 Geofabrik 한국 PBF 원본 URL·바이트 수·SHA-256·MD5·자료 기준 시각을 고정했다. 원본은 `.cache/road-data/raw/`에 보관했다.
2. Python 독립 추출기와 Node 가공·비교·전송 측정 스크립트를 구현했다. 서울·부산·구로/광명 인근 경계에서 0.01/0.02/0.04도 격자 107개 후보 파일을 만들었다. 가공·런타임 모두 형제 프로젝트 파일을 읽지 않는다.
3. `src/modules/road-data/file-format.ts`에 v1 파일·매니페스트 검증·격자 선택·ID 기반 병합을 추가했다. 실제 엔진의 보행 필터와 전체 way·node ID·태그·좌표를 보존한다. 기존 계산 엔진과 일반 도로 API는 변경하지 않았다.
4. SHA-256·gzip 해제를 위해 fflate 0.8.3 / noble-hashes 2.0.1을 고정 추가하고 `road-file-lab`에 별도 로컬 측정 화면을 만들었다. 검증용 loopback 서버만 사용하며 운영 주소·영구 캐시·클라우드 자원은 만들지 않았다.
5. 모든 9개 조합의 입력·그래프·전체 코스 결과가 일치했다. 각 지역 하트 3km 후보 5개다. 0.02도는 0.01도 대비 총 파일 수 약 69% 감소·gzip 약 9% 증가로 잠정 선택했다. 휴대폰 수치 전에는 확정하지 않는다.
6. 사용법·공급 계약·PC/Android 측정 JSON·검증 문서, 상태·로드맵·서버 계획·작업 지침·목차를 갱신했다. 기존 사용자 문서 변경을 보존했다.

## 검증

- `fetch-source.ps1`: 고정 SHA-256·크기 검사 통과. 처음 받은 원본은 공식 MD5와도 일치.
- Python 3.12.14 / pyosmium 4.3.1: 한국 highway 1,816,595개 순회, 표본 후보 way 25,243개 추출, 약 57.20초. Python 경계 검사 4개 통과.
- `roads:package` / `roads:verify`: 3개 지역 × 3개 격자 전체 입력·연결·계산 결과 일치. 검색으로 추가되는 `reachable` 상태를 새 그래프와 비교하던 검증 도구 오류를 수정하고 완료했다. 엔진 변경 없음.
- `roads:benchmark`: 9개 조합 × 3회 Node loopback 측정. 0.02도 전체 전송·입력·그래프 중앙값 서울 139.65ms, 부산 87.77ms, 경계 118.31ms. 운영 CDN·휴대폰 수치가 아님.
- `npm test`: 84개 통과. 공급 계약·codec 10개 포함. `dev.ps1 check`: 타입·린트 통과.
- Expo doctor: 네트워크 권한 허용 후 20/21. 기존 Expo·constants·router 3개 패치 갱신 안내만 남음. 새 라이브러리 문제는 없음. 이번 범위에서 기존 SDK 버전을 변경하지 않음.
- Gradle debug arm64/x86_64 빌드, Android production JS/Hermes export 통과. Metro 최신 DevTools는 로컬 dotslash 오류로 fallback을 사용했으며 번들·앱 실행 정상.
- API 36 x86_64 에뮬레이터 + debug APK + production JS / Hermes=true에서 0.02도 9회 입력 해시·그래프 수 비교 통과. 완료 화면·스크린샷과 취소 처리를 확인했다. 전체 중앙값 서울 5.736초·부산 2.938초·경계 4.305초, JS 해시 검사가 주요 비용이었다. 전체 코스 계산 시간은 이 측정에 포함하지 않았다.
- 에뮬레이터 메모리 초반 12회 스냅샷과 전후 PSS/RSS를 보존했다. 실제 휴대폰·전체 구간 순간 최대 메모리로 보고하지 않는다.
- 휴대폰 연결을 요청했으나 마지막 확인에도 emulator-5554만 연결돼 있었다. 실제 휴대폰 측정은 미완료다.

## 남은 작업과 종료

남은 필수 작업은 USB 디버깅이 허용된 실제 Android 휴대폰에서 각 격자 반복 처리 시간·전체 구간 메모리를 측정하고 0.02도/gzip 잠정 선택을 확정하는 것이다. 연결 기기 부재로 4-1은 부분 완료이며 목표를 완료 처리하지 않았다. 4-2 클라우드 구축은 아직 시작하지 않는다.

기기 연결 후 이 기록을 이어 쓴다. 설치된 휴대폰 APK는 이번 작업에서 변경하지 않았다. 에뮬레이터는 측정 후 기존 9월 30일 로컬 릴리스 APK로 되돌리고 이번 서버·포트 전달·에뮬레이터를 종료한다. 정리 결과와 최종 갱신 시각은 후속 절에 기록한다.
