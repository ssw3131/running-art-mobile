## 실행 전 계획

1. 기존 SQLite 저장 코스의 검증된 스냅샷을 GPX 1.1 트랙으로 변환한다. 경도·위도 순서를 올바르게 변환하고 전체 경로·순서·정밀도를 유지한다. XML 이스케이프·유효 문자·파일명을 처리하며 가상의 시간·속도·고도나 목표 도형은 내보내지 않는다. OSM 출처와 합성 테스트 코스를 구분한다.
2. 코스 상세에서 저장된 코스를 다시 읽어 임시 GPX 파일을 만들고 기기의 공유 창으로 내보낸다. 네트워크·GPS·재계산·서버 계정 없이 동작하며 공유 취소를 저장 성공으로 표시하지 않는다. 중복 실행·화면 이탈·저장/공유 실패를 처리하고 기존 DB를 변경하지 않는다.
3. Expo SDK에 맞는 파일·공유 모듈을 연결한다. 저장 데이터와 기존 Android 로컬 설정을 보존하고 필요한 네이티브 빌드를 수행한다.
4. 기준 코스 전체 좌표·XML 유효성·오류·취소·파일 전달을 검사한다. 타입·린트·관련 회귀와 Android 빌드를 확인하며 사용 가능한 에뮬레이터에서 공유 창·취소·재시도를 검증한다. 휴대폰은 현재 연결되지 않아 실제 기기 검증 가능 여부를 별도로 기록한다.
5. 사용법·검증 결과·현재 상태·로드맵과 실행 기록을 갱신한다. 서버 배포·회원 서버·유료화·CI/CD는 재개하지 않는다.

## 실행 결과

저장 코스 상세에서 GPX 1.1 파일을 Android 공유 창으로 내보내도록 구현했다. `src/modules/courses/gpx.ts`·`export.ts`·`share-gpx.ts`와 웹 안내를 추가하고 상세 버튼을 연결했다. 최신 DB 이름과 전체 경로를 읽으며 기존 스키마·자료는 변경하지 않는다. 중복 실행·화면 이탈·쓰기/공유 실패를 처리하고 공유 창 종료를 저장 성공으로 표시하지 않는다. 수신 중 파일이 삭제되지 않도록 공유 파일을 보존하며 다음 내보내기에서 오래된 임시 폴더를 정리한다.

Expo 파일·공유 의존성, GPX 11개 자동 검사, 공식 XSD 검증 도구, 네트워크 권한 없는 Android 로컬 수신 검사 앱을 추가했다. 기존 도구·Android 로컬 설정을 유지하는 no-clean prebuild 후 release APK를 만들었다. `build/install/running-art-0.1.0-20261001-gpx.apk`와 해시·한글 안내를 준비했다. 실제 서버·클라우드 가입·배포·외부 APK 공개는 실행하지 않았다.

- 에뮬레이터: 오프라인 합성 코스 저장, 연속 버튼 입력, 공유 취소·재시도, 별도 앱의 `content://` 읽기·한글 파일명·MIME·본문 확인. 이름 변경·강제 종료/복원 후 다시 전달. 2회 수신의 각 151점이 DB의 전체 좌표와 정확히 일치하고 XSD 통과.
