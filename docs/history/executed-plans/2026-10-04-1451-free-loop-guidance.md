## 실행 전 계획

### 확정한 동작

- 탐색 범위는 **지도 중심 반경 2km 전체**로 유지한다. 중심 100m 안에 도로가 있어야 하는 조건과 중심 출발·복귀 조건을 없앤다.
- 코스의 어느 지점에서든 출발하며, 처음 달리는 방향을 자동 인식한다. 해당 방향으로 코스 전체를 돌아 합류 지점에 복귀하면 완주한다.
- 코스 밖에서는 **보행 도로상 최단 경로**로 합류한다. 접근 구간도 시작 버튼을 누른 순간부터 러닝 거리·시간에 포함하지만, 코스 완주 진행률에서는 제외한다.
- 러닝 중 이탈하면 마지막 정상 진행 지점으로 최단 복귀한다. 완주하면 자동 일시정지하고 **완주 저장 / 계속 달리기**를 제공한다.

### 코스 추천 변경

- 기존 v0.2의 도형·점수·거리 허용 범위·중복 억제·추가 탐색을 유지하면서, 중심에 묶이지 않는 순환 코스 탐색 모드를 추가한다. 앱의 일반 코스 생성에 적용하고 기존 모드는 원본 회귀 검증용으로 유지한다.
- 중심과 연결된 도로망에 한정하지 않고 반경 안의 각 연결 도로망을 탐색한다. 중심 접근 거리의 감점·탈락 조건과 접근·복귀 경로를 제거하고, 순환 구간 자체로 거리와 점수를 계산한다.
- 새 추천은 양방향 보행이 가능한 도로로 구성한다. 보행 금지·사유지·일방통행과 실제 OSM 연결성은 계속 준수한다.
- 지도 중심은 탐색 기준으로만 표시한다. 고정 출발·도착점 표시와 접근/복귀 거리 문구를 없애고, “어느 지점에서든 양방향 출발”을 안내한다.

### 합류 경로와 러닝 안내

- 안내 상태를 `접근 → 방향 확인 → 코스 진행 → 이탈 복귀 → 완주 확인`으로 구분한다. GPS 정확도·최신성 조건은 유지하되 기존 출발점 25m 제한은 제거한다.
- 접근 경로는 현재 위치에서 도달 가능한 코스 구간들을 대상으로 최단 거리 탐색을 수행한다. 직선으로 가까운 지점이나 기존 첫 좌표를 목적지로 고정하지 않는다. 도로 구간 중간에도 합류할 수 있게 한다.
- 기존 도로 공급·캐시를 사용하고 필요한 범위를 단계적으로 넓히되 **조회 반경 최대 10km**를 지킨다. 범위 초과·자료 부족·연결 불가 시 사유를 표시하고, 경로 확보 또는 직접 합류 전까지 시작을 막는다.
- 경로 준비 중에는 러닝을 기록하지 않는다. 준비 완료 후 시작 시 위치를 다시 확인하며, 비동기 계산은 취소·재요청을 지원하고 오래된 결과를 반영하지 않는다.
- 코스 가까이에서 안정적으로 위치가 확인되면 그 지점을 한 바퀴의 기준으로 저장한다. 초기 연속 이동으로 방향을 결정하고, 방향 확인 중 이동도 확정된 진행률에 반영한다. 모호한 교차점에서는 방향 확정을 기다린다.
- 진행률은 코스 순서에 따른 연속 통과로 계산한다. 역주행·왕복·교차점의 다른 구간으로 이동·GPS 공백을 추가 진행으로 인정하지 않는다. 방향을 거슬러 이동하면 진행률을 유지하고 원래 진행 방향으로 안내한다.
- 이탈·중단 후 복귀 목적지는 마지막 정상 진행 지점으로 유지한다. 복귀 경로 재계산이 실패해도 기존 기록은 계속 보존하고, 안내 불가 상태와 재시도를 제공한다.
- 완주 판정은 한 바퀴의 연속 진행과 합류 지점 복귀를 함께 요구한다. 기존 GPS·이탈·복귀·완주 임계값을 초기값으로 사용한다. ‘계속 달리기’ 후에는 완주 이력을 보존하고 같은 완주로 반복 정지하지 않는다.

### 인터페이스·저장 호환

- 탐색 입력에 자유 순환 모드를 추가하고, 결과에는 고정 출발점 없는 코스임을 구분한다. 경로 계산과 화면 표시가 같은 모드를 사용하도록 연결한다.
- 새 코스 사본 형식에는 OSM 도로 구간 참조와 양방향 가능 정보를 보존한다. 좌표만 가까운 고가도로·교량·평행 도로를 합류 지점으로 잘못 연결하지 않도록 사용한다.
- 안내 체크포인트 새 버전에 합류 위치·방향·현재 위치와 인정된 진행량·접근/복귀 경로·완주 이력을 저장한다. GPS 기록과 같은 트랜잭션으로 확정하고, 저장 후 음성·진동을 실행한다.
- 기존 저장 코스와 완료 기록은 재작성하지 않는다. 기존 코스는 저장된 전체 경로를 한 바퀴로 취급하며 예전 접근 구간을 임의로 삭제하지 않는다. 기존 진행 중 세션은 이전 규칙으로 복원하고 새 세션부터 새 규칙을 적용한다.
- 새 코스 형식과 이전 형식을 저장·동기화·복원에서 모두 읽는다. 기존 SQLite JSON 열과 Supabase 저장 계약을 사용하며 서버 테이블 변경은 하지 않는다. 닫히지 않은 경로는 임의 직선으로 연결하지 않고 코스 러닝 불가 사유를 표시한다.
