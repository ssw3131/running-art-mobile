## 2026-09-26T15:53:22+09:00 — 지도 글자 렌더링 보완 계획

- 지도 도형·위치 점·카메라 이동은 확인했으나 현재 Pixel 7 에뮬레이터의 OpenGL에서 지도 글자가 표시되지 않는다.
- MapLibre 공식 이슈 #3648에서 에뮬레이터 OpenGL의 유사 증상과 Vulkan 대안을 확인했다. 현재 설치 패키지의 공식 Expo plugin `android.nativeVariant` 설정으로 Vulkan을 적용하고 다시 빌드·표시 검증한다. SDK·AGP·Gradle 기준은 바꾸지 않는다.
- 현재는 테스트용 개발이므로 이 렌더러 선택을 배포용 전체 기기 호환성 검증으로 간주하지 않는다. 실제 휴대폰은 이후 확인한다.
- 위치 공급자는 기기의 GPS를 사용할 수 있도록 High 정확도를 요청하고, 별도 Google 위치 정확도 동의 창을 자동으로 띄우지 않도록 설정했다. 한 번 수신·15초 제한·구독 정리 정책은 유지한다.

## 2026-09-26T15:56:13+09:00 — 네이티브 재생성 명령 보완

- Vulkan 재빌드의 prebuild 단계가 Android Studio에서 열린 `android/` 폴더를 지우려다 `EBUSY`로 실패했다. 최초 빌드 로그에서도 기본 prebuild가 Android 폴더를 삭제·재생성했던 것을 확인했다.
- 현재 설치된 Expo CLI `prebuild --help`에서 `--no-clean` 옵션을 확인했다. 공유 `prebuild:android` 명령에 추가해 이후 네이티브 설정을 기존 폴더에 적용하고 IDE 로컬 설정·빌드 캐시를 보존한다.
- 다음 실행: 남은 생성 폴더 상태를 확인하고 `--no-clean`으로 재생성·빌드한다. 필요한 IDE 로컬 설정은 기존 복구 백업을 확인해 복원한다. 폴더 수동 삭제나 도구 기준 변경은 하지 않는다.
