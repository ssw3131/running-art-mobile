## 실행 전 계획

### 1. 유지할 내용

- 근거리 탐색: 실제 도보 합류 거리 **300m → 500m → 1km**
- 기존 광역 탐색 범위와 방식
- 점수 계산식과 화면의 `%` 표시
- 가까운 대표와 최고점 후보의 **5점 차이 비교**
- 최대 5개 추천과 도로 중복 제거
- API 버전·요청 및 응답 형식

### 2. 변경 전·후

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 근거리 탐색 중단 | 해당 범위에 유효 후보가 있으면 중단 | **50점 이상인 유효 후보가 있어야** 중단 |
| 다음 거리 단계 검토 | 유효 후보가 없을 때 | **50점 이상 후보가 없을 때** |
| 최종 추천 목록 | 30~40점대도 포함 가능 | 가까운 후보·먼 대안 모두 **50점 이상만 포함** |
| 후보 수 부족 | 낮은 점수도 포함 가능 | 기준 충족 후보만 표시 |
| 모든 후보 미달 | 낮은 점수 후보 표시 가능 | 결과 없음 및 조건 변경 안내 |

예: 300m 안에 40점 후보만 있으면 500m를 검토한다. 500m에서 55점 후보를 찾으면 근거리 확장을 멈춘다. 기존 광역 탐색은 그대로 수행한다.

### 3. 구현 내용

**근거리 탐색 중단 조건**

- 최소 점수를 공통 상수 `50`으로 정의한다.
- `engine.ts`의 기존 합류 거리 조건에 `score.raw >= 50`을 추가한다.
- 거리 단계·단계별 탐색량·경로 유효성 검사는 유지한다.
- 반올림 전 점수를 사용하므로 49.99점은 제외한다.

**최종 후보 선정**

- `nearby.ts`에서 50점 미만을 먼저 제외하고 기존 대표 선정·중복 제거·정렬을 수행한다.
- 기준을 통과한 후보끼리 기존 5점 비교를 적용한다. 차이가 5점 이하면 가까운 대표를 자동 선택하고, 초과하면 직접 비교하게 한다.
- 1km 초과·접근 거리 확인 불가 후보는 기존처럼 자동 선택하지 않는다.
- 가까운 적합 후보가 없으면 기존 광역 탐색에서 찾은 50점 이상 후보를 먼 대안으로 표시한다.
- 최대 5개까지 표시하되, 부족한 수를 낮은 점수 후보로 채우지 않는다.

**안내 문구**

- 확장 시: “300m 이내에서 유사도 기준을 만족하는 코스를 찾지 못해 500m까지 넓히고 있어요.”
- 먼 대안만 있을 때: “합류 1km 이내에 유사도 기준을 만족하는 코스가 없어 더 먼 대안을 표시했어요.”
- 모두 미달일 때: “유사도 50% 이상인 코스를 찾지 못했어요. 위치·거리·도형을 바꿔 보세요.”
- 도로 연결 확인 실패는 유사도 미달과 구분한다.

### 4. 검증 및 완료 기준

- **점수 경계:** 49.99점 제외, 50점 포함.
- **탐색 단계:** 미달 후보만 있으면 다음 단계로 이동하고, 적합 후보가 있으면 근거리 확장 중단.
- **최종 목록:** 먼 대안까지 미달 후보 제외, 최대 5개·중복 제거 유지.
- **기존 비교:** 차이 정확히 5점은 가까운 대표 선택, 5점 초과는 자동 선택 없음.
- **빈 결과:** 결과 없음 안내 및 기존 생성 횟수 미차감 확인.
- **통합:** 서버·기기 계산 결과 일치, 진행 표시·취소 정상 동작 확인.
- 고정 도로 표본으로 변경 전후 점수·합류 거리·후보 수·계산 시간을 비교한다.
