## 실행 전 계획

### 동작
- **시작 → 권한·현재 GPS 확인 → 러닝 기록 시작 → 사용자가 자유롭게 코스로 이동 → 합류 감지 → 코스 안내**로 변경한다.
- 최초 합류 경로를 계산하지 않는다. 합류 전에도 거리·시간·궤적을 기록하고 현재 위치와 저장된 코스를 표시한다.
- 코스 완주 진행률은 합류 후부터 계산한다. 합류 후 이탈하거나 미완주 러닝을 이어달릴 때는 기존 마지막 진행 지점까지의 복귀 안내를 유지한다.

### 구현 변경
- **준비 화면:** 코스가 정상적으로 로드되면 시작 버튼을 누를 수 있게 한다. GPS 미수신·만료나 경로 준비 여부로 버튼을 막지 않는다. 기존 안내창은 “코스까지 자유롭게 이동하세요. 합류하면 자동으로 안내를 시작해요.”로 바꾸고 확인을 즉시 허용한다.
- **시작 처리:** 준비 화면·시작 컨트롤러·저장소의 합류 경로 계산 및 필수 경로 검증을 제거한다. `RunPreparation`은 최신 GPS만 전달하도록 정리하고, 시작 관련 내부 함수에서도 합류 경로 인자를 제거한다. 권한 확인과 최신 GPS 조건인 **5초 이내·정확도 30m 이내**, GPS 확보 최대 15초·취소 처리는 유지한다. 실패하거나 취소하면 기록을 만들지 않는다.
- **합류 판정:** 기존 `approach → direction → lap` 상태를 재사용한다. 최초 합류 상태에서는 경로 요청을 발생시키지 않고, **코스 어느 지점이든 12m 이내에서 3초 유지**하면 기존 진행 방향 판정을 거쳐 안내한다. 교차 구간의 방향이 불명확하면 기존처럼 확정될 때까지 기다린다.
- **지도·안내:** 합류 전에는 이동 궤적 방향 우선·기기 방향 보조라는 기존 화면 방향 로직을 유지한다. 점선 합류 경로·회전 지시·합류 거리·경로 계산/재시도 문구는 표시하지 않는다. 대신 “코스에 합류하면 안내를 시작해요.”를 표시한다. 합류 후 코스 방향 추적, 지도 둘러보기·현재 위치 복귀·터치 잠금은 유지한다.
- **불필요한 사전 계산:** 추천 화면에서 실제 현재 GPS를 기준으로 실행하던 러닝용 합류 경로 선계산을 제거한다. 추천에 사용하는 선택 출발지 기준 접근 거리와 가까운 코스 선정은 유지한다.
- **복원 호환:** 기존 v2 기록의 최초 합류 상태에 남은 경로·오류는 실행 상태 복원 시 무시한다. `return` 상태의 복귀 경로·진행 지점은 유지하고 늦게 도착한 최초 합류 경로 응답은 반영하지 않는다. DB·서버 API·저장 코스 형식 변경 없이 적용하며 기존 v1 복원도 유지한다.

### 검증
- 유효한 GPS가 있으면 코스 밖·도로 자료 없음·오프라인에서도 시작할 수 있고, **준비 화면부터 최초 합류까지 러닝용 경로 계산 호출이 0회**인지 확인한다.
- GPS 대기·만료·부정확한 위치·권한 거부·시작 취소·중복 누르기를 검사한다. 버튼 검사는 준비 상태를 고정한 모의 값에 의존하지 않도록 보완한다.
- 코스 중간 합류, 양방향 출발, 순간적인 근접 통과, GPS 흔들림·공백, 교차 구간에서의 합류·방향 판정을 확인한다.
- 합류 전 거리·시간·궤적은 기록되지만 완주 진행률은 증가하지 않는지 확인한다. 합류 후 이탈·이어달리기·기존 기록 복원·시뮬레이션도 회귀 검사한다.
- 합류 전후 위치 표시·화면 방향·안내 문구와 지도 조작을 검증한다. 경로 계산 없이 합류와 코스 진행으로 전환되는 기존 엔진 동작은 메모리 내 GPS 입력으로 사전 확인했다.
