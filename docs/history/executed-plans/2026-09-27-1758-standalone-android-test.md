## 실행 전 계획

1. 연결된 SM-S942N과 기존 앱·소스 상태를 확인한다. 기존 개발 APK와 앱 데이터를 보존하고 같은 앱 ID·테스트 서명으로 업데이트한다.
2. 현재 소스와 지도 설정을 포함한 arm64 릴리스 방식 APK를 로컬 빌드한다. 개발 서버에서 JS를 받는 기존 성능 모드와 구분한다. 스토어 배포·서명키 변경·CI/CD는 수행하지 않는다.
3. APK 서명·패키지·내장 JS·개발 가능 플래그를 검사하고 휴대폰에 설치한다. 앱을 다시 열고 USB의 Metro 연결을 제거한 상태에서 실행·지도를 확인한다.
4. 서울 고정 OSM·하트·5km 계산의 원본 전체 결과, 시간·입력·취소·재시작을 확인한다. 가능하면 반복 측정하고 설치 성공과 실제 실행 성공을 구분한다.
5. 내부 테스트 APK 위치, 재설치/빌드 방법, 검증 결과·미검증과 현재 상태를 갱신한다. 지도 인터넷 연결은 유지하며 PC 개발 서버 의존성만 배제한다.

## 실행 결과·검증

현재 소스로 arm64 릴리스 APK를 빌드하고, 연결된 SM-S942N·Android 16에 업데이트 설치했다. 계산 알고리즘·앱 기능·의존성·서명 설정은 변경하지 않았다. 기존 사용자 변경도 보존했다.

### 빌드와 APK 확인

프로젝트 `scripts/env.ps1`의 Node 24·JDK 17·SDK를 적용하고 `NODE_ENV=production`으로 `android/`에서 `gradlew.bat assembleRelease --max-workers=2 -PreactNativeArchitectures=arm64-v8a`를 실행했다. **BUILD SUCCESSFUL, 14분 36초, 869개 작업(801 실행·68 최신 상태)**였다. 기존 의존성의 deprecated API·Gradle 경고가 있었으나 오류는 없었다. 최초 전체 `assembleRelease`는 라이브러리 조립도 포함했다. 재현 안내에는 앱을 대상으로 한 `:app:assembleRelease`를 제공한다.

- APK: `android/app/build/outputs/apk/release/app-release.apk`
- 크기: 58,479,307바이트 (약 58.5MB)
- SHA-256: `7f9254d4eb44d0ea197e44594909e13a56f41f52f03400d268e24a7bf1545949`
- 패키지: `com.runningart.mobile.dev`, versionName `0.1.0`, versionCode `1`, arm64-v8a 전용
- `apksigner verify` 통과. 기존 설치 APK와 인증서 SHA-256이 같음.
- `aapt`에서 디버그 가능 플래그 없음. 내장 Hermes 바이트코드 헤더 및 번들 3,923,240바이트 확인.

기존 설치 APK를 `.cache/standalone-qa/installed-debug-before.apk`로 보존했다. 18:15:26에 `adb install -r --no-streaming`으로 업데이트했고 앱을 삭제하거나 데이터를 초기화하지 않았다. 설치 전후 데이터 디렉터리 식별자도 같았다. 테스트 서명을 쓰는 release variant이며 스토어 배포를 진행하지 않았다.

### 휴대폰 실제 검증

휴대폰의 Metro `tcp:8081` 전달을 제거한 뒤 앱을 강제 종료·새로 실행했다. 개발 서버 연결 없이 홈·서울 지도·내장 도로 계산이 동작했다. USB는 화면 관측/입력에 사용했고 지도 인터넷 연결은 유지했다. 종료 시 포트 전달 0개, 앱 프로세스 유지, 해당 프로세스 crash buffer의 치명적 오류 0개였다.

같은 서울 OSM·광화문·하트·목표 5km·반경 2km에서 **24.832 / 23.752 / 27.961초**, 중앙값 **24.832초**였다. 세 번 모두 추천 5개·전체 경로·점수·거리·통계가 원본과 허용 오차 1e-6 이내로 일치했다. 최적화된 엔진 진단 수치도 이전 실행과 같았다. 2회차 계산 중 반응 확인 횟수 1, 별도 계산 21.7초 시점의 취소, 취소 후 3회차 재실행을 확인했다.

앱 전체 PSS는 계산 전 322,941 KiB, 반복 후 408,671 KiB였다. 순간 관측이며 엔진 전용 메모리·최대치·누수 판단과 구분한다. 앞선 개발 모드 58.435초·개발 APK + 배포용 JS 44.265초와 이번 릴리스 APK를 구분하며, 열·부하를 통제한 개선율로 해석하지 않는다.

기존 알고리즘·앱 소스를 바꾸지 않은 패키징 작업으로, 이번 검증은 릴리스 빌드·서명/자산 검사와 실기기 실행에 집중했다. 이전 58개 자동 테스트 통과와 이번 기기 검증을 구분해 보고했다. 상세 시간·메모리·증거는 [코스 계산 검증](../../quality/route-engine-verification.md)에 기록했다. 문서 링크·`git diff --check`도 통과했다.

### 문서·종료 상태·남은 범위

[독립 실행 테스트 APK 안내](../../development/android-test-apk.md)를 추가하고 README·문서 목차·Windows CLI 안내·현재 상태·코스 계산/성능 설명·로드맵·검증 기록·실행 목록을 갱신했다. APK 파일과 빌드 로그·기기 증거는 Git 제외 경로에 보관한다. 커밋·푸시·CI/CD·스토어 공개는 수행하지 않았다.

휴대폰은 릴리스 APK의 마지막 결과 화면을 유지했다. 에뮬레이터는 기존 개발 APK이며 Metro 8081도 유지했다. 휴대폰에서 개발 작업으로 돌아갈 때는 기존 테스트 서명의 개발 APK를 다시 설치하고 Metro에 연결한다.

이번 릴리스 APK에서 GPS 권한·저장소 CRUD·야외 GPS/배터리·다른 폰·iOS·장시간 메모리까지 새로 검증한 것은 아니다. 테스트 앱의 기능 범위는 그대로이며, 주변 도로 다운로드·실제 코스/러닝 저장은 후속 단계다.
