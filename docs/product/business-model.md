# 현재 비즈니스 모델과 변경 관리

**2026-10-24 확정 변경:** 무료 생성은 성공한 계산 5회, 저장은 누적 15회다. 삭제해도 횟수는 복구되지 않고 자동 충전은 없다. DB 정책에서 총량을 변경할 수 있고 기존 회원의 사용량은 유지한다. 상단/보관함은 사용/총량을 표시한다. 결제·가격표는 구현하지 않으며 소진 시 ‘추가 이용권 구매는 준비 중입니다’를 안내한다. 아래 10-11 상품/보관 공간 표는 검토 이력이며 이번 무료 횟수 계약보다 우선하지 않는다. [구현 계약과 운영 절차](../development/archive-usage-20261024.md).

아래는 **2026-10-11 당시 검토 이력**이다. 사용자가 제공한 [원본 표](assets/business-model-20261011.png)와 “계속 바뀔 수 있어”라는 조건을 보존한다. 현재 무료 정책은 위 2026-10-24 결정과 구현 계약을 따른다. 유료 팩의 가격·지급·환불 규칙은 후속 검토이며 판매 중인 상품이 아니다.

## 이전 상품 검토안 — 2026-10-11

| 상품 | 가격 | 추가 생성 횟수 | 구매 후 보관함 한도 |
| --- | --- | --- | --- |
| 무료 회원 | 무료 | 가입 시 5회 | 3개 |
| 기본 팩 | 1,900원 | 10회 | 5개 |
| 플러스 팩 | 4,900원 | 30회 | 15개 |
| 확장 팩 | 6,900원 | 50회 | 30개 |

- 생성 횟수는 **추가 지급량**이다. 기본 팩의 10회는 이전 잔여 횟수를 10회로 덮는다는 뜻이 아니다.
- 보관함 수치는 **구매 후 한도**다. 무료 3개에 기본 팩 5개를 더해 8개로 계산하지 않는다.
- 기본→플러스 구매 후 한도 표기는 15개다. 같은 상품 재구매·확장 사용자의 기본 팩 구매처럼 기존 한도가 더 크거나 같은 경우는 별도 규칙이 필요하다. 표만으로 하향 또는 누적을 결정하지 않는다.
- 매일 무료 충전·월 구독·무제한 제공은 **현재 표에 없다**. 과거 안을 자동 적용하지 않는다.
- 가격과 혜택은 변경 가능하다. 변경할 때 기존 구매자의 획득 권리/잔여 횟수를 새 상품 수치로 일괄 재계산하지 않는다.

아래는 10-11 시점에 정리한 미정 항목이다. B-02~B-05와 B-07의 무료 정책 부분은 10-24 구현 계약에서 확정했다. 유료 상품의 재구매·지급·유효기간·환불은 해당 기능을 구현할 때 결정한다.

| --- | --- | --- |

| B-02 | 생성 1회의 성공 기준, 후보 0개/일부만 생성, 취소, 타임아웃, 서버→기기 전환, 재시도 시 차감/복구 | S2 표시 계약·S7 차감 |

미정 상태에서 기본값을 임의로 적용해 기존 사용자의 자료를 삭제하거나 유료 권리를 바꾸지 않는다. 실서비스 결제 검증/정책 적합성 확인은 S7의 별도 작업이며, 이 분석은 법률·스토어 정책 검토 완료를 뜻하지 않는다.

## 이전 유료 상품 설계안

- `ProductCatalog`: 상품 ID, 표시명, 정책 버전, 추가 생성량, 보관함 한도, 판매 상태. 위 표는 기획 기준이고 실제 판매 가격·통화 표시는 연결된 스토어 상품 정보와 대조한다.
- `Entitlement`: 계정에 실제 적용된 생성 잔량·보관함 한도. 화면 컴포넌트가 숫자를 따로 소유하지 않는다.
- `PurchaseLedger`: 검증된 거래 ID, 상품/정책 버전, 당시 지급 혜택, 적용/환불 상태. 동일 거래 재전달을 중복 지급하지 않는다.
- `GenerationUsage`: 생성 작업 ID와 예약/확정/복구 상태. 하나의 작업이 서버 실패 후 기기에서 재시도되어도 중복 차감되지 않도록 설계한다.
- 상품 카탈로그, 생성 차감 규칙, 저장 한도 판단을 각각 분리한다. 화면은 결과를 표시하고 명령을 요청한다.
- 상품 변경은 새 버전을 추가하고 과거 거래 스냅샷은 보존한다. 온라인 권한 판단은 서버를 기준으로 설계하고 앱 캐시는 표시/오프라인 계약 범위만 담당한다.
- 기존 공개 계산 API의 운영 한도는 이 모델과 별개다. 사용자별 결제 한도를 강제하려면 인증·작업 식별·오프라인 규칙을 함께 설계해야 하며 프런트엔드 숫자만으로 막지 않는다.

위 유료 상품 타입명/저장소는 당시 제안이다. 현재 무료 사용량 정책·원장·인증 계산은 [10-24 구현 계약](../development/archive-usage-20261024.md)에 따라 운영 반영했다. [S7 개발 단위](../planning/service-implementation.md)는 후속 결제 계약과 데이터 이행을 구체화할 때 참고한다.
