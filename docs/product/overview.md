# RunPen 실서비스 기획과 제품 결정

갱신일: 2026-10-03 (Asia/Seoul)

## 현재 기준과 결정 이력

**서비스명은 RunPen이며 저장소·기술 프로젝트명은 Running Art / running-art-mobile을 유지한다.** 현재 모바일 앱을 실서비스로 이어 개발한다. 별도의 개발용·배포용 앱을 만들지 않는다. 서버 환경 분리 여부는 후속 결정이며, 이 문서 수정으로 앱 ID·서명·DB·클라우드 설정을 바꾸지 않는다.

2026-10-03 사용자 제공 [Figma UI 페이지](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=0-1)를 서비스 화면·기능의 기준으로 삼는다. **UI 페이지 우선 → prototype 보조 → 보관함 과거 시안** 순서다. component 페이지의 로고·도형·배지·아이콘은 디자인 자산 참고다. 기존 Google AI Studio 프로토타입은 기능 참고로 남기고, Codex v0.2 계산 알고리즘 기준은 유지한다.

Figma 전체 기능을 목표로 **단계적으로 완성**한다. 모든 기능을 최초 출시 필수로 확정하지 않는다. 현재 구현·검증 사실은 [현재 상태](../handoff/status.md), 후속 순서는 [로드맵](../planning/roadmap.md)을 따른다.

## 제품 목표와 정보 구조

사용자의 위치 주변에서 원하는 그림을 닮은 실제 보행 코스를 만들고, 달린 GPS 궤적을 기록·배지·공유 이미지로 남기는 서비스다. 전국 사용자 위치를 대상으로 Android부터 개발·검증하고 이후 iOS로 확장한다.

핵심 흐름은 **로그인·가입 → 홈 → 출발 위치·거리·도형 설정 → 후보 비교·코스 선택 → 러닝 → 기록·배지 확인 → 외부 공유·재도전**이다. 하단은 **홈 / 코스 생성 / 실시간 러닝 / 기록 보관함 / 마이페이지**의 5개 탭으로 구성하며 서비스 안내는 상단 메뉴에서 접근한다. 시뮬레이션은 실제 GPS 러닝과 구분한다.

다음 내용은 Figma에서 확인한 서비스 목표이며, 예시 거리·시간·유사도·배지 수치가 확정 계산식이나 운영 규칙을 뜻하지 않는다. 미정 사항은 구현에 앞서 별도로 확정한다.

## 화면별 기획과 현재 구현의 차이

### 1. 가입·로그인

- **출처:** [로그인 UI](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=10-1130), [회원가입 UI](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=10-1907).
- **흐름:** 카카오·네이버·Google로 계속하기 또는 가입 → 제공자 인증 → 앱 복귀·계정 연결. UI 페이지를 우선하므로 이메일 로그인·이메일 가입·아이디 찾기·비밀번호 찾기/재설정은 현재 목표에서 제외한다. UI에 남은 빈 이메일 오류 제목도 구현 요구로 해석하지 않는다.
- **현재:** Google 로그인·브라우저 복귀·계정 표시·세션 저장/갱신·로그아웃은 실제 휴대폰 검증 완료다. 개인 자료 소유권·동기화는 후속 실제 구현·서버 적용·휴대폰 검증을 완료했다. [검증 범위](../quality/personal-sync-verification.md)를 따른다.
- **추가 개발:** 서비스 가입/로그인 화면, 카카오·네이버 연결, 신규 가입과 기존 계정의 흐름, 동의·프로필 연계.
- **미정:** 비로그인 이용 범위, 필수 동의 시점·문구, 다른 제공자 계정 통합, 닉네임 정책. Google 검증 완료가 세 제공자 전체의 완료를 의미하지 않는다.

### 2. 홈

- **출처:** [UI 페이지의 홈화면 보드](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=0-1).
- **흐름:** 첫 방문자는 추천 도형을 선택해 코스 설정으로 이동한다. 미완료 코스가 있으면 진행률·달린 거리와 이어달리기를 보여준다. 반복 이용자는 최근 러닝·연속 러닝·누적 거리·최근 코스·추천 코스를 확인하고 생성으로 이동한다.
- **현재:** 기능 테스트 진입용 홈과 개별 코스·러닝 화면이 있다. 세 가지 서비스 홈과 추천·통계는 미구현이다.
- **추가 개발:** 이용 상태별 홈, 미완료 코스 연결, 최근 코스·통계 집계, 추천 진입.
- **미정:** 홈 상태의 우선순위, 미완료 코스의 보관·재개 기준, 연속 러닝 산정, 추천 기준. 기존 프로세스 중단 복원과 여러 날에 걸친 이어달리기를 같은 기능으로 간주하지 않는다.

### 3. 코스 생성

- **출처:** [코스탐색 UI](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=10-2350)의 조건 설정·추천 코스 화면.
- **흐름:** 현재 위치 또는 장소 검색으로 출발 위치 지정 → 지도 확인 → 목표 거리·코스 모양 선택 → 추천 생성 → 후보별 유사도·거리·예상 시간·난이도 비교 → 선택 후 러닝. 내장 도형 외에 직접 그리기와 도형 이미지 업로드 진입이 있다. 추천 화면은 지도와 스크롤 가능한 후보 목록, 도형 원형 표시를 제공한다.
- **현재:** 전국 도로 공급·영구 캐시·v0.2 계산·후보 지도·선택·취소 기반이 있다. 서비스용 직접 그리기·이미지 입력·장소 검색·난이도 표시는 미구현이다.
- **추가 개발:** 서비스 조건/결과 화면, 도형 입력과 변환, 장소 검색, 후보 비교·원형 표시, 실제 데이터에 근거한 예상 시간·난이도 표시.
- **미정:** 지원 도형 목록, 이미지 형식·추출 방식, 거리·탐색 범위, 후보 개수, 유사도 표시 방식, 예상 시간·난이도 산식, 후보 없음의 안내. 시안의 후보 5개나 예시 비율을 엔진 계약으로 고정하지 않는다.

### 4. 코스 상세

- **출처:** [코스탐색 UI](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=10-2350)의 코스 상세 및 [기록 보관함 UI](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=35-4723)의 도전 코스 상세.
- **흐름:** 경로 지도 → 이름·출발지·거리·예상 시간·난이도·참고 사항 확인 → 이름 변경·GPX 내보내기 또는 러닝 도전. 보관된 코스는 삭제와 다시 도전으로 이어진다.
- **현재:** 코스 기기 저장·목록·상세·이름 변경·삭제·오프라인 복원·GPX 전달은 휴대폰까지 검증했다. 코스 시뮬레이션은 PC·에뮬레이터 검증 완료다.
- **추가 개발:** 서비스 상세 화면, 생성 결과와 도전 코스의 연결, 출발지·난이도·참고 정보, 러닝 시작 연계. 기존 시뮬레이션은 재사용 가능한 기능으로 보존하되 서비스 노출 위치는 별도 결정한다.
- **미정:** 선택한 후보의 저장 시점, 도전 상태 전환, GPX 버튼 활성 조건, 시뮬레이션 노출 위치.

### 5. 실시간 러닝

- **출처:** [실시간 러닝 UI](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=24-3817)의 지도·집중 정상/이탈·설정 화면.
- **흐름:** 코스를 따라 달리며 이동 거리·남은 거리·러닝 시간·페이스와 다음 방향을 확인한다. 지도 모드와 집중 모드를 전환하고, 경로 이탈 시 복귀 안내를 표시한다. 일시정지·재개·종료와 러닝 중 지도 테마·음성 피드백·화면 잠금 설정을 제공한다.
- **현재:** GPS 시작·일시정지·재개·종료, 거리·활동 시간·평균 페이스, 백그라운드 수신·로컬 기록·중단 복원 기반이 있다. 방향 안내·경로 이탈·음성·집중 모드는 미구현이다. 장시간 잠금·배터리·실제 거리 오차는 미검증 범위가 남아 있다.
- **추가 개발:** 선택 코스와 GPS 진행 상태의 연결, 방향·이탈 안내, 집중 모드, 음성 안내, 러닝 설정과 완료 흐름.
- **미정:** 코스 매칭·이탈·복귀·완주 판정, 안내 간격, 잠금 동작, 재개 위치 처리, 칼로리 산정. 지도에 보이는 경사·고도 등이 실제 공급 데이터에 있는지도 개발 전 확인한다.

### 6. 기록·성취

- **출처:** [기록 보관함 UI](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=35-4723), [완주·배지 UI](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=24-3817), [마이페이지 UI](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=35-5943).
- **흐름:** 도전 코스와 완주 기록을 탭으로 구분 → 목록·상세 → 삭제·재도전. 완주 시 축하 화면·배지를 보여주고 마이페이지에서 누적 거리·완주 수·총 러닝 시간과 배지를 확인한다.
- **현재:** 저장 코스와 GPS 러닝 기록의 목록·상세·삭제는 각각 있다. 서비스의 도전/완주 분류, 배지·누적 통계·재도전 연결은 미구현이다. 개인 자료 동기화·복원 기반은 검증 완료이며 서비스의 도전/완주 관계와는 구분한다.
- **추가 개발:** 코스와 러닝의 관계·진행 상태 정리, 완주 기록 화면, 배지 획득·모음, 통계와 재도전.
- **미정:** 완주 인정 기준, 배지 기준·중복 획득, 연속/누적 통계의 기간, 코스 삭제와 연결 기록의 관계. 누적 완주·난이도별 완주·도형 유사도·누적 거리 배지 시안의 수치는 정책 확정 전 참고값이다.

### 7. 외부 공유

- **출처:** [실시간 러닝 보드의 공유 화면](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=24-3817)과 UI 페이지의 공유 규격 주석.
- **흐름:** 완주 → 경로·기록·배지가 담긴 결과 이미지 → 이미지 저장 또는 외부 앱 공유. 스토리 1080×1920(9:16), 피드 1080×1350(4:5)를 목표로 하며 정사각형 1080×1080(1:1)은 선택안이다.
- **현재:** GPX 파일 공유는 구현했다. 완주 결과 이미지 생성·저장·공유는 미구현이다.
- **추가 개발:** 공유 카드 생성·규격별 배치·저장·모바일 공유 흐름. Figma의 Instagram·카카오 등의 아이콘이 각 서비스에 직접 게시하는 API 구현을 뜻하지는 않는다.
- **미정:** 공유 규격 선택, 개인정보·출발/도착 위치 표시 범위, 공유 문구, 워터마크와 외부 앱별 지원. 커뮤니티 피드·댓글·좋아요는 이 범위와 분리한 후속 확장이다.

### 8. 마이페이지·서비스 안내

- **출처:** [마이페이지 UI](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=35-5943), [메뉴·안내 UI](https://www.figma.com/design/QYRGII8OdvQB1SrtH3BA08?node-id=36-6572).
- **흐름:** 프로필·연결 계정·통계·배지 확인 → 프로필 편집, 테마·음성·위치 권한 관리, 로그아웃 확인·회원 탈퇴. 상단 메뉴에서 서비스 소개·이용 방법·FAQ·문의/의견·공지 목록/상세·이용약관·개인정보처리방침·위치정보 이용약관으로 이동한다.
- **현재:** Google 계정 표시·로그아웃 및 개별 위치 권한 처리 기반은 있다. 서비스 마이페이지·프로필 편집·탈퇴·안내/운영 화면은 미구현이다.
- **추가 개발:** 프로필·설정 저장, OS 권한 상태와 화면 연결, 계정 탈퇴·자료 삭제, 안내 콘텐츠와 문의/공지 운영 기능.
- **미정:** 프로필 이미지·닉네임 규칙, 테마 기본값, 탈퇴 시 삭제/보관 범위, 문의 전달·응답 채널, 공지 관리, 약관 내용과 동의 이력. Figma의 약관 문구는 확정 운영 약관으로 선언하지 않는다.

## 과금 정책 — 검토 중, 미확정

출처는 2026-10-03 사용자가 제공한 “2. 기본 상품 구조” 이미지다. 사용자는 **고민 중이며 확정이 아님**을 명시했다. [원본 이미지](assets/billing-policy-draft-20261003.png)를 보존한다. 기존 초기 무료 제공 방침과 구분되는 변경 검토안으로 기록하며, 결제·구독·생성 승인·차감·저장 제한을 이번 작업에서 구현하지 않는다.

| 항목 | 이미지에 제시된 검토안 | 미확정 해석 |
| --- | --- | --- |
| 무료 체험 | 최초 생성 요청 5회, 코스 저장 3개까지 | 생성 요청과 성공의 차감 기준, 계정/기기 기준 |
| 무료 횟수 갱신 | 매일 자동 충전, 가입일 기준 1일이 지나면 갱신 | 매일 충전량·누적/상한·정확한 시점·시간대. 매일 5회라고 확정하지 않음 |
| 유료 상품 | 추가 생성 이용권, 추후 고민 | 판매 여부·구성·유효기간·소진 순서 |
| 유료 가격·제공 횟수 | 사용성과 생성 비용 검증 후 확정 | 단가·횟수 미정 |
| 월·연 구독 | 월 2,900원으로 무제한 생성 | 월 금액도 검토안이며 연간 요금·할인은 제시되지 않음 |
| 도형 제한 | 없음 | 전체 과금안과 함께 검토 중 |
| 저장 개수에 따른 과금 | 무료 코스 저장 3개, 구독 무제한 | 구독 종료 후 초과 자료의 보관·열람·수정·신규 저장 처리 |

실패·취소의 차감/복구, 오프라인·복수 기기의 횟수 처리, 구독 종료 후 정책, 연간 요금, 실제 도입 여부·시점은 미정이다. 무제한의 운영 조건·악용 대응도 확정하지 않는다. 로컬 계산을 유지하면서 서버에서 어떤 이용 권한을 검증할지는 과금안 확정 후 검토한다. 기존 자료를 소급 삭제하거나 제한하지 않는다.

## 유지하는 기술·운영 경계

- React Native·Expo·TypeScript·Expo Router, Android 우선 방향과 MapLibre React Native·MapTiler를 유지한다.
- Codex v0.2 계산은 휴대폰 내부 모듈에서 수행한다. 루트 v0.3, 생성형 AI 호출·독립 계산 서버로 전환하지 않는다.
- 전국 OSM 파일은 모바일 전용 R2에서 공급하고 SQLite 영구 캐시를 사용한다. 지도 타일과 계산용 도로 그래프를 분리하며 OSM ID·연결성을 보존한다.
- SQLite 로컬 우선 저장과 Supabase 회원·개인 자료 기반을 이어간다. 개인 GPS 원본과 외부 공개 자료는 접근 범위를 구분한다.
- 두 형제 웹 프로젝트는 참고 자료다. 모바일 실행·서버·가공·배포는 독립하며 기존 테스트 서버 복구를 재개하지 않는다.
- 단일 앱은 기존 설치와 자료를 이어가는 방향이다. 현재 앱 ID의 `.dev` 문자열 제거, 서명 교체, 앱 재설치·데이터 이전은 이번 결정만으로 실행하지 않는다. 개발 도구의 빌드 방식과 별도 서비스 앱의 운영을 구분한다.
- CI/CD는 실행 보류다. 커뮤니티·과금은 후속이며 Gemini 코칭·생성형 AI 일러스트는 현재 범위에서 제외한다. 이미지에서 도형 입력을 받는 요구가 생성형 AI 사용 결정을 뜻하지 않는다.
