# 프로젝트 목표와 최종 결정

## 목표와 사용자 흐름

2026-09-26 사용자 결정: **현재는 핵심 기능 테스트용 앱을 개발합니다.** 실제 서비스 기획·디자인은 이후 사용자에게 전달받아 반영합니다. 아래는 기술 검증을 위한 기능 방향이며, 현재 화면·문구·정보 구조를 최종 서비스 기획으로 확정하지 않습니다.

Running Art는 사용자의 현재 위치 주변에서 도형을 닮은 실제 보행 코스를 찾고, 이를 달린 GPS 궤적과 운동 기록을 남기는 앱입니다. 서울 한정이 아닌 전국 사용자 위치를 기준으로 설계합니다.

**출발 위치·목표 거리 설정 → 도형 선택·직접 그리기 → 주변 도로에 맞는 후보 계산 → 코스 선택 → 실제 러닝 → 기록 저장·확인**이 핵심 흐름입니다. 시뮬레이션은 실제 러닝과 구분합니다.

Android를 먼저 개발·현장 검증·배포하고 이후 iOS로 확장합니다. 웹 프론트 경험을 활용하며 Codex·Claude 등을 개발 도구로 사용할 수 있습니다.

## 결정과 이유

| 결정 | 이유와 의미 |
| --- | --- |
| React Native + Expo + TypeScript + Expo Router | React 경험을 활용하고 Android부터 시작해 iOS에서도 로직·화면을 공유하기 위함입니다. |
| AI Studio 기능을 기준으로 새 모바일 앱 구현 | 기능·흐름은 살리되 DOM, Leaflet, Canvas, 브라우저 GPS·저장소를 네이티브 지도·권한·백그라운드 위치·저장으로 바꿔야 합니다. 단순 웹 포장으로 끝내지 않습니다. |
| AI Studio 사용은 필수가 아님 | 기능 기준은 이미 확보했으며 개발 도구와 앱 실행 플랫폼은 별개입니다. |
| Codex 루트 v0.3 알고리즘 재사용 | 알고리즘을 재시험·고도화한 결과를 가져옵니다. Codex UI 전체를 기능 기준으로 삼지 않습니다. |
| 알고리즘은 앱 내부 모듈, 계산은 휴대폰 | 코스 조회마다 생성형 AI나 독립 계산 서버를 호출하지 않습니다. 모듈 분리는 서버 분리를 의미하지 않습니다. |
| MapLibre React Native + MapTiler | 기존 지도 방향을 유지하며 화면 표시와 경로 계산용 보행 그래프를 분리합니다. |
| Geofabrik OSM을 지역별 파일로 전처리·정적 배포 | 주변 데이터만 내려받아 캐시하며 공개 Overpass의 실시간 가용성에 의존하지 않습니다. |
| OSM 노드 ID·연결 관계 보존 | 가까워 보이는 서로 다른 도로·교량·터널을 잘못 연결하지 않기 위함입니다. |
| Expo development build | 네이티브 지도·백그라운드 기능과 실제 앱 권한·실행 환경을 검증합니다. |
| Expo Location·TaskManager·SQLite | 모바일 위치 추적과 휴대폰 내부 기록 저장을 위한 예정 구성입니다. |
| CI/CD는 별도 계획 보관 | 자동화 방향은 정했으나 추후 실행하기로 했으므로 현재 구축하지 않습니다. |

## 기능 범위

| 기능 | 모바일 방향 |
| --- | --- |
| 내장 도형·직접 그리기 | AI Studio 흐름을 네이티브 화면으로 구현 |
| 후보 코스·지도·선택 | v0.3 결과를 지도 폴리라인과 상세 정보로 변환 |
| 러닝·일시정지·재개·종료 | 네이티브 위치·권한 처리, 실기기 화면 잠금 검증 |
| 시뮬레이션 | 실제 GPS 기록과 구분한 미리 보기 |
| 보관함·러닝 기록 | 우선 휴대폰 내부 SQLite 저장 |
| GPX 내보내기 | 모바일 파일·공유 흐름으로 이식, 외부 앱 지원은 확인 후 안내 |

현재 구현·검증 상태는 [인수인계](../handoff/status.md)를 기준으로 확인합니다. 위 표 전체가 구현 완료되었다는 의미는 아닙니다.

Gemini 코칭·생성형 AI 일러스트, 독립 경로 계산 서버는 현재 범위에서 제외합니다. 로그인·과금·동기화·운영·피드백 수집 정책은 지금 확정하지 않습니다. 이미지 업로드 등 부가 입력은 핵심 이식 후 범위를 정합니다.

경로 계산 자체에 생성형 AI API 비용은 들지 않습니다. 지도 타일·데이터 전송·개발 도구·스토어까지 무료라는 뜻은 아닙니다. 실제 계정·요금제는 연결할 단계에서 확인합니다.
