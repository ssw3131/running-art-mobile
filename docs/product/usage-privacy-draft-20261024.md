# 무료 이용 횟수·탈퇴 안내 변경 초안 — 미게시

이 초안은 제품 결정에 따른 문안 준비다. 시행일·운영자 정보·최종 법률 검토 및 게시 승인을 대신하지 않는다. 기존 게시 정책을 변경하지 않았다.

## 무료 이용 안내

코스 생성은 성공한 계산 결과 묶음당 1회, 코스 저장은 새로운 코스 저장당 1회를 사용합니다. 무료 제공 횟수는 앱에 표시된 현재 총량을 따릅니다. 코스를 삭제해도 이미 사용한 저장 횟수는 복구되지 않으며 자동 충전되지 않습니다. 기존 코스를 달리거나 러닝 기록을 저장하는 데에는 생성·저장 횟수를 사용하지 않습니다. 추가 이용권 구매는 준비 중입니다.

## 탈퇴 전 안내

탈퇴하면 기존 절차에 따라 계정과 서버의 프로필·코스·러닝 위치 자료를 삭제합니다. 기기 자료 보존 선택은 기존 탈퇴 화면 안내를 따릅니다. 무료 혜택 중복 제공 방지를 위해 소셜 로그인 제공자와 계정 고유값을 비밀키로 변환한 식별값 및 누적 이용 횟수는 무료 혜택 정책 운영 기간 동안 별도로 보관합니다. 같은 소셜 계정으로 다시 가입해도 사용한 횟수가 초기화되지 않습니다.

## 개인정보 처리방침 추가 항목

| 항목 | 내용 |
| --- | --- |
| 목적 | 무료 혜택 횟수 관리, 중복 제공 및 재가입 초기화 방지 |
| 보관 정보 | 서버 비밀키로 HMAC 처리한 제공자별 계정 식별값, 누적 생성·저장 사용량 |
| 별도 보관하지 않는 원문 | 이메일, 소셜 계정 원본 고유 ID, 탈퇴한 회원의 프로필·코스·GPS |
| 기간 | 무료 혜택 정책 운영 기간. 무료 총량 변경만으로 기간이 종료되지 않음 |
| 파기 | 정책 종료 후 사용 원장과 연결 정보 및 식별값·누적 사용량 삭제 |
| 접근 | 권한을 부여받은 서버/관리자만 접근. 회원의 원장 직접 수정 불가 |

HMAC 값도 같은 주체의 사용량을 연결할 수 있는 가명 식별정보로 취급합니다. 운영자는 최종 법적 근거·권리 행사 절차·실제 시행일을 기존 정책과 대조한 후 게시해야 합니다.
