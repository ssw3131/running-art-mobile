## 확정된 제품 수치와 운영 정보

- 가입 최초 생성 5회·저장 10회. 월별 무료 추가·초기화 없음. 기존 사용량·추가 지급분 보존.
- 기본 1,900원/생성 10회/저장 20회, 플러스 2,900원/30회/**60회**, 확장 4,900원/60회/120회. 실제 결제는 아직 준비 중.
- 운영자·공개 주소·고객지원 이메일·책임자는 [10월 24일 사용자 확정 정보](../policies-draft-20261024/README.md)를 재사용했다. 확인되지 않은 전화번호·사업자번호·운영 시간은 만들지 않았다.

## 후속 실행 순서

1. 운영 조건을 결정하고 실제 공급자·보관 설정을 대조한다. 기획·법률 검토 결과를 ID별로 날짜와 함께 남긴다.
2. 결제는 구매 검증·지급·복원·환불·구매별 사용량 설계를 별도 구현한다. 이번 화면의 준비 상태를 실제 성공으로 전환하지 않는다.
3. 정책 문안과 위치약관·가입 동의문을 함께 대조하고 버전을 부여한다. 기존 시험 정책을 덮어쓰지 않는다.
4. 별도 게시 작업에서 열람·동의·권리 행사·문의·탈퇴를 검증한다. 이 문서 변경으로 운영 게시·동의를 실행하지 않는다.
