# RunPen 개인정보처리방침 개정 초안

> 정책 회신 전 구현을 대조한 초안 본문을 보존한 문서다. 이후 고도 조회 제거·테스트 구매 검증 기반 등이 반영됐으므로 현재 처리 범위는 [데이터 흐름](../policy-dataflows-20261122.md)·[구현 현황](../policy-implementation-20261122.md), 정책 기준은 [확정 회신](../policy-decision-reply-20261122.md)을 따른다. 실제 계약·보존 설정·법률 확인과 고객 대상 최종 문안·게시는 미완료다. [통합 안내](README.md).

작성일: 2026-11-22. **검토용·미게시. 공고일·시행일 미정.** 아래는 코드에서 확인한 처리 사실을 바탕으로 한 초안이다. 처리의 법적 근거, 공급자 계약과 보유 기간 등은 [결정표](decisions.md)에 따라 확정한 후 게시한다.

## 1. 운영자와 목적

알로하랩은 계정 인증, 코스 생성·보관, GPS 러닝 기록·안내, 선택 동기화·공유, 이용량 관리와 문의 처리를 위해 정보를 처리한다. 서비스 전체가 익명으로 작동하거나 모든 정보가 기기에만 저장되는 것은 아니다. 프로필 및 체중 입력, 동기화·공유 등 선택 기능은 사용자가 선택한 범위에서 처리한다.

## 3. 보유·파기와 탈퇴

기기 기록은 삭제 기능으로 지울 수 있다. 로그아웃하거나 동기화를 끄는 것만으로 기기·서버 기록이 모두 삭제되지는 않는다. 탈퇴가 서버에서 확인되면 서버 계정, 해당 개인 기록·사진·공유·문의 및 연결된 동의 이력을 정리한다. 현재 앱은 기기의 코스·러닝을 비로그인 기록으로 보존하며 기기 설정도 남을 수 있다. 서버에만 있던 자료는 탈퇴 후 복원할 수 없다.

공유 중단·원본 삭제 반영·탈퇴는 서비스가 관리하는 링크 접근을 차단할 수 있지만 이미 다른 사람이 받은 이미지·GPX·복사본을 삭제하지는 않는다. 오프라인·삭제 실패·재시도 중에는 서버 반영이 지연될 수 있다.

운영 DB의 삭제와 백업·접속 로그의 소멸은 구별한다. 사용량 식별값 및 누적 카운터, 공급자 백업·로그, 법령상 별도 보존 정보의 항목·근거·기간·파기 방식은 **D06 미정**이다. 확인하지 않은 ‘30일 후 완전 삭제’나 ‘탈퇴 즉시 모든 정보 삭제’를 약속하지 않는다.

## 4. 외부 서비스 처리 현황

다음 표는 기술적 전송 사실이다. 법적 수탁자·제3자 제공·국외 이전 분류를 확정한 표는 아니며, 계약 상대방 법인명·국가·업무·보유 기간·이전 시점/방법·거부 영향은 D05에서 확인한다.

| 연결 서비스 | 확인된 기능·전송 범위 | 게시 전 확인 |
| --- | --- | --- |
| Google·카카오·네이버 | 소셜 인증과 제공 범위 내 계정/프로필 정보 | 제공자별 동의 항목, 책임 범위와 인증 웹 처리 |
| Supabase | Auth, 개인 동기화·사진·공유·가입 동의·문의·사용량 | 실제 계약 주체, 리전 외 처리·재수탁, 로그·백업 |
| Google Cloud Run | 인증된 코스 계산 입력·작업 상태 | 실제 리전·접근 로그·보관·위탁 계약 |
| MapTiler | 지도 타일, 검색어와 위치/주소·지형 요청 | 전송 국가·로그·역할·관련 고지 |
| Cloudflare | 공개 도로 파일과 공유 웹 제공 시 접속 요청 | 실제 서비스별 접속 로그·리전·재수탁 |
| 이용자가 선택한 공유 수신자·앱 | 공개 링크 또는 이미지·GPX | 이용자 선택 공유의 안내와 외부 서비스 책임 범위 |

특정 서버가 서울에 있다는 기록만으로 모든 처리·백업이 국내라고 단정하지 않는다. 위 사실을 무시한 ‘제3자 전송 없음’ 문구도 사용하지 않는다.

## 5. 자동 수집 장치와 기기 저장

보관함은 브라우저 식별 쿠키가 아니라 앱 SQLite와 계정 소유권·선택 동기화를 사용한다. 기기 보안 저장소에는 인증 세션과 처리 복구 상태가 저장될 수 있다. 소셜 로그인 웹 창·공유 웹·외부 지도 요청의 쿠키 및 접속 정보는 실제 공급자 처리와 함께 확인해야 하므로 서비스 전체에 쿠키가 전혀 없다고 선언하지 않는다(D05).

## 6. 이용자 권리와 안전조치

앱에서 프로필·체중·설정을 변경하고 기록 삭제, 동기화 선택, 공유 중단, 탈퇴를 진행할 수 있다. 기기 위치 권한은 OS 설정에서 바꾸며 이를 거부하면 위치 관련 기능이 제한될 수 있다. 열람·정정·삭제·처리 정지 등 권리 행사는 앱 문의 또는 아래 연락처로 요청할 수 있다. 본인 확인 방법·대리인 절차·법령상 예외와 처리 기한은 게시 전에 확정한다(D08·D09).

구현에는 소유자별 접근 제한, 비공개 파일 저장소, 세션의 기기 보안 저장, 서버 인증과 입력 검증이 포함된다. 이를 전체 시스템에 대한 무조건적인 안전 보장으로 표현하지 않는다. 운영 권한·접근 기록·백업·사고 대응 절차는 D05·D06의 운영 확인이 필요하다.
