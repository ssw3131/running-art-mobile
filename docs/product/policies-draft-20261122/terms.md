# RunPen 이용약관 개정 초안

> 정책 회신 전 초안 본문을 보존한 문서다. 연령·가격·유효기간·환불 등 아래의 미정 문구는 현재 결정 상태가 아니다. [확정 회신](../policy-decision-reply-20261122.md)·[구현 현황](../policy-implementation-20261122.md)·[통합 안내](README.md)를 먼저 읽는다. 고객 대상 최종 문안·게시본으로 사용하지 않는다.

작성일: 2026-11-22. **미게시·시행일/공고일 미정.** 유료 상품 부분은 출시 준비 문안이며 현재 결제 가능하다는 뜻이 아니다. [결정표](decisions.md)의 미정 사항을 확정한 뒤 게시본을 만든다.

## 제1조 목적과 운영자

이 약관은 알로하랩(이하 ‘운영자’)이 제공하는 RunPen의 이용 조건과 이용자·운영자의 권리 및 의무를 정하기 위한 것이다. 운영자 주소는 서울시 중랑구 신내로 21길 16, 520-1002이며 문의는 제12조에 따른다.

## 제2조 서비스와 용어

RunPen은 도형·직접 그린 윤곽·이미지에서 추출한 윤곽을 바탕으로 코스를 만들고, 코스 저장, GPS 러닝 기록·안내, 배지, 기록 동기화 및 공유를 제공한다. 코스용 이미지 윤곽은 기기에서 처리한다. 외부 AI 코칭·이미지 생성 서비스와 정기 구독은 제공 중인 기능에 포함하지 않는다.

‘생성 횟수’는 코스 생성 이용량, ‘저장 횟수’는 새 코스를 저장하는 이용량이다. 저장 횟수는 보관함의 동시 보관 공간 수가 아니다. 동일 코스의 기존 저장 확인은 새 저장과 구분하며, 코스를 삭제해도 이미 사용한 저장 횟수가 자동으로 돌아오지는 않는다.

## 제3조 가입과 계정

회원 기능은 지원하는 소셜 계정으로 로그인하고 필수 약관을 확인·동의한 후 이용한다. 게스트는 공개 화면을 탐색할 수 있으며 회원 전용 생성·저장·구매 관련 기능은 가입 안내를 거친다. 제공되는 범위는 각 화면의 안내를 따른다.

로그인 정보와 기기는 이용자가 관리하고, 다른 사람의 계정·기록을 무단 사용하거나 접근 제한을 우회해서는 안 된다. 가입 대상 연령 및 필요한 보호자 절차는 게시 전 확정한다(D08).

## 제4조 무료 혜택과 사용량

가입 최초 1회 무료 생성 5회·저장 10회를 제공한다. 매월 자동 추가 지급하거나 사용량을 초기화하지 않는다. 탈퇴·재가입만으로 최초 혜택이 반복 지급되지는 않는다. 실제 잔량은 서버에서 확인한 계정의 총량과 사용량에 따른다. 기존에 별도로 지급된 혜택을 이 문안 때문에 초기화하지 않는다.

실패·취소·동일 요청 재시도의 처리는 서버 확인 결과를 따른다. 처리 결과가 확인되지 않은 경우 임의로 성공·차감·환급을 표시하지 않고 재확인한다. 이미 완료된 생성·저장과 단순 화면 조회를 구분한다.

## 제5조 단건 팩 — 출시 준비 문안

팩은 생성과 저장 횟수를 함께 추가하는 단건 상품이며 자동 갱신 구독이 아니다.

| 상품 | 표시 가격 | 추가 생성 | 추가 저장 |
| --- | ---: | ---: | ---: |
| 기본 팩 | 1,900원 | 10회 | 20회 |
| 플러스 팩 | 2,900원 | 30회 | 60회 |
| 확장 팩 | 4,900원 | 60회 | 120회 |

현재 화면은 구매 준비 상태이며 결제·횟수 지급을 실행하지 않는다. 출시 시 최종 결제 금액·지급 조건을 결제 전에 확인할 수 있도록 한다. 세금 포함 표시는 D10, 유효기간·재구매 시 합산/차감 순서·지급/복원 검증 방식은 D01~D04를 확정 후 반영한다.

## 제6조 계정 귀속과 기기 변경

생성·저장 잔량은 로그인 계정의 사용량으로 관리하며 기기 변경을 새로운 무료 혜택 지급으로 취급하지 않는다. 장래 유료 구매의 계정 연결·복원은 검증된 구매 결과를 기준으로 설계하고, 다른 RunPen 계정으로의 양도 가능 여부 등은 출시 전에 정한다(D04).

코스와 러닝 기록은 먼저 기기에 저장된다. 로그인만으로 기존 기기 기록이 자동 업로드되지는 않는다. 개인 동기화를 켜면 해당 계정의 코스와 종료한 러닝 기록을 서버에 저장·복원할 수 있다. 동기화하지 않은 자료는 다른 기기에 자동으로 나타나지 않으며 기기 분실·앱 데이터 삭제 전에 보관 상태를 확인해야 한다. ‘기기 변경 시 횟수 확인’과 ‘기록 복원’은 서로 다른 기능이다.

## 제7조 청약철회·환불과 오류

유료 기능 출시 시 [환불정책 초안](refunds.md)을 확정해 구매 전에 안내한다. 미사용, 일부 생성·저장 사용, 지급 실패, 중복 결제는 결제와 이용 이력을 확인하여 구분한다. 법령상 권리와 적용되는 결제 플랫폼 절차를 제한하는 일률적인 ‘환불 불가’ 문구를 두지 않는다. 세부 산식·처리 기간·권한은 D01~D04 확정이 필요하다. 문의처는 **제12조**이다.

## 제8조 위치·안내와 안전

위치 권한을 사용하여 내 위치 확인과 러닝 기록·안내를 제공한다. GPS·지도·도로 정보는 실제 환경과 다를 수 있으므로 교통 법규, 통행 가능 여부 및 주변 안전을 직접 확인한다. 현재 코스 시작은 유효 GPS 확인 후 기록을 시작하고 이용자가 자유롭게 이동하여 코스에 합류하는 방식이다. 초기 합류 경로 계산이 끝날 때까지 대기하도록 요구하지 않는다. 소모 칼로리는 선택 체중 또는 기본값을 사용하는 추정치다.

## 제9조 개인정보와 공유

실제 처리 항목과 이용자의 권리는 [개인정보처리방침 초안](privacy.md)을 확정하여 안내한다. 공유 링크를 준비하면 선택한 종료 기록을 서버에 전송할 수 있으며 링크를 가진 사람이 경로를 볼 수 있다. 이미지·GPX는 이용자가 선택한 앱·저장 위치로 전달한다. 공유 중단으로 이미 내려받거나 재전달된 복사본까지 회수되지는 않는다.

## 제10조 탈퇴와 기록

탈퇴가 확인되면 계정과 서버의 해당 개인 자료를 삭제한다. 현재 앱은 이 기기의 코스·러닝 기록을 비로그인 기록으로 남기며 이용자가 별도로 삭제할 수 있다. 기기 설정도 남을 수 있다. 다른 계정으로 자동 업로드하지 않는다. 최초 혜택 반복 방지용 변환 식별값과 누적 사용량은 현행 서버에 남으므로 ‘모든 정보 즉시 삭제’라고 안내하지 않는다. 해당 보유의 근거·기간과 유료 잔량의 탈퇴 처리 기준은 게시 전 확정한다(D04·D06).

## 제11조 서비스 변경과 책임

기능 변경·점검·중단 시 영향을 받는 이용자에게 적절한 방법으로 안내한다. 결제 서비스의 종료·장애 시 미사용 유료 혜택 처리 기준은 출시 전에 정한다. 운영자의 고의·과실에 따른 책임이나 법령상 이용자 권리를 일괄 배제하는 면책 조항으로 해석하지 않는다. 공지 기간과 분쟁 처리 문안은 최종 검토 대상이다(D09).

## 제12조 문의 및 권리 행사

앱의 마이페이지 → 고객문의에서 비공개 문의를 접수하고 답변을 확인할 수 있다. 계정 접근이 어렵거나 개인정보 권리 행사 등이 필요한 경우 `runpen.team@gmail.com`으로 문의한다. 앱 문의는 이메일 입력을 요구하지 않는다. 운영 시간·응답 기한은 아직 확정되지 않았다.

## 제13조 시행과 변경 이력

공고일·시행일은 미정이며, 이 초안에 동의한 것으로 처리하지 않는다. 최종 문안 확정 시 실제 정책 버전, 변경 안내, 필요한 동의 절차를 함께 반영한다. 기존 원문과 시험 게시 이력은 [초안 안내](README.md)에 보존되어 있다.
