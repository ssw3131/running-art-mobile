# 개발 계획 문서 위치

최종 결정·이유는 [프로젝트 목표](product/overview.md), 순서는 [단계별 개발 계획](planning/roadmap.md), 구현 방법은 [구현 구조](architecture/implementation.md)로 나누었습니다.

**4-1 독립 가공·PC 검증은 완료했고 휴대폰 연결 테스트는 사용자 요청으로 보류했습니다. 다음 제안은 4-2 독립 도로 서버 배포 준비입니다.** 0.02도 격자·gzip은 잠정 선택이며 휴대폰 측정과 형식 최종 확정은 미완료입니다. 표본 검증 → 서버 구축·배포 → 앱 전환·영구 캐시 → 전국 운영 순서와 완료 조건은 [독립 서버 계획](planning/server-strategy.md), 실제 진행 상태는 [현재 상태](handoff/status.md)를 확인합니다. 독립 서버 구축·앱 전환은 아직 미착수입니다.
