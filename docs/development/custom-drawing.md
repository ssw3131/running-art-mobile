# 직접 그린 도형으로 코스 만들기

## 사용법

1. **코스 만들기 → 도형 → 직접 그리기**를 연다.
2. 흰 영역에 한 획으로 도형을 그리고 갈색 시작점으로 돌아온다. 닫힌 윤곽 하나를 사용하며 선이 교차하거나 겹치는 모양은 다시 그린다.
3. 손을 떼면 정리된 모양을 미리 보여준다. 작은 끝점 틈은 자동으로 닫는다. **이 도형 사용**으로 적용한다. 영역을 다시 터치하면 새로 그리며 **모두 지우기**, **취소**, Android 뒤로 가기도 지원한다. 취소하면 이전에 적용한 도형이 유지된다.
4. 위치·목표 거리 3/5/7km를 선택하고 **코스 계산하기**를 누른다. 기본 도형과 같은 반경 2km 자유 순환 검색을 사용한다. 후보가 없으면 위치·거리·도형을 바꾼다.
5. 후보를 선택해 저장한다. 저장 이름의 기본값은 `직접 그린 도형 N.NNkm`다. 저장한 코스 목록·상세에서 다시 열고 GPX 내보내기·러닝 준비로 이동한다.

기본 9종 도형도 계속 사용할 수 있다. 도형을 변경해도 마지막 완료 결과는 계산 당시 도형을 유지하며 다시 계산할 때 새 조건을 적용한다. 계산 중 편집을 열면 계산을 취소한다. 그리기 초안은 화면 내부 상태이며 앱 종료 후 복원하지 않는다. 저장한 코스의 도형·경로는 영구 보존한다.

## 입력 처리와 저장 계약

- 별도 라이브러리·서버 계산 없이 React Native 터치 입력과 기존 v0.2 `customTemplate`을 사용한다. 화면 좌표는 정사각형의 0~1, 엔진 입력은 종횡비를 보존한 중앙 정렬·y축 반전 좌표다.
- 한 획 최대 2,048점. 표시용 선분은 약 256개로 제한하고, 손을 떼었을 때 원본 입력으로 단순화한다. 빈 입력·작은 모양·직선·큰 끝점 간격·자기 교차·겹침·과도한 복잡도를 거절한다.
- 도형의 최소 가로/세로 폭은 영역의 8%, 긴 변은 20% 이상이다. 끝점 틈은 긴 변의 18% 이내만 닫는다. RDP 단순화로 엔진 계약인 4~49점의 폐곡선을 만들고 적용 전에 미리 보여준다. 이 수치는 초기 입력 품질 기준이며 거리·점수 계산 규칙을 바꾸지 않는다.
- 요청 시작 시 `customTemplate`을 깊은 복사한다. 도로 로딩 중 입력 변경, 계산 취소·늦은 응답, 이전 결과 저장이 새 도형과 섞이지 않는다.
- 사용자 도형만 코스 JSON **v3**, `shape: 'custom'`, 정규화한 `customTemplate`을 사용한다. 실제 도로 코스는 v2와 동일하게 닫힌 경로·양방향 OSM 구간 참조를 검증한다. 지도에 배치된 `target`도 저장해 상세·러닝 사본·공유에서 원래 도형을 보존한다.
- 기본 도형은 기존 JSON v1/v2를 유지하고 다시 쓰지 않는다. SQLite v7·개인 동기화 파일 외피·서버 DB/API는 그대로다. 이전 앱은 v3 코스 상세에 업데이트 안내를 표시하며 새 앱은 v1/v2/v3를 읽는다.
- 이미지 입력, 여러 획/구멍 있는 도형, 도형 라이브러리 관리, Figma 디자인 적용은 이번 기능에 포함하지 않는다.

검증과 APK·범위는 [직접 그리기 검증](../quality/custom-drawing-verification.md)을 따른다.
