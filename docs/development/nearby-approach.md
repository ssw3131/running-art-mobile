# 가까운 코스와 합류 경로 — 2026-11-15

입력 거리는 접근 구간을 제외한 도형 코스 거리다. 새 `nearby-v1` 정책은 선택한 출발지에서의 도보 합류 거리 300→500→1,000m 순으로 근거리 배치를 최대40개씩 별도 평가한다. 유효 근거리 후보를 찾으면 다음 단계는 생략한다. 기존 광역420개 평가/정제 후보군과 점수식을 보존하고 중복 배치는 평가 결과를 재사용한다.

최고점 후보와 중복되는 후보를 제외하고 가장 가까운 거리 단계에서 최고점인 후보를 가까운 대표로, 연결 가능한 전체 후보 중 최고점을 모양 비교 대상으로 고른다. 원시 점수 차이≤5이면 가까운 대표를 선택하고, >5이면 선택을 비워 비교하도록 한다. 1km 초과 또는 연결 확인 불가 후보는 자동 선택하지 않는다. 최대5개 및 도로 중복80% 제한을 유지한다. 반경 제한은 전체 코스 배치 범위이며 접근 거리 제한과 다르다.

`runpen-routes-v3`의 `options.proximity=nearby-v1`만 새 정책을 사용한다. v1/v2는 요청·결과·점수·저장 형식을 유지한다. `Accept: application/x-ndjson`으로 실제 진행/결과/오류를 수신하고, 복원 응답의 기존 JSON도 읽는다. 하나의 operation ID와 기존 reserve→ready→commit 수명 안에서 모든 단계가 실행된다. 결과 메타데이터와 합류 경로는 저장 코스 snapshot에 추가하지 않는다.

추천 이동 거리는 선택 출발지 기준이다. 이미 확보한 유효 GPS가 있으면 선택 후보의 실제 합류 경로도 우선 준비하며 화면 전환 시 동일 진행 작업을1초 동안 인계할 수 있다. 유효한 서버 경로를 실행 중 합류 캐시에 보관하며, 실제 시작은 현재 GPS·동일 보행 도로·코스 해시/복귀 목적지를 검증한다. 생성 위치와 GPS가 다르면 도로 확인/현재 위치 경로 계산이 필요하다.

합류 탐색은 직선거리 하한에30m 도로 스냅 여유를 둔1/2/5/10km 최소 단계에서 시작한다. 반경 경계의 긴 원본 도로는 합류용 그래프에서만 내부 세분 구간을 보존한다. 소스 도로 없음/모호성은 확장으로 해결하지 않는다. 경로 거리+현재 GPS에서 도로까지 거리가 그래프 경계의 거리 하한보다 작아야 재조회 없이 확정한다. 그렇지 않으면 넓히며 보행 방향·OSM 연결성을 유지한다.

캐시는 최대2개 그래프/노드+간선 합계10만/5분, 경로10개/5분이다. 그래프 퇴출 시 이를 붙잡은 경로도 제거한다. 계정·도로 버전 변경 시 무효화하고 코스/복귀 목적지 변경은 별도 키다. GPS 관측은 기존5초·정확도30m 기준, 준비의 GPS 대기는15초, 경로 대기는10초다. 안내창 전체의10초 강제 취소는 제거하고 실패 시 지도·명시적 재시도를 제공한다. 준비가 유효하지 않으면 기록 시작을 막는다.
