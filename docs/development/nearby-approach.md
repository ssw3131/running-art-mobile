# 가까운 코스와 합류 경로 — 2026-11-15

**2026-11-18 러닝 자율 합류:** 최초 러닝 합류 경로 계산·현재 GPS 선계산·시작 경로 검증은 제거했다. 유효한 GPS로 기록을 시작하고 코스 12m/3초 합류 후 기존 방향 판정/안내를 사용한다. 아래 추천의 선택 출발지 기준 접근 거리/가까운 대표 정책과 이탈·이어달리기의 복귀 경로 엔진은 유지한다. [러닝 계약](course-gps-guidance.md)·[실행 기록](../history/executed-plans/2026-11-18-2147-manual-course-join.md).

입력 거리는 접근 구간을 제외한 도형 코스 거리다. 새 `nearby-v1` 정책은 선택한 출발지에서의 도보 합류 거리 300→500→1,000m 순으로 근거리 배치를 최대40개씩 별도 평가한다. 2026-11-16부터 원점수 50점 이상인 유효 근거리 후보를 찾으면 다음 단계는 생략한다. 50점 미만만 있으면 다음 거리 단계를 검토한다. 기존 광역420개 평가/정제 후보군과 점수식을 보존하고 중복 배치는 평가 결과를 재사용한다.

최종 후보군에서 원점수 50점 미만을 먼저 제외한다. 기준 충족 후보가 부족하면 그 수만 표시하고, 없으면 빈 결과/생성 횟수 미차감과 조건 변경 안내를 유지한다. 이후 최고점 후보와 중복되는 후보를 제외하고 가장 가까운 거리 단계에서 최고점인 후보를 가까운 대표로, 연결 가능한 전체 후보 중 최고점을 모양 비교 대상으로 고른다. 원시 점수 차이≤5이면 가까운 대표를 선택하고, >5이면 선택을 비워 비교하도록 한다. 1km 초과 또는 연결 확인 불가 후보는 자동 선택하지 않는다. 최대5개 및 도로 중복80% 제한을 유지한다. 반경 제한은 전체 코스 배치 범위이며 접근 거리 제한과 다르다.

`runpen-routes-v3`의 `options.proximity=nearby-v1`만 새 정책을 사용한다. v1/v2는 요청·결과·점수·저장 형식을 유지한다. `Accept: application/x-ndjson`으로 실제 진행/결과/오류를 수신하고, 복원 응답의 기존 JSON도 읽는다. 하나의 operation ID와 기존 reserve→ready→commit 수명 안에서 모든 단계가 실행된다. 결과 메타데이터와 합류 경로는 저장 코스 snapshot에 추가하지 않는다.

추천 이동 거리는 선택 출발지 기준이다. 서버가 제공한 접근 거리와 선택 출발지 기준의 구형 결과 거리 조회는 유지한다. 실제 현재 GPS로 선택 후보의 러닝 합류 경로를 미리 준비하던 작업은 제거했다. 추천 거리 조회는 러닝 시작의 선행 조건이 아니다.

합류 탐색은 직선거리 하한에30m 도로 스냅 여유를 둔1/2/5/10km 최소 단계에서 시작한다. 반경 경계의 긴 원본 도로는 합류용 그래프에서만 내부 세분 구간을 보존한다. 소스 도로 없음/모호성은 확장으로 해결하지 않는다. 경로 거리+현재 GPS에서 도로까지 거리가 그래프 경계의 거리 하한보다 작아야 재조회 없이 확정한다. 그렇지 않으면 넓히며 보행 방향·OSM 연결성을 유지한다.

캐시는 최대2개 그래프/노드+간선 합계10만/5분, 경로10개/5분이다. 그래프 퇴출 시 이를 붙잡은 경로도 제거한다. 계정·도로 버전 변경 시 무효화하고 코스/복귀 목적지 변경은 별도 키다. 보행 일방통행에서는1m 넘게 이동하면 경로를 현재 위치에서 다시 만들고 도로망만 재사용한다. 러닝 시작의 GPS 조건은 기존5초·정확도30m와 시작 시15초 대기/취소를 유지한다. 2026-11-18부터 준비 안내 및 시작은 합류 경로 준비 상태에 의존하지 않는다. 위 캐시는 추천 거리와 이탈·이어달리기 복귀 계산에서 사용하며 최초 합류에는 사용하지 않는다.

검증 및 미완료 범위: [검증 기록](../quality/nearby-approach-20261115.md). 배포는 구 계약 호환 서버→새 앱 순이며 이번 구현은 운영 배포/폰 설치를 포함하지 않는다.

## 2026-11-16 최소 점수 조건

거리 단계·단계별 탐색량·광역 탐색·점수식/퍼센트 표시·5점 비교·v3 형식은 유지한다. 가까운 대표와 먼 대안 모두 반올림 전 `score.raw >= 50`을 충족해야 한다. 1km 안에 적합 후보가 없으면 기존 광역 후보 중 적합한 먼 대안을 표시하며, 추가 도로 반경 확대는 없다. 이전 저장 코스와 복원 결과를 재채점하거나 마이그레이션하지 않는다. 도로 연결 실패는 품질 미달과 구분하고 빈 결과에서 존재하지 않는 대안 선택을 안내하지 않는다.
