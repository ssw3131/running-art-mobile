# Codex 사용과 프로젝트 인수인계

## 프로젝트 열기

Codex에 **running-art-mobile 폴더 자체**를 프로젝트로 추가하고 새 작업을 시작합니다. 상위 폴더를 열면 하위 프로젝트 지침·스킬이 동일하게 발견된다고 가정하지 않습니다. CLI에서는 해당 폴더로 이동한 후 `codex`를 실행합니다.

각자 계정으로 로그인하고 프로젝트 내용을 확인한 뒤 신뢰 설정을 적용합니다. 프로젝트 설정은 신뢰된 프로젝트에서 읽힙니다. 개인 계정·모델·권한은 각자의 설정을 사용합니다. 이 저장소는 이를 변경하지 않습니다. [공식 설정 안내](https://learn.chatgpt.com/docs/config-file/config-basic)

## 공유되는 설정

| 파일 | 역할 |
| --- | --- |
| `AGENTS.md` | 먼저 읽을 문서, 제품 결정, 코드 배치, 검증, 실행 이력 규칙 |
| `.codex/config.toml` | 프로젝트 경계와 지침 읽기 한도. 개인 절대 경로·계정 정보 없음 |
| `.agents/skills/` | 업무에 따라 자동 선택되는 프로젝트 스킬 |

프로젝트 지침과 스킬을 Git으로 공유하므로 다른 사람의 홈 폴더에 별도로 설치할 필요가 없습니다. AGENTS.md는 시작 지침, 스킬은 해당 작업에 필요한 상세 절차입니다. [공식 AGENTS.md 안내](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [공식 스킬 안내](https://learn.chatgpt.com/docs/build-skills)

## 분야별 스킬

| 스킬 | 적용 시점 |
| --- | --- |
| `$running-art-android` | Android Studio·Windows Android 설치·빌드·기기 연결·실행 문제 |
| `$running-art-algorithm-port` | Codex v0.3 계산 모듈의 실제 이식·회귀 검증 |
| `$running-art-plan-record` | 계획에 따른 실행 시작과 종료, 날짜별 계획·결과 기록 |

세 스킬 모두 자동 선택을 허용합니다. 실행 기록은 AGENTS.md에도 작업 규칙으로 두어 별도 요청 없이 적용하게 합니다. 목록에 보이지 않으면 프로젝트를 다시 열거나 새 작업을 시작하고, 필요하면 AGENTS.md에 연결된 SKILL.md를 직접 읽도록 요청합니다.

## 자동 기록의 의미

실제 구현에 들어가는 계획만 `docs/history/executed-plans/`에 저장합니다. 실행 직전 계획은 보존하고 종료 때 결과·검증·시각을 덧붙입니다. CI/CD처럼 미실행 계획은 제외하며, 과거 기록 복원은 원문 보존과 구분합니다.

이 자동화는 Codex 작업 절차입니다. 백그라운드 예약이나 외부 편집 감시가 아닙니다. 사람이 직접 작업하거나 다른 AI 도구를 쓰면 같은 지침과 템플릿을 읽고 기록해야 합니다.

## 새 작업에서 확인할 요청 예시

```text
AGENTS.md와 현재 상태 문서를 읽고 프로젝트의 목표, 구현 완료 범위,
미실행 계획, 실제 실행 계획 기록 규칙, 사용할 수 있는 스킬을 요약해 줘.
아직 구현은 시작하지 마.
```

이 요청은 읽기·확인만 수행하므로 실행 기록을 만들지 않습니다. 다음에 실제 구현을 요청하면 해당 계획을 기록합니다. 도구가 지침·스킬을 실제 읽는지는 새 세션에서 확인해야 하며, 파일 생성만으로 모든 계정에서의 로딩을 검증했다고 간주하지 않습니다.
