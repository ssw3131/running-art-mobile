# RunPen 러닝 안내 모의 시험

현재 앱의 **러닝 안내 시험 · 모의 주행**은 실제 위치를 수집하지 않고 코스 안내를 시험한다. 저장 코스 상세에서도 같은 이름의 버튼으로 진입한다. 별도 앱·로그인·계산 서버 없이 동작하며 실제 GPS 러닝 안내의 완료를 뜻하지 않는다.

[사용자가 전달한 5개 화면 기준 이미지](../product/assets/running-guidance-reference-20261003.png)를 보존했다. 모의 시험에서는 시안의 교차로 단정 문구·저장 버튼을 현재 기능에 맞게 바꾸고 배지·칼로리·공유를 후속으로 분리했다.

## 사용 흐름

1. 홈 → 러닝 안내 시험 → 정상 완주·회전/유턴·이탈/복귀·위치 흔들림·신호 끊김·교차·왕복·장시간 중 시나리오를 선택한다. 저장 코스로 진입하면 원래 좌표를 사용하며 정상·이탈/복귀·위치 흔들림·신호 끊김을 선택한다.
2. 모의 주행 시작을 누르고 Android 알림을 허용한다. 위치 권한은 요청하지 않는다. 지도와 집중 모드는 같은 진행 상태를 보여준다. 실제 GPS 러닝 중이면 먼저 일시정지/종료해야 하며, 모의 시험을 종료해야 실제 GPS 러닝을 시작할 수 있다.
3. 설정에서 지도/집중, 음성, 화면 꺼짐 안내를 바꾼다. 설정 화면에서도 주행은 계속된다. 초기값은 지도·음성 켜짐·화면 꺼짐 안내 켜짐이다.
4. 시험 조작에서 1·5·10·30배, 수동 이탈·지나온 길 복귀·위치 불량·신호 끊김·정상 수신·처음부터를 선택한다. 버튼은 모의 위치 공급기에 작용하며 안내 상태를 강제로 성공 처리하지 않는다.
5. 코스를 끝까지 따라가면 멈추고 완주 결과 보기 버튼을 표시한다. 결과는 모의 이동 거리·시간·평균 페이스다. 중도 종료는 완주와 다르게 표시한다.

모든 화면과 실행 알림에 모의 주행임을 표시한다. 시험은 메모리에서 실행하며 SQLite·Supabase에 코스/러닝/배지 자료를 쓰지 않는다. 앱 프로세스를 종료하면 시험은 초기화되고 자동 재개하지 않는다. 기존의 코스 시뮬레이션은 앱을 내리면 멈추는 원래 동작을 유지한다.

## 거리·시각·안내 기준

- 기준 속도는 6분/km다. 배속은 모의 시간을 가속하고 평균 페이스는 모의 활동 시간/이동 거리다. 이탈 후 제자리에서 기다리는 시간도 포함하며 일시정지 시간은 제외한다.
- 이동 거리는 허용한 모의 좌표 간 거리, 코스 진행은 원본 좌표를 순서대로 따라간 거리다. 이탈·복귀 거리를 코스 진행에 더하지 않는다. 복귀 중 잔여 거리는 복귀 궤적 길이+원래 코스 잔여 거리다.
- 저장 코스에는 교차로/도로명 정보가 없다. 좌표의 전후 10m 방향 변화에서 35도 이상을 회전, 150도 이상을 유턴으로 보고 20m 이내 중복 안내점을 억제한다. 실제 도로 교차로 여부를 보장하지 않는다.
- 이전 코스 진행 지점 주변에서 위치를 매칭하고 진행 순서를 보존한다. 교차·같은 도로 왕복·출발/도착 중복을 별도 표본으로 검증한다.
- 신뢰 가능한 위치가 경로에서 25m 초과로 5초 지속되면 이탈, 이탈 지점 12m 이내에서 3초 지속되면 복귀다. 정확도 30m 초과·수신 공백 5초 초과·초당 12m 초과 점프는 안내 판단을 보류한다. 시간 문턱은 모의 시간 기준이다.
- 복귀는 저장한 이동 궤적을 역순으로 되짚는다. 위치 공백으로 궤적이 끊긴 경우 직선 복귀 경로를 만들지 않고 위치 확인 중을 표시한다.
- 마지막 코스 구간에 순서대로 도달하고 잔여 10m 이하·도착점 15m 이내가 3초 유지되면 완주다. 출발점과 도착점이 같아도 출발 즉시 완주하지 않는다.
- 방향 음성은 100m·30m 전 각 한 번, 이탈 진동은 한 이탈에 한 번이다. 가속 시 오래된 음성을 누적하지 않는다. 음성은 정상 속도로 출력하며 한국어 데이터가 없으면 문자 안내와 설치 안내를 표시한다.

위 수치는 초기 모의 검증 기준이며 실제 GPS 야외 검증으로 확정한 제품 정책이 아니다.

## Android 실행과 실패 처리

로컬 Expo 모듈 `modules/guidance-native/`가 사용자 시작형 `specialUse` foreground service·한국어 오프라인 TTS·진동을 담당한다. 공통 TypeScript 안내 엔진은 단일 Headless JS 세션에서 실행된다. 화면은 상태를 구독하고 별도로 시간을 누적하지 않는다. 생성된 Android 폴더를 직접 수정하지 않고 로컬 모듈의 manifest와 Gradle 설정으로 재현한다.

2026-10-04 재개 보완에서는 `setInterval` 대신 서비스의 `nextTick(token)`을 한 번씩 기다린다. Android main Handler가 250ms 뒤 응답하므로 화면 프레임 타이머가 멈춰도 갱신하며, JS가 늦어져도 요청을 쌓지 않는다. 서비스 종료는 대기 중 요청을 해제하고 세션 토큰으로 이전 응답이 새 주행에 영향을 주지 않게 한다. 완주 음성의 7초 대기·정리도 같은 신호를 사용한다. 하트비트 감시는 유지한다. 기기 재시험 결과와 설치 범위는 검증 문서를 따른다.

화면 꺼짐 안내를 켜면 잠금/다른 앱에서도 실행한다. 알림에 일시정지·시험 종료가 있으며 앱 복귀 후 같은 상태를 표시한다. 끄면 백그라운드 전환 때 일시정지하고 전경 복귀만으로 자동 재개하지 않는다. 사용자 일시정지·종료·오류 시 서비스/작업/음성/진동을 정리한다. 서비스 응답이 끊기면 중단하며 OS가 프로세스를 없앤 뒤 자동으로 새 시험을 시작하지 않는다.

MapTiler 배경 지도는 인터넷이 필요하다. 실패하거나 배경을 끄면 기본 경로 화면을 사용하며 안내 계산은 계속된다. 한국어 오프라인 음성은 Android 음성 출력 설정의 Google 음성 데이터 → Korean (South Korea)에서 설치할 수 있다. 모의 주행의 특별 용도 서비스는 내부 시험 APK용이며 스토어 출시용 서비스 종류는 실제 GPS 연결 단계에서 다시 검토한다.

## 검증 명령과 후속

2026-10-04 휴대폰 후속에서 재개→Home의 `heartbeat_timeout`을 재현·수정했다. 현재 설치본은 `20261004-guidance-resume.apk`이며, 기존 `058c6d3`에 안내 수정만 담아 별도 GPS/계정 개발 변경과 구분한다. 3회 반복·315.8초 연속 잠금·알림 제어·강제 종료/완주에 이어 사용자 잠금 해제 후 배경 OFF 자동 정지/복귀 후 정지 유지·ON 복원·자료/계정 전후 UI 대조를 통과했다. 서비스와 임시 도우미 정리까지 완료했다. `scripts/qa/guidance-phone.py --serial <연결한 기기 ID>`는 UI/서비스 증거를 수집하며 DB 쓰기를 하지 않는다. 갱신 중 삼성 UI 덤프는 대기할 수 있어 정지 상태에서 캡처하며 보안 잠금은 사용자가 직접 해제한다. 아래 최초 휴대폰 제외 범위보다 [최신 검증 결과](../quality/running-guidance-simulation-verification.md)를 우선한다.

```powershell
. .\scripts\env.ps1
node --test tests/guidance*.test.mjs
npm.cmd test
powershell -ExecutionPolicy Bypass -File .\dev.ps1 check
```

`scripts/qa/guidance-emulator.py`는 `emulator-5556`만 대상으로 UI 캡처·조작·DB 내용 해시·화면 꺼짐 모니터 증거를 모은다. `guidance-fixture.mjs`는 공개 v0.2 회귀 좌표를 검증용 저장 코스 파일로 만든다. `seed-fixture`는 모든 사용자 테이블이 비어 있는 v4 에뮬레이터에서만 동작하며 `restore-fixture`로 원래 내용을 복구한다. 앱의 모의 주행 기능에는 이 자료 생성·DB 쓰기 기능이 들어 있지 않다. `RunningUiDump.java`는 이전 XML을 재사용하지 않도록 새 덤프 생성까지 검사한다. 생성 자료는 `.cache/guidance-qa/`에 보관한다.

실제 GPS 연결·새 경로 계산·중간 합류/역방향 출발·프로세스 종료 후 시험 복원·실제 러닝 저장·배지·칼로리·공유 이미지는 후속이다. 실제 휴대폰 설치·야외 GPS·배터리·진동 감각·iOS도 이번 검증에서 제외한다. 실제 실행 결과는 [검증 기록](../quality/running-guidance-simulation-verification.md)을 따른다.
