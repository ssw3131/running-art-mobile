# 현재 결정과 회귀 검사 연결

이 문서는 최근 통합에서 확인한 **변경된 기대 동작**의 출발점이다. 제품 전체 기획이나 실기기 검증 완료 목록은 아니다. 2026-11-09 기준 구현·검증 근거는 [PR50 실행 기록](../history/executed-plans/2026-11-08-2020-pr49-ci.md), 작업 상태는 [현재 상태](../handoff/status.md)를 따른다. 새 사용자 결정이 나오면 해당 행과 관련 검사/문서를 같은 PR에서 갱신한다.

과거 개발 계약에는 그 날짜 당시의 결정과 미병합/미배포 상태가 남아 있다. `course-archive-running.md`의 1~10km·유사도 미표시, `course-generation-figma-20261024.md`의 제한 없음, `account-mypage.md`의 화면 꺼짐 설정 등 과거 문구를 그대로 최신 테스트 정답으로 삼지 않는다. 최신 명시적 사용자 결정과 변경 근거를 먼저 확인하고, 충돌이 해소되지 않으면 기대 동작을 확정한다. Figma 예시 숫자를 실제 기록·잔량으로 복사하지 않는다.

- 결정 일시와 근거: 사용자 결정/기획 링크 및 이전 어느 동작을 대체하는지.

- 화면 변경이면 원본/기준/차이 검토와 출처. 운영 API·자료 형식 변경이면 별도 영향 범위.
- 실행한 검사의 실제 범위와 결과, 미검증 사항. 코드 구현·CI·폰 설치·운영 배포를 각각 구분.

## 2026-11-09 공유 대상별 화면 결정

Figma 643:4169/4246/6323/4439/4535를 기준으로 공유 화면은 인스타그램·인스타스토리·링크 공유·이미지 저장을 구분한다. 인스타그램은 1080×1080, 스토리는 1080×1920, 저장은 두 비율을 선택한다. 기존 1080×903 기본 카드 및 4:5·닉네임/날짜 스위치 UI를 대체하며, 기존 모델의 구형 형식 처리 자체는 보존한다. 선택 기록의 실제 지도/경로·현재 프로필·날짜·출발지·추정 kcal를 이미지 미리보기에 표시한다. 예시 주소·숫자·프로필을 하드코딩하지 않는다. 2026-11-11 결정에 따라 체중 미설정은 기본 60kg으로 추정, 지도 실패는 기록 윤곽으로 표시한다. 이미지에 보이는 정보는 수신 앱으로 전달되며 링크 중단으로 회수되지 않는다.

전달은 Android 시스템 공유 창을 통해 사용자가 Instagram/Story/카카오톡을 선택한다. 전송·게시 완료를 앱에서 임의로 주장하지 않는다. 링크는 기존 서버 확인·명시적 공개 확인·복사·공유 중단과 서비스 미설정 안내를 유지하며, 화면 진입만으로 링크를 공개하지 않는다. 완주 기록 상세의 최초/누적 완주 모두 선택 기록의 공유 화면으로 이동하고, 재도전은 기존 동작을 유지한다.

관련 회귀: `run-card-export`, `share-card-readiness`, `share-map`, `achievements`, `run-share-card`, `achievement-export`; Node `achievement-card`; 격리 Android S56은 플랫폼 선택→실제 PNG 비율→공유창 취소→파일 저장 취소/바이트 일치를 확인한다. 네 개 기존 기본 화면의 이미지 마스크나 임계값은 바꾸지 않는다.


## 2026-11-11 선택 몸무게·홈·코스 순서·러닝 선

가입 몸무게는 선택 입력이다. 비워 두면 60kg을 계산 기본값으로 사용하고 문구에 표시하며, 실제 체중을 입력한 것처럼 60kg을 계정에 저장하지 않는다. 기존 계정의 입력 체중·다른 설정과 가입 동의 확인 절차를 보존한다. 잘못된 입력은 프로필/동의 저장 전에 차단한다.

반복 홈은 저장 코스 → 뱃지 도전 → 획득 뱃지 → 완주 코스 순서다. 완료되지 않은 세션을 완주 코스에 섞지 않는다. 홈·러닝 선택·보관함은 동일한 최신 시도 판정으로 미완주 우선, 같은 그룹은 생성 최신순이며 SQL 페이지/홈 5개 제한 전에 정렬한다. 저장되지 않은 과거 러닝을 홈에서 임의로 저장하거나 GPS를 재개하지 않는다.

미획득 도형/모음/카테고리·누적 거리/시간 중 적은 러닝 횟수로 달성 가능한 후보에서 실행별 무작위 추천한다. 폴링·탭 이동으로 바꾸지 않고 앱 시작/다시 활성화 시 갱신한다. 별도 지역·거리 변주나 동일 코스 반복 조건을 단순한 도형 1회 완주로 오안내하지 않는다. 2026-11-12 후속 결정에 따라 추천 CTA는 해당 뱃지의 도전 상세로 이동한다. 저장 코스 유무와 관계없이 코스 생성/사용량 차감은 하지 않는다.

실시간 지도에서 계획 경로는 파랑 3px, 실제 궤적은 주황 7px이다. 현재 위치 추적·회전·진행 계산·GPS 구간 분리는 변경하지 않는다.

## 2026-11-12 홈 목록·기록 경로 후속

홈 저장/완주 코스 및 획득 뱃지는 최대5개 가로 스크롤이다. 저장 미완주 우선·나머지 최신순을 유지하고 홈 썸네일 정보 문구를 제거한다. 추천 원본 뱃지는 원형 표시 영역으로 모서리를 가린다. 코스 설정은 선택된 도형만 주황색이다. 저장 목록은 후속 요청에 따라 정적 지도 이미지로 표시하며 미완주 여부와 선택 테두리를 분리한다. 실제/시뮬레이션 지도와 미완주 저장 상세의 경로는 파랑3px 코스·주황7px 실제 기록이며 GPS 공백은 잇지 않고 한 점 구간은 점으로 남긴다. 상세 열기는 기록/위치추적을 변경하지 않는다.

## 2026-11-12 코스 지도 목록·뱃지 상세·즉시 GPS 갱신

홈 저장 카드는 예상 시간·간단한 지역·미완주 표시를 제공하고 날짜는 표시하지 않는다. 추천 CTA는 뱃지 도전 상세, 획득 뱃지의 링크는 더보기다. 완주 카드에는 중복 완주 상태 뱃지를 두지 않는다.

저장 목록과 실시간 러닝 선택 목록은 원본 저장 snapshot의 경로를 정적 캐시 지도 이미지로 표시한다. 계정 전환의 늦은 응답은 무시한다. 주소는 도로명까지 표시하고 건물번호·우편번호는 제외하며, 번호가 들어간 도로명 자체는 보존한다.

완주 기록 목록은 거리와 예상 시간을 함께 표시하고 완료일(endedAt, 없을 때 startedAt) 기준으로 정렬/그룹/날짜를 표시한다. 시뮬레이션 표시 문구는 이 목록에서만 제거하며 원본 reason과 실제/모의 러닝 구분은 보존한다. 도형 선은 주황색이다. 작은 폰에서도 거리와 km를 분리하지 않는다.

뱃지 획득 조건은 원본494:3414 체크 SVG24x24를 사용한다. 제목/이름의 중첩 텍스트도 글꼴 크기를 명시하고 자동 줄바꿈을 허용한다. GPS 저장 transaction 성공 뒤 화면을 즉시 갱신하며, 다른 JS 인스턴스/재진입을 위한1초 폴링을 유지한다. 합류/복귀 선은 실제 주황 궤적 아래다. GPS 필터·공백·완주 판정·기록·계정 소유권은 바꾸지 않는다.

관련 회귀: `home`, `saved-course-presentation`, `running-chooser`, `archive`, `runs`, `badge-gallery`, `course-generation`, `run-recording-refresh`, `guidance-trail`; Node `road-address`, `running-controller`, `archive-retry`, `home`. 기존 홈의 무작위 추천·변경된 보관함 전체 프레임 기준은 후속이며 제품 영역 마스크/허용오차로 통과시키지 않는다. 사용자 지시로 PR59 draft/main 미병합을 유지한다.

## 2026-11-13 시뮬레이션 trace snapshot

loop/legacy 엔진의 공개 trace는 copy-on-write로 갱신한다. 같은 배열의 push/splice는 배포 React Compiler가 GuidanceMap 하위 JSX를 재사용해 주황선을 첫 점에 고정시키므로 금지한다. 이전 snapshot/좌표는 다음 입력으로 바뀌지 않아야 한다. `guidance-trail`은 실제 Android/Hermes production Babel/React Compiler로 부모 컴포넌트를 변환한 회귀를 포함한다. Map/Camera/단일 source ID와 파랑3/주황7 순서는 유지한다. Handset44/SM-A102N 시뮬레이션 같은 화면 연속 이동에서 즉시 주황선 확인, 앞선42/43 미해결 이력은 실행 기록에 보존했다. 야외 GPS 검증으로 확대 해석하지 않는다.

## 2026-11-13 준비·미완주 이어달리기·공유

준비 안내의 확인은 최신 정확한 위치와 유효한 도보 합류 경로(코스 위는 경로 불필요)가 준비된 뒤 활성화한다. 준비 중/오류·재시도를 표시한다. 미완주 코스의 다음 시도는 같은 소유자/동일 snapshot의 이전 진행·주황 궤적·활동 시간을 복사해 이어 달리며 이전 종료 기록은 수정하지 않는다. 중단 구간은 새 segment로 분리한다. 실제 GPS와 시뮬레이션은 서로의 기록을 이어받지 않고, 이미 완주한 코스는 새 도전이다. 이는 과거 ‘종료 후 항상 처음부터’ 계약보다 우선하는 사용자 변경이다. 시뮬레이션 저장 판정은 소유권/코스 해시를 확인한 DB checkpoint를 이어받고 새 위치를 재검증한다. 호출자가 제공한 완주 플래그는 받지 않는다. 음성은 옵션이 켜진 경우 회전30m 전 방향당1회, 거리 갱신/일반 상태 문구로 반복 발화하지 않는다.

스토리/세로 저장 카드는 중앙 타이틀과 주소/원본 브랜드 이미지가 동일하다. 공유 링크는 서버의 실제 URL 전체를 줄바꿈해 표시하며 웹페이지 버튼은 해당 URL을 브라우저로 연다. 링크가 없을 때는 기존 공개 확인 후 생성하므로 보기만 해도 경로를 공개하지 않는다. 추천 재설정은 삭제 안내 후 설정으로 이동하며 즉시 계산/횟수 차감하지 않는다.

## 2026-11-13 사용자 재보고 후속

준비 안내는10초 내 도보 경로를 준비하지 못하면 요청을 끊고 실패 문구 후 지도 준비로 진행한다. 실패 후 GPS 러닝을 자동 시작하지 않는다. checkpoint가 없는 동기화 복원 기록도 실제 points/segment에서 복구해 미완주를 이어받으며, 원본과 같은 hash의 재저장 코스도 지원한다. 시뮬레이션 재개는 기존 선을 보여주는 일시정지로 열고 계정의 음성 설정을 따른다. 한국어 TTS는 setLanguage 후 음성을 선택하고 offline 우선/기기 대체 엔진을 지원한다.

링크 탭 선택은 해당 기록의 실제 공유 URL 준비 동작이며, 준비 후 주소와 브라우저 열기를 연결한다. 다른 이미지 탭은 자동 공개하지 않는다. 추천 상세의 경고 확인은 기존 조건을 채운 설정으로 이동만 하고 계산/차감하지 않는다. 앞선 자동재계산·checkpoint필수·시뮬레이션 voice:false 고정은 이 변경으로 대체한다.
