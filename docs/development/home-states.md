# S1 홈 3상태

2026-10-13 구현 중. Figma `2:855`, `2:1168`, `5:73`의 현재 컨텍스트/스크린샷을 조회했다. 상하단은 S0 공통 표현을 재사용한다.

## 상태와 데이터 계약

인증 확인과 홈 조회가 끝나기 전에는 로딩을 표시한다. 조회 실패는 오류·재시도를 제공하며 첫 방문으로 처리하지 않는다. 현재 계정의 활성 러닝이 있으면 진행 홈, 없고 종료 기록이 있으면 기록 홈, 두 가지 모두 없으면 초기 홈이다. 저장 코스만 있는 경우도 초기 홈에서 보관함으로 갈 수 있다.

- 초기: 원본 소개 이미지와 하트/물고기 선택 → 기존 생성 화면에 선택 도형을 한 번 전달한다. 이후 일반 탭 이동이 변경한 도형·거리·계산 결과를 덮지 않는다. 강아지는 원본 아이콘을 보존하고 비활성/준비 중으로 표시한다. 기존 엔진의 도형 확장은 S2다.
- 진행: 실제 running/paused/interrupted 상태·코스 이름 또는 자유 러닝·시작일·거리·진행률을 표시한다. 홈 버튼은 기존 러닝 화면 이동만 수행한다. 중단/일시정지를 홈에서 자동 재개하지 않는다. 여러 날의 별도 세션을 합산하는 도전은 S4 후속이다.
- 기록: 종료한 러닝의 최근 거리/시작일, 이번 달 거리, 최근 3개의 실제 GPS 경로·거리·활동시간·상세 이동을 제공한다. 완주와 중도 종료·자유 러닝을 모두 실제 저장 기록으로 취급하며 완주라고 오표시하지 않는다.

월간 집계는 **조회 시점 기기 시간대의 달력 월, 세션 시작일 기준**, 하한 포함/다음 달 시작 제외다. 자정을 넘는 세션을 일별 좌표로 분할하지 않는다. 종료한 세션만 포함하며 조회 목록의 3/30개 제한과 무관하게 SQL로 전체 합산한다. 기록 삭제·동기화 반영 후 다시 조회한다. S5 성취/연속일 산식은 별도다.

코스 진행률은 저장된 안내 체크포인트의 `progressM / totalM`이다. 실제 이동 거리로 나누지 않는다. 접근/이탈을 포함한 이동 거리와 코스 길이를 구분해서 표기한다. 자유 러닝은 백분율 대신 활동시간을 표시한다. 코스 사본/안내 정보가 손상돼도 활성 기록과 복귀 동작은 유지하며 오류를 표시한다.

## 소유권과 수명

`modules/home/repository.ts`는 기존 SQLite를 한 번의 읽기 트랜잭션으로 조회하고 시작/끝/반환 시 계정 범위를 대조한다. DB 스키마·소유권·동기화 계약·사용자 기록은 변경하지 않는다. `use-home.ts`는 포커스 중 전경에서 조회하고 2초마다 갱신한다. 계정 변경 시 바로 이전 자료를 숨기고 화면 이탈/계정 변경 전 시작한 늦은 응답을 버린다. 기존 루트의 인증·러닝 복원 감시를 중복 설치하지 않는다.

미리보기는 실제 저장 좌표를 로컬에서 그리며 배경 지도/위치 권한/온라인 호출을 요구하지 않는다. 진행 중 코스는 시작 당시 코스 사본, 자유 러닝과 최근 기록은 실제 GPS 궤적이다. GPS 세그먼트 간 공백은 연결하지 않고 홈에서는 약 240점으로 제한한다. 원본 위치 자료는 서버/진단 로그에 추가 전송하지 않는다.

## Figma 적용과 후속

원본 소개 이미지·도형·달력·운동화·트로피·더보기 화살표는 `assets/home/`에 저장한다. SVG는 원본 root 크기와 도형 슬롯의 overflow를 보존한다. 소개 이미지의 원본 마스크/크롭 비율을 반응형 컨테이너로 옮긴다. 실제 기록을 예시 지도 사진으로 대체하지 않는다.

상단 상품 잔량/한도는 S7, 다일 도전은 S4, 연속일/배지는 S5다. 추천 코스 공급/선정 기준이 없어 예시 ‘한강 시민 공원/45분’을 만들지 않으며 현재 생성 기능으로 연결한다. 홈의 선택은 지원 도형 추천이며 이미 계산된 코스 추천이 아니다. 게스트 가입 안내는 기존 결정대로 홈·마이페이지에만 유지한다.

운영 약관/회원 DB 적용과 휴대폰 설치는 이번 홈 구현의 범위 밖이다. 실제 검증·남은 항목은 작업 종료 시 검증 문서에 기록한다.
