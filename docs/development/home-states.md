# 홈 두 상태와 공통 인증 차단

2026-10-24 사용자 확정 계획을 적용한다. 이전 S1 3상태·게스트 허용 계약은 이 문서로 대체한다. 구현·검증 상태는 [검증 기록](../quality/home-auth-20261024.md)을 따른다.

## 접근과 이동

루트 `ServiceStack`에서 인증 확인 중에는 로딩만 표시한다. 비로그인 공개 경로는 `account-entry`, `auth/callback`, `service-policy`뿐이다. 가입 화면에서 로그인으로 전환하며 게스트 입장 버튼은 없다. 홈·탭·상세·운영 안내·개발 화면은 `Stack.Protected`에 등록한다. 경로 목록 검사는 새 페이지가 차단 밖에 자동 등록되는 실수를 검출한다.

서비스 진입 조건은 **로그인 계정 존재**다. 가입 정보·약관 안내는 기존 MembershipPrompt를 유지하며 동의 완료로 진입을 막지 않는다. 인증 콜백은 공통 인증 처리 완료를 기다린 후 홈 또는 가입 화면으로 이동한다. 로그인/로그아웃/직접 계정 전환은 내비게이션 컨테이너의 서비스 이력까지 초기화한다. 재시작 시 유효한 세션이 있으면 허용된 딥링크를 열 수 있다.

기존 게스트 자료를 삭제하거나 자동으로 귀속하지 않는다. 계정별 SQLite 조회·동기화 소유권을 재사용한다. DB 스키마, 서버 API, 공개 공유 웹·계산 서버 인증은 변경하지 않는다.

## 홈 데이터

| 상태 | 현재 로그인 계정 자료 | 구성 |
| --- | --- | --- |
| 처음 이용 | 저장 코스 0, 러닝 0 | 인사, 원본 소개 이미지, 하트/물고기/강아지, 전체보기, 생성 버튼 |
| 재방문 | 저장 코스 또는 러닝 존재 | 인사, 통계 3개, 최근 러닝/저장 코스, 생성 버튼 |

진행/일시정지/중단 러닝도 포함하며 전부 삭제하면 처음 이용으로 돌아간다. 별도의 이어달리기 홈·복귀 배너는 없다. 조회 실패는 오류/재시도이고 빈 기록이 아니다.

- 처음 이용은 하트 기본 선택. 생성 버튼이 선택 도형을 한 번 전달한다. 전체보기는 기존 생성 화면의 조건/도형 영역을 연다. 일반 탭 이동으로 이후 편집한 조건을 덮지 않는다.
- 통계: 가장 최근 시작한 종료 러닝의 실제 거리/시작일, 기존 성취 모듈의 현재 연속일, 이번 달 종료 러닝 누적 거리. 달력 월·기기 시간대·시작일 기준은 기존 계약을 유지한다. 종료 기록이 없으면 `— / 0일 / 0km`.
- 최근 러닝: 미종료 먼저, 각 그룹 시작일/ID 내림차순, 최대 3개. 실제 거리·활동시간·시작일을 표시한다. 코스 러닝 `courseOutcome=finished`만 완주, 나머지는 미완주. 자유 러닝은 배지 없음.
- 미종료 카드는 `/run` 이동만 하며 자동 재개하지 않는다. 종료는 `/runs/[id]`, 중도 종료 재도전은 기존 상세 기능을 사용한다.
- 최근 저장 코스: 저장일/ID 내림차순 3개. 이름·거리·저장일을 표시하며 가상 활동시간을 넣지 않는다. `/courses/[id]`로 이동한다.
- 더보기는 `/courses?view=runs|courses`로 이동한다. 빈 목록은 각각 안내한다.

한 읽기 트랜잭션의 시작/끝/반환 때 소유권을 확인한다. 포커스·앱 전경에서 2초마다 갱신하며 계정 변경/화면 이탈 전 요청의 늦은 응답은 버린다.

## 지도와 표시

러닝은 실제 GPS 좌표만, 저장 코스는 저장 snapshot 경로만 사용한다. GPS segment 사이를 연결하지 않으며 약 240점으로 줄여도 각 구간 양끝을 보존한다. 손상된 저장 경로는 카드와 상세 진입을 유지하고 미리보기 오류를 표시한다.

카드가 보이고 홈 포커스·앱 전경일 때만 조작 불가 MapLibre 지도를 올린다. 같은 경로의 재조회는 네이티브 지도를 재생성하지 않는다. 키 없음/오프라인/지도 오류/12초 로딩 초과 시 로컬 SVG 실제 경로로 대체한다. 합성 개발 경로에는 실지도를 사용하지 않는다. MapTiler/OSM 출처는 목록에 유지한다.

기본 3열, 작은 화면 2열, 글꼴 1.4배 이상 1열이며 큰 글씨 통계는 세로 배치한다. 기존 두 테마·상단 로고/메뉴·하단 5탭을 재사용한다. 상품 이용량/한도 수치는 보류한다. Figma UI `2:855`, `5:73`과 제공된 두 이미지를 기준으로 원본 자산을 사용한다. 예시 닉네임·지도·통계는 실제 계정 데이터로 바꾼다.

휴대폰 설치·운영 배포·코스 생성/배지/공유의 전면 개편은 별도 후속이다.
