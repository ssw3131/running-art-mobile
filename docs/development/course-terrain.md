# 코스 지형 표시

코스 만들기의 **선택한 후보**와 **저장 코스 상세**에서 ‘경사 보기’를 누르면 고도를 조회한다. 계산·추천 순위·코스 좌표·저장 파일·러닝 방향 설정은 바꾸지 않는다. 합성 진단 코스와 모의 주행에는 표시하지 않는다.

## 사용자 표시

- 청록: 완만(절댓값 3% 미만), 황토: 경사 있음(3% 이상~6% 미만), 보라: 가파름(6% 이상). 색상과 함께 범례를 제공한다. 운동 난이도·도로 통행 가능 판정이 아니다.
- ‘총 오르막’은 보정한 고도에서 양의 변화량을 합한 값이다. 순환 코스의 출발·도착 고도 차이와 구분한다.
- 고도 그래프는 거리(km)·고도(m)를 표시한다. 누르거나 좌우로 움직이면 지점·고도·구간 경사도와 지도 점이 바뀐다. 스크린리더의 다음/이전 지점 조작도 지원한다.
- 지도에는 그래프 기준점과 진행 화살표를 표시한다. ‘방향 바꾸기’는 그래프와 경사 부호만 반전하고 선택 지점의 실제 위치를 유지한다. 경사 색상은 방향에 무관하다.
- 고도는 MapTiler DEM 기반 추정치다. 다리·터널 등 실제 도로 높이와 다를 수 있다는 안내와 출처 링크를 제공한다.

## 데이터와 수명

기존 `EXPO_PUBLIC_MAPTILER_API_KEY`로 앱이 [MapTiler Elevation API](https://docs.maptiler.com/cloud/api/elevation/)를 직접 호출한다. 2026-10-10 현재 키의 HTTP 200과 실제 다중 요청을 확인했다. API는 요청당 최대 50좌표를 받으며 좌표별로 사용량을 산정한다. 요금제·키·서버 설정은 변경하지 않는다.

`src/modules/terrain/`은 표본화·분석, 조회, 화면 요청 수명을 분리한다. 약 50m 간격의 균등 누적 거리 표본을 최대 201개 생성한다. 긴 코스는 간격을 늘린다. 순환 코스의 중복 끝점은 조회하지 않는다. 인접 3점 이동평균을 쓰며 순환 경계를 연결하고 열린 코스의 양 끝 고도는 유지한다. 경사도는 고도 변화/수평 이동 거리×100이다. 지도 구간에는 중간의 원래 도로 꼭짓점을 모두 보존한다.

사용자가 선택한 코스에서 요청할 때만 조회하며 자동 선조회·자동 재시도는 없다. 최대 50좌표씩 순차 호출하고 전체 조회 시간 제한은 20초다. 응답 개수·순서·좌표·숫자·범위를 검사한다. 누락·오류·취소된 결과는 저장하거나 0m로 표시하지 않는다. 한도·설정·연결·응답 오류는 패널에만 표시하고 기존 저장·러닝 기능을 유지한다.

완료 결과만 앱 프로세스 메모리에서 최대 16코스 재사용한다. 재실행하면 사라지며 DB·파일·동기화에 넣지 않는다. 이미 조회한 결과는 같은 프로세스에서 인터넷 없이 다시 열 수 있지만 영구 오프라인 기능을 의미하지 않는다. 후보 변경·화면 이탈·백그라운드 이동은 요청을 취소하며 오래된 응답을 무시한다. 키나 요청 URL·좌표를 오류/진단 로그에 출력하지 않는다.

고도 HTTP 요청에 `Cache-Control: no-cache, no-store`를 지정한다. React Native Android의 기본 OkHttp 디스크 캐시가 재실행 뒤 응답을 다시 사용하는 것을 실제 에뮬레이터에서 발견해, 고도 조회만 해당 캐시를 사용하지 않도록 했다. 배경 지도·도로 캐시 정책은 그대로다.
