# 실제 러닝 경로 링크 공유

2026-10-04 사용자 결정 기준. [적용·검증 상태](../quality/run-link-sharing-verification.md)를 함께 확인한다.

## 사용 흐름

로그인한 계정의 동기화를 켜고 종료한 러닝 상세에서 **링크로 공유**를 누른다. 공유 범위를 확인하면 서버 동기화 후 링크를 만들고 기기의 공유 창을 연다. 공유 창 취소는 이미 만든 링크를 없애지 않으며 **공유 중단**으로 끌 수 있다. 다시 공유하면 새 링크를 발급하며 이전 링크는 살아나지 않는다.

수신자는 앱 설치·로그인·GPX 다운로드 없이 웹 지도를 본다. 실제 GPS 경로, 출발 당시 도로에 맞춘 계획 코스, 그때 지도에 배치한 원래 도형을 동시에 표시한다. 색·선 모양과 개별 토글로 구분하며 전체 경로 보기로 범위를 맞춘다. 코스 없는 자유 러닝에는 실제 경로만 표시한다. 일시정지·GPS 공백을 선으로 연결하지 않는다.

공개 내용은 코스 이름 또는 기본 제목, 실제 거리·활동 시간과 세 경로 좌표다. 계정 ID·이메일·GPS별 시각·정확도·원본 저장소 경로는 제외한다. 링크를 가진 사람은 해당 경로를 볼 수 있으므로 앱에서 공개 범위를 확인한다. 개인 기록이나 파일 전체를 공개하지 않는다.

오프라인 로컬 삭제의 공유 중단은 서버 동기화 뒤 반영된다. 즉시 중단하려면 온라인에서 먼저 **공유 중단**을 누른다. 탈퇴 준비가 시작되면 공개 조회를 차단하며 계정 삭제 시 공유 사본도 제거한다.

## 구현·저장 계약

- `src/modules/run-sharing`: 공개 사본 검증, 계정 고정·전환 차단, 동기화 확인, 서버 응답 확인 후 링크 반환. 개인 동기화나 비로그인 기록 귀속을 임의로 켜지 않는다.
- `RunSharePanel`은 기존 러닝 상세에 연결한다. 기존 저장 코스의 GPX 내보내기는 유지한다.
- 공유 SQL은 기존 개인 기록·탈퇴 마이그레이션 이후 적용한다. 소유자만 생성/조회/해제하고 익명 사용자는 토큰별 읽기만 가능하다. 직접 테이블 열람·목록 조회를 허용하지 않는다.
- 토큰은 64자리 무작위 값이다. URL fragment에 보관해 웹 호스트·지도 요청에 전달하지 않는다. 동일 기록의 재시도는 같은 토큰을 반환한다.
- 원본 동기화 삭제·내용 변경 시 기존 공유를 지운다. 기존 링크가 새 좌표를 자동으로 공개하지 않는다.
- `web/run-share`는 독립 정적 웹이며 빌드에 사용자 좌표를 넣지 않는다. MapTiler 부분은 `map-provider.js`로 분리했다. 공급자 변경 시에도 좌표·링크를 유지할 수 있지만 앱 지도 변경만으로 웹 지도가 자동 변경되지는 않는다.
- 실제 좌표 최대 100,000점, 계획/원형 각각 20,000점, JSON 최대 8 MiB다. 제한 초과·자료 불일치 시 원본을 보존하고 오류를 표시한다.

## 배포·검증

현재 공개 주소는 **https://runpen-shared-runs.ssw3131.workers.dev/** 이다. 2026-10-04 사용자가 직접 배포했고 정적 파일·헤더·실제 합성 링크의 지도/공유 중단을 확인해 원본 앱에 연결했다. 임시 계정/자료를 정리했으며 PC·서버·웹 검증은 완료했다. 기본 주소는 안내 화면이고 앱에서 만든 `#r/…` 링크가 특정 기록을 보여준다. 아래 1~3은 최초 설치 절차다. 휴대폰 설치 결과와 남긴 후속은 [검증 기록](../quality/run-link-sharing-verification.md)을 따른다.

1. 기존 Supabase에 `20261004074000_run_shares.sql`을 한 번 적용한다. 적용한 서버에 재실행하지 않는다.
2. 공개 Supabase URL/publishable key와 공개 MapTiler 키를 `.env.local`에 준비하고 `npm run build:run-share`를 실행한다. 서버 비밀 키를 웹에 넣지 않는다.
3. `build/run-share-web`만 Cloudflare Workers 정적 파일로 배포한다. `_headers`도 포함해 캐시 방지·referrer 차단·CSP·검색 제외를 적용한다. QA 도구·합성 자료는 배포하지 않는다. CLI 설정은 `infra/run-share/wrangler.jsonc`다.
4. 공개 HTTPS 주소의 안내·지도·공유 중단을 검증한 뒤 앱의 `EXPO_PUBLIC_RUN_SHARE_URL`을 설정한다. 미설정 시 준비 중으로 안내한다. 가정한 URL로 활성화하지 않는다.
5. `npm run test:run-sharing`, `npm run test:run-sharing-server`, `node --env-file=.env.local scripts/qa/run-sharing-http.mjs`, `dev.ps1 check`, Android 번들을 확인한다.

로컬 SQL 검사는 기존 계정 QA의 PGlite 설치를 재사용하며 `RUN_SHARE_PGLITE_MODULE`로 위치를 지정할 수 있다. 서버 SQL 검사는 합성 계정만 사용하고 트랜잭션을 롤백한다. `scripts/qa/share-web-server.mjs`는 loopback 전용 합성 자료·명시적 요청 대역으로 화면만 검증한다. 이를 실제 호스팅 링크 검증으로 보고하지 않는다.

새 공유 페이지의 GPX 다운로드·이미지 공유는 이번 범위에서 제외한다. 장소 검색은 제품 계획에서도 제외한다.
