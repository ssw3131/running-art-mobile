# S0 서비스 내비게이션

2026-10-12 S0의 서비스 구조와 5탭을 유지한다. 2026-10-24부터 공통 인증 차단과 홈 두 상태는 [현재 홈 계약](home-states.md)을 따른다. [S0 계획](../planning/service-implementation.md)·[당시 실행 기록](../history/executed-plans/2026-10-12-1942-service-s0.md).

## 경로와 책임

| 진입 | 경로 | 연결 |
| --- | --- | --- |
| 홈 | `/` | 실제 계정 인사·코스/기록 진입·진행 중 러닝 복귀 |
| 코스 생성 | `/route-lab` | 기존 지도 중심·도형/거리·계산/취소·후보·저장. 탭 이동 때 진행 계산은 취소하고 입력/완료 결과는 유지 |
| 실시간 러닝 | `/run`, `courseId` | 기존 코스 준비·실제 GPS·일시정지/재개·종료. 탭 진입만으로 기록을 시작하지 않음 |
| 기록 보관함 | `/courses?view=courses` 또는 `view=runs` | 기존 저장 코스·실제 러닝 목록을 공통 탭으로 선택 |
| 마이페이지 | `/account` | 기존 소셜·프로필·통계·설정·동기화·탈퇴 |
| 상세 | `/courses/[id]`, `/runs/[id]`, `/account-*` | 루트 Stack에 표시. 상세의 뒤로는 기존 탭 상태로 복귀 |
| 호환 진입 | `/runs`, `/auth/callback` | 기존 러닝 목록 직접 경로와 소셜 복귀 경로 유지 |
| 안내 | `/service-info` | 사용 가능한 코스/보관함/계정 진입·실제 버전·개발 도구. 상세 소개/문의/약관 콘텐츠는 S6 |
| 개발 | `/development` | 이전 홈의 지도·도로·저장소·모의 안내·개발 환경 진입 유지. UI 미리보기는 개발 환경에서 연결 |

`src/app/(tabs)`는 Router 연결만 담당하고 기존 화면은 `features`로 이동했다. `features/service`는 홈·보관함 합성·이동 책임, `components/navigation`은 데이터/라우터 없는 표현만 담당한다. 공통 `BottomTabBar`·`TopBar`·테마·로컬 폰트를 재사용하고 Figma 로고를 로컬 에셋으로 보관한다.

## 수명과 상태 보존

- 인증 최초 실행·콜백 URL 처리·앱 전경 갱신·동기화·러닝 복원 감시는 기존 루트에 한 번만 설치한다. 탭마다 새 서비스를 만들지 않는다.
- 계정 ID가 바뀌면 서비스 화면과 내비게이션 이력을 초기화해 이전 계정 자료가 남지 않게 한다. 같은 로그인 계정의 탭 이동은 화면을 유지한다. 비로그인 상태에는 서비스 탭을 표시하지 않는다.
- 하단 탭은 기존 route params를 병합해 이동한다. 코스 출발 준비의 `courseId`와 보관함의 `view`를 지우지 않는다. 탭 복귀 시 일반 러닝으로 바뀌던 현상을 실제 재현해 수정했다.
- 생성 화면 재진입 시 GPS로 중심을 덮어쓰지 않는다. 최초 위치 조회와 명시적 ‘내 위치’·설정 복귀를 구분한다. 떠나는 화면의 진행 계산/위치 요청은 취소한다.
- 상세/안내/인증 콜백에서 탭으로 이동할 때 `openServiceTab`/`ServiceTabLink`로 상세 스택을 닫고 기존 탭으로 이동한다. `replace('/account')` 등으로 새 탭 묶음을 만드는 방식은 사용하지 않는다. 취소 콜백으로 생성 입력이 초기화되는 현상을 실제 재현해 수정했다.
- 러닝 화면이 탭 전환 후 유지되므로 취소된 작업의 busy 상태도 해제한다. 출발 위치 준비는 요청 번호를 사용해 빠른 이탈/복귀의 오래된 응답이 새 요청을 덮지 않게 한다.
- 러닝 종료는 결과 상세를 push하고 코스 준비 파라미터를 해제한다. 결과에서 뒤로 가도 종료한 세션을 재시작하지 않는다.
- 루트 복원 오류는 상태바 아래에서 재시도할 수 있다. 계정이 바뀌면 이전 오류를 표시하지 않는다. 시작 감시에 실패했다고 기록을 삭제하거나 GPS를 자동 재개하지 않는다.
- 코스 상세 이름 편집은 키보드가 표시되면 실제 상단 바 위치를 포함해 입력칸을 위로 스크롤한다. 큰 글씨에서 키보드에 일부 가리던 현상을 보완했다.

## 적용 범위

상하단 공통 UI와 안전 영역을 서비스 루트에 연결했다. 기존 생성·러닝·계정 본문의 스타일은 해당 S2~S6 이관 단계까지 재사용한다. 홈의 미구현 상품 잔량/저장 한도, 배지·추천·통계 예시 숫자는 표시하지 않는다. Android 우선이며 iOS·실물 휴대폰 설치·야외 정확도는 별도다.

이 변경은 앱 ID·서명·SQLite v7·코스/러닝 형식·Supabase/Cloud Run/R2 계약을 변경하지 않는다. 실제 출시 범위·상품 정책을 확정한 것으로 해석하지 않는다.
