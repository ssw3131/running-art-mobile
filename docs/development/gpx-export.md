# 저장 코스 GPX 내보내기

저장된 코스를 GPX 1.1 파일로 만들어 Android 공유 창에 전달한다. 서버 계정·인터넷·GPS·재계산 없이 사용할 수 있다. 2026-10-01 구현·자동 검사·에뮬레이터 파일 전달을 완료했으며 후속 SM-S942N의 업데이트·실제 파일 전달·오프라인 취소/재시도도 확인했다.

## 사용 방법

1. 홈 → **저장한 코스** → 원하는 코스를 연다. 코스가 없으면 계산 결과에서 먼저 저장한다. **합성 격자**로도 확인할 수 있으나 가상 코스는 실제 달릴 길이 아니다.
2. 상세 아래 **GPX 내보내기**를 누르고 파일을 받을 앱을 선택한다. 이름을 바꾸려면 먼저 **이름 변경 저장**을 누른다. 입력 중인 이름이 아닌 DB에 저장된 최신 이름을 내보낸다.
3. 받은 앱에서 저장·가져오기 결과를 확인한다. **공유 창을 닫았어요**는 Android 창이 닫혔다는 뜻이며 파일 저장 성공을 확인한 메시지가 아니다. 취소한 뒤 다시 내보낼 수 있다.

파일에는 출발 위치와 전체 경로가 들어간다. 파일명은 `running-art-코스이름-ID앞8자리.gpx` 형태이며 파일명에 사용할 수 없는 문자는 바뀐다. GPX 내부에는 원래 코스 이름을 보존한다. 파일을 받을 수 있는 앱과 저장 방식은 설치된 앱에 따라 다르다.

최신 로컬 설치 파일은 `build/install/running-art-0.1.0-20261001-gpx.apk`다. 기존 앱을 삭제하지 않고 업데이트하며 [APK 안내](android-test-apk.md)를 따른다. SM-S942N에도 00:56:22 KST에 이 GPX APK를 업데이트하고 기존 코스·메모 보존과 파일 전달을 확인했다.

## 데이터 범위와 처리

- 저장 경로의 모든 점·순서·중복점을 하나의 `trk/trkseg`로 보존한다. `[경도, 위도]`를 GPX의 `lat`·`lon` 속성으로 변환하고 경로를 단순화하거나 반올림하지 않는다. 목표 도형은 포함하지 않는다.
- GPX는 **예정 코스**다. 실제 러닝 시각·속도·고도를 만들어 넣지 않는다. OSM 코스에는 출처·ODbL 링크를, 합성 코스에는 가상 테스트 안내를 넣는다.
- GPX 범위가 제외하는 경도 `+180`은 같은 자오선인 `-180`으로 표시한다. 지수 표기는 소수로 풀고, 소수점 이하 20자리를 넘는 값은 호환성을 위해 오류로 안내한다. 극소 좌표를 임의 반올림하지 않으며 DB는 변경하지 않는다. 이는 앱의 호환 범위이며 GPX 표준의 20자리 제한을 뜻하지 않는다.
- 기존 코스 검증과 SHA-256 확인을 거친 최신 DB 자료만 읽는다. 손상·삭제·더 최신 형식의 자료는 내보내지 않는다. 기존 DB 스키마 2와 저장 자료는 유지한다.
- 내보내기 동안 이름 변경·삭제·중복 실행을 막는다. 파일 작성 전후 화면 이탈은 취소 처리하고 늦게 도착한 결과를 다른 화면에 표시하지 않는다.
- 파일은 앱 캐시의 개별 임시 폴더에 만든다. 수신 앱이 읽는 동안 지우지 않도록 공유를 시작한 파일은 유지하고, 이후 내보내기 때 24시간이 지난 내보내기 폴더를 정리한다. 운영체제는 캐시를 더 일찍 회수할 수 있으므로 영구 백업은 수신 앱에서 저장해야 한다.

`src/modules/courses/gpx.ts`가 GPX 생성, `export.ts`가 취소·중복·오류 처리, `share-gpx.ts`가 Expo 파일·공유 연결을 맡는다. `expo-file-system/legacy`의 비동기 UTF-8 API와 `expo-sharing`을 사용한다. 추가 저장소 권한이나 서버 업로드 API는 없다. 웹은 Android 확인 안내를 표시하며 iOS 빌드·공유는 미검증이다.

검증 방법·결과·타사 앱 호환성의 확인 범위는 [GPX 검증 기록](../quality/gpx-export-verification.md)에 있다. GPX 가져오기·회원 동기화·커뮤니티 공개는 별도 후속 기능이다.
