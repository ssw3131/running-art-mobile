## 코스 생성

- 서비스 선택은 하트·별·강아지·고양이·사람·물고기·뼈다귀·거북이·아이스크림·딸기·구름·왕관, 목표 거리 1~10km(1km 간격). 기존 토끼/집/다이아몬드/번개/화살표 ID와 저장 자료는 읽기·재도전을 유지한다.
- 기존 v0.2 도형과 계산 산술은 보존하고 새 도형 좌표만 별도 모듈로 추가한다. 도로 탐색 반경은 2km를 유지하는 구현 선택이다. 긴 목표 거리·도로 형태에 따라 0~5개 후보가 나오며 실제 길이는 목표와 다를 수 있다.
- 실제 거리·추천 순위·경사를 표시한다. 유사도%·예상 시간·난이도·혼잡도·잔량은 표시하지 않는다. 원시 점수는 개발 검증용이다.
- 이미지 선택은 시스템 선택기/자르기 → 기기 내 최대 192px PNG → 배경과 구분되는 가장 큰 외곽선 → 4단계 윤곽 기준/미리보기/다시 그리기 → 명시적 적용이다. 빈 그림·큰 독립 모양 여러 개·배경 여백 없음은 재선택을 안내한다. 구멍·내부 선은 코스에 포함하지 않는다.
- 선택 이미지 최대 64MP/30MB, 디코더 최대 256px/8bit 비인터레이스 PNG로 제한한다. 방향 보정·일반 사진 형식 처리는 네이티브 이미지 처리기에 맡긴다. 추출 결과는 기존 custom v3 윤곽이다. 원본 파일을 서버에 올리지 않으며 계산에는 윤곽 좌표만 보낸다. 변환 임시 PNG는 처리 후 삭제한다.
- 취소/화면 이탈/계정 변경 뒤 늦게 돌아온 선택 결과는 적용하지 않는다. 시스템 선택기 취소는 이전 윤곽을 보존한다. 편집·미리보기만으로 코스가 저장되거나 계산되지 않는다.
- 서버 입력 검증과 OpenAPI는 새 범위를 수용한다. 운영 서버가 아직 이전 버전인 동안 새 조건 거부는 기존 기기 계산 전환 경로로 처리된다. 운영 배포를 이 구현의 검증 완료로 간주하지 않는다.

## 보관함과 재도전

- 저장 코스와 실제 러닝 기록은 별도 탭이다. 러닝 기록에는 완주·중도 종료·자유 러닝·진행/중단 기록을 모두 표시하고 기기 달력의 시작일 기준 연월로 묶는다. 각 목록은 30개 단위로 추가 조회한다.
- 저장 코스 상세: 저장 경로·실제 거리·목표 거리·원본 형상·경사·이름 변경·GPX·러닝 준비·삭제. 검증되지 않은 ETA/난이도와 가짜 출발 주소는 없다.
- 코스 삭제는 보관함 설계만 지운다. 이미 시작한 러닝의 불변 코스 사본/진행률/실제 GPS와 과거 기록은 남는다. 기록 삭제는 별도 확인하며 기존 공유·동기화 정리 규칙을 유지한다.
- 종료한 코스 러닝의 ‘이 코스 저장·재도전’은 당시 사본을 명시적으로 저장(동일 사본 중복 제거)한 뒤 준비 화면을 연다. 원본 코스가 삭제됐어도 가능하다. 준비 화면에서 GPS 시작을 다시 확인해야 새 세션을 만든다. 활성 러닝이 있으면 먼저 재개/종료하도록 안내한다.
- 이전 세션의 거리·완주 결과·이름은 재도전으로 수정하지 않는다. 계정 전환 시 이전 목록/상세와 진행 중 조회 결과를 숨기고 새 범위를 다시 읽는다. 게스트 자료는 자동 병합하지 않는다.

## 러닝

- 한 번의 러닝에서 순환 코스 한 바퀴를 완주한다. 종료하면 다음 날도 새 도전이다. 여러 종료 기록의 구간/거리를 합쳐 완주로 인정하지 않는다. 일시정지·프로세스 중단 체크포인트 복원과 명시적 재개는 유지한다.
- 실제 코스 안내에 지도/집중 모드를 연결한다. 집중 모드는 정상 초록·이탈/복귀 주황·GPS 대기/일시정지 남색이며 안내 엔진의 실제 방향·진행/남은 거리와 저장 거리/활동 시간/평균 페이스를 사용한다. 합류·복귀 경로 오류는 재조회한다.
- 일시정지·재개·종료 조작은 스크롤 밖에 고정한다. 설정은 화면 모드·음성·화면 꺼짐 중 기록을 현재 세션의 기존 guidance_options_json에 저장하며 재실행 뒤 복원한다. OS 위치 권한 설정은 별도다.
- 터치 잠금은 앱의 모달로 오작동을 막으며 GPS/음성/백그라운드 설정을 바꾸지 않는다. 0.8초 길게 누르기·기기 뒤로·접근성 활성화로 해제한다. 앱 재시작 때는 잠기지 않는다. OS 화면 잠금이나 화면 켜짐 유지 기능과 구분한다.
- 화면 꺼짐 중 기록을 끄면 백그라운드에서 일시정지하며 복귀 후 직접 재개한다. 완주 도착은 확인 대기, 명시적 종료·저장 후 완주 기록이 된다. S5 배지/칼로리·S7 구매는 이번 범위가 아니다.
