# 진행 중 코스 우선 정렬

2026-11-22 사용자 결정과 Figma `697:2991`을 반영한다. 과거 ‘미완주/진행 중을 같은 그룹에서 저장 최신순’보다 이 계약을 우선한다.

- 홈 저장 코스, 보관함 저장 코스, 러닝 코스 선택은 같은 정렬을 사용한다: 진행 중(러닝·일시정지·중단 복구) → 종료한 미완주 → 완주/미시작.
- 각 그룹 안에서는 저장 시각과 ID 내림차순을 유지한다. 코스의 최신 시도 판정은 활성 시도를 우선하고, 종료 시도는 실제 종료 시각을 우선한다.
- 계정 ID를 제한한 뒤 코스 ID 또는 불변 사본 해시로 관련 시도를 찾는다. 다른 계정의 시도나 같은 도형이라는 이유만으로 연결하지 않는다.
- SQL 정렬 후 페이지 범위와 홈 최대5개를 적용한다. 오래전에 저장한 진행 코스도 최근 미완주6개 이상에 밀려 첫 페이지에서 사라지지 않는다.
- 세 목록의 상태는 `진행 중` 또는 `미완주`다. 선택 테두리는 상태 태그와 독립적으로 유지한다.
- 목록 조회·선택·상세 열기는 GPS를 시작하거나 기록·설정·생성/저장 횟수를 변경하지 않는다. 완주 후 다음 조회에서 순위와 상태가 갱신된다.

검사: `tests/course-priority.test.mjs`, `tests/home.test.mjs`, UI `home`, `archive`, `running-chooser`. 실행 근거와 필수 Android/PR/main 상태는 [실행 기록](../history/executed-plans/2026-11-22-1016-course-packs-policy.md)을 따른다.
