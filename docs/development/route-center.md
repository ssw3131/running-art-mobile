# 지도 중심으로 코스 계산하기

**주변 OSM**은 선택한 중심 주변 2km의 도로 파일을 기기에 저장하고 v0.2 엔진으로 계산한다. 현재 앱 소스는 개발용 R2 전국 채널을 사용한다. 한국 OSM 추출본의 조회 중심 지원 범위는 위도 [33,39), 경도 [124,132)이며 도로 내용과 연결성은 해당 원본 기준이다. [전국 공급](national-roads.md)·[전국 검증](../quality/national-roads-verification.md). 실제 휴대폰에는 아직 판교를 포함한 네 표본 APK가 설치돼 있고 전국 APK 설치·검증은 사용자 결정으로 후속이다.

## 사용 순서

1. 홈 → 코스 계산 테스트 → **주변 OSM**을 누른다. **서울 강남 / 부산 시청 / 구로·광명 / 판교 228번길 17 / 대전 시청 / 제주 시청 / 울릉도** 중 하나를 고르면 GPS 대기를 취소하고 해당 위치로 이동한다.
2. 지도를 움직여 중심을 바꿀 수 있다. 늦은 GPS 응답은 수동 선택을 덮어쓰지 않는다. **내 위치**를 누르면 다시 위치를 요청하며 지원 범위 밖이거나 저장 자료가 부족한 오프라인 위치는 실패로 안내한다. 도로가 없는 곳은 원본에 따라 빈 결과를 반환한다.
3. **저장 자료 우선 / 새 버전 확인 / 오프라인**을 선택한다. 첫 수신에는 인터넷이 필요하다. 저장 자료 우선은 요청 영역의 유효한 자료가 있으면 네트워크를 호출하지 않는다. 저장 목록에 없는 새 지역은 최신 목록을 확인한다. 새 버전 확인은 포인터·목록을 다시 확인하고 정상 파일을 재사용한다. 오프라인은 저장 자료만 읽는다.
4. 도형과 목표 거리를 고르고 **코스 계산하기**를 누른다. 지도·GPS 대기 중에는 계산을 막지만, 위치 버튼을 직접 선택하면 배경 지도 로딩 실패와 무관하게 계산할 수 있다.
5. 도로 조회·코스 계산·전체 시간과 계산 기준 좌표, 저장 자료/새 다운로드 수를 확인한다. 만료 또는 갱신 실패로 이전 자료를 사용하면 출처 설명에 표시한다.

지도 이동·내 위치·도형/거리·공급 모드 변경은 진행 중 작업을 취소하지만 완료된 경로·후보·시간·계산 기준은 보존한다. 다시 계산하거나 데이터 종류를 바꾸면 이전 결과를 초기화한다. 화면 이탈·백그라운드 전환도 진행 중 작업을 취소한다.

## 지도와 계산용 도로 자료

배경 지도는 MapTiler에서 받는다. 도로 파일은 모바일 전용 R2에서 받으며 기존 테스트 사이트 API·Overpass 대체 호출은 제거했다. 지도 이동만으로 도로 파일을 요청하지 않는다. 도로 파일이 저장되어 있어도 배경 지도가 완전히 오프라인으로 제공되는 것은 아니다.

공개 기본 주소는 `src/modules/road-data/channel.ts`에 있으며 `.env.local`의 선택적 `EXPO_PUBLIC_ROAD_BASE_URL`로 HTTPS 기본 주소를 바꿀 수 있다. 이전 `EXPO_PUBLIC_ROAD_DATA_URL`은 사용하지 않는다. 앱에는 공개 다운로드 주소만 포함하고 업로드 자격 증명은 넣지 않는다.

1. 별도 SQLite에서 공급자·매니페스트 해시·격자로 저장된 gzip 파일을 확인한다.
2. 필요한 경우 `roads/samples/v1/current.json`을 받아 같은 공급자의 불변 매니페스트 주소·크기·SHA-256·버전을 검사한다. 저장된 목록에서 누락 타일을 받을 때도 원본 매니페스트 해시로 같은 릴리스 주소를 사용한다.
3. Expo 스트리밍 전송으로 Content-Length·MIME·실제 크기를 확인한다. 리디렉션·Content-Encoding 변환을 거부하고 선언된 크기를 넘으면 중단한다. 포인터는 16 KiB, 매니페스트는 2 MiB, 개별 gzip은 형식 계약의 최대 8 MiB다.
4. 압축 전후 해시·도로 연결·전체 요청 범위를 검증하고 완전한 입력만 원자적으로 저장한다. OSM way 좌표·태그·노드 ID를 보존하며 계산은 휴대폰에서 실행한다.

조회 전체 제한은 65초다. 중간 실패·취소 시 부분 데이터를 저장하지 않고 자동 재시도나 다른 서버 호출을 하지 않는다. 취소가 SQLite 커밋 이후에 도착하면 이미 완료된 저장은 유지하되 늦은 화면 결과는 막는다. 상세 정책과 캐시 64 MiB·7일 기본값은 [영구 캐시 안내](road-cache.md)를 따른다.

## 시간과 원본 비교

| 표시 | 측정 범위 |
| --- | --- |
| 도로 조회 | 저장 조회 또는 다운로드·압축 해제·전체 검사·SQLite 저장 |
| 코스 계산 | 그래프 구성·탐색·화면 응답을 위한 실행 양보 |
| 전체 소요 시간 | 위 두 단계 합계 |

지도·GPS 대기는 계산 버튼 이전이므로 포함하지 않는다. `ROAD_DATA_ATTEMPT`는 성공/실패·조회 모드·시간·HTTP 요청 수·캐시 메타데이터를 기록한다. 캐시 적중도 요청 수 0으로 기록한다. `ROUTE_LAB_METRICS`는 계산 시간·그래프·후보와 `roadCache`를 남긴다. 선택/GPS 좌표와 지도 키는 측정 로그에 기록하지 않는다.

합성 격자·단절 테스트는 고정 표본을 유지한다. 합성 하트 5km·다이아몬드 3km는 원본과 비교한다. 움직일 수 있는 OSM 입력은 고정 광화문 원본과 비교하지 않는다. 고정 원본 회귀는 Node 테스트에 보존했다.
