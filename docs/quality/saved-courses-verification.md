# 로컬 코스 저장 검증

검증일: 2026-09-30 (Asia/Seoul). [실행 계획](../history/executed-plans/2026-09-30-1844-saved-courses.md)·[사용법](../development/saved-courses.md)·[기기 검증 요약](saved-courses-report.json).

## 자동 검사

Node 24.21.0에서 전체 **119개 테스트 통과**, 코스 신규 검사 10개를 포함한다. SQLite 대역이 아닌 `node:sqlite` 실제 DB로 다음을 확인했다.

- 기존 버전 1 DB의 메모를 유지하면서 버전 2로 업그레이드, 동시 초기화 공유.
- 기존 v0.2 회귀 자료의 코스 25개를 저장하고 경로·목표 도형·원점·반올림 전 거리·지도 표시 데이터를 전체 비교. 합성 격자와 서울 OSM 출처 구분.
- 호출자가 원본 배열·입력을 바꾸어도 저장 내용 유지, 같은 스냅샷의 동시 저장 시 ID·이름·개수 유지.
- 이름의 SQL 문자·유니코드 저장, 이름 변경 시 경로·최초 시각 보존, 선택 삭제와 없는 ID 처리.
- 최신 순서와 동일 시각의 ID 정렬·목록 페이지 구분. 목록은 전체 경로 JSON을 읽지 않음.
- 잘못된 이름·좌표·형식·출처·후보 없음·점 수 초과 거부.
- JSON·해시·요약 손상 격리, 정상 코스 조회 유지, 손상 코스 삭제.
- INSERT 뒤 실패 주입 시 트랜잭션 롤백과 재시도. 실제 기기 저장 공간을 채운 시험은 아님.
- 계산 중 다음 입력의 위치·도형·거리·도로 종류가 바뀌어도 완료 결과에는 처음 조건 유지.
- 파일 DB의 이름 변경·삭제 보존. 별도 프로세스가 미완료 삭제 트랜잭션 안에서 종료한 뒤 재열기 시 이전 상태 복원.

`dev.ps1 check`의 타입·린트 통과. `npm run export:android`의 1,401개 모듈·약 4.7MB Hermes 번들 생성 통과. 번들 파일은 `entry-537cd99abd9df777bcaeba3ecbaad842.hbc`다. 의존성·네이티브 패키지를 추가하지 않았다.

## Android 가상 기기

기존 `RunningArt_API_36` x86_64 AVD를 백그라운드로 시작했다. 기존 SQLite가 포함된 개발 APK에 최신 소스를 로컬 Metro 8087로 연결했다. 휴대폰에는 연결·설치하지 않았다. 합성 격자 하트 5km를 실제 계산했고 기준 비교가 허용 오차 안에서 일치했다. 이번 계산 35.98초는 개발 모드 단일 관측으로 제품 성능 측정이 아니다.

1. 1순위 코스를 저장하고 성공 안내·상세의 경로 그림을 확인했다. 실제 DB 스키마 2, 경로 151점·목표 도형 27점, 거리 5.400000000001176km·94점이다.
2. 이름에 `QARenamed`를 추가하고 저장했다. DB를 읽어 ID와 전체 스냅샷 JSON·해시가 이름 변경 전과 같은지 확인했다.
3. 에뮬레이터 Wi-Fi·모바일 데이터를 끄고 앱을 강제 종료·재실행했다. 로컬 Metro는 ADB 포트 연결을 사용했다. 저장 목록·상세의 경로 표시를 다시 확인했고, DB의 모든 코스 열이 종료 전과 정확히 같았다.
4. 삭제 확인창에서 취소하면 모든 열이 유지됐다. 다시 삭제를 확정하면 목록이 비었고 실제 DB의 코스 수가 0이 됐다.

스냅샷 SHA-256과 비교 결과는 [JSON](saved-courses-report.json)에 보존했다. 화면 캡처·DB 복사본은 Git 제외 경로 `.cache/courses-qa/`에 있다. `course-detail.png`는 첫 상세, `offline-detail.png`는 네트워크를 끄고 재실행한 상세 화면이다. 저장 경로와 안내 문구를 시각적으로 확인했다. 이번 에뮬레이터에는 사용자 DB가 없었으므로 **버전 1 메모의 실제 기기 업그레이드는 시험하지 않았고 PC의 실제 SQLite 검사로 확인했다.**

ADB는 샌드박스 초기화 실패 후 허용된 기기 명령으로 실행했다. Metro의 DevTools 캐시 초기화 경고는 대체 버전으로 넘어갔으며 앱 번들·화면 실행에 영향을 주지 않았다. 기존 설정·도구 버전은 변경하지 않았다.

검증 후 Metro를 종료하고 가상 기기의 Wi-Fi·모바일 데이터를 원래 활성 상태로 복구한 값을 확인했다. ADB 연결 응답 지연은 임시 서버 포트로 복구했으며, 테스트용 포트 연결을 해제하고 가상 기기·임시 ADB 서버를 종료했다. 기본 ADB 서버를 다시 시작한 뒤 연결 기기 목록이 비어 있음을 확인했다.

## 휴대폰 후속 설치·검증 — 22:09 업데이트

사용자 “폰연결했어 설치및 테스트해” 요청으로 SM-S942N(Android 16 / API 36)에 최신 독립 실행 APK를 **2026-09-30 22:09:04 KST**에 업데이트했다. 위 에뮬레이터 기록과 달리 이번 설치본은 Metro 없이 실행한다. 앱 소스 변경 없이 현재 작업 트리로 빌드했으며 기존 자동 검사 119개의 결과는 앞선 검증이다.

- 파일: `build/install/running-art-0.1.0-20260930-courses.apk`, 95,595,419바이트, arm64·x86_64. 같은 폴더에 SHA-256 파일과 `INSTALL-courses-20260930-ko.txt`가 있다. 기존 APK와 서명이 같고 `adb install -r --no-streaming`으로 업데이트했다.
- APK SHA-256: `d98437c15854221331b07b754b4797ccfa0947e03ab7df49bb8bb7202de78b6a`. 휴대폰에서 다시 읽은 설치 APK와 일치한다. 내장 Hermes 번들과 빌드 생성물이 같고, 소스맵의 앱 소스 40개가 현재 파일과 일치한다.
