# 4-2 도로 서버 배포 준비 검증

검증일: 2026-09-30 (Asia/Seoul). **배포 준비·로컬 통합 검증 완료. 실제 R2·CDN 배포는 미실행.** 휴대폰 연결 테스트는 사용자 보류를 유지했다.

**2026-10-01 후속:** 실제 R2의 개발용 `r2.dev` 배포·공개 HTTP·첫 포인터 전환·재업로드 재사용을 검증했다. 아래 9월 30일 기록은 당시 로컬 결과이며 새 결과는 [실제 R2 검증 JSON](road-deployment-r2-dev-report.json)과 후속 절을 따른다. 운영 CDN·실제 이전 릴리스 복구·일반 앱 연결은 이번 범위에 포함하지 않았다.

## 구현과 실제 표본

`scripts/road-data/deployment.mjs`, `publish.mjs`, `r2-store.mjs`, `deploy.mjs`에 배포 묶음 검증·R2 업로드·공개 HTTP 검사·조건부 포인터 전환을 구현했다. [사용법](../development/road-deployment.md)을 따른다. AWS S3 SDK 3.1143.0은 개발 의존성으로 고정했으며 앱 소스·기존 API·계산 엔진은 변경하지 않았다.

실제 0.02도 표본의 불변 객체는 타일 23개 + 매니페스트 + 출처 안내, 총 **25개 / 1,206,038바이트**다. 현재 버전 포인터는 733바이트다. 압축 원본 바이트를 보존하며 Content-Encoding을 설정하지 않는다. 매니페스트 SHA-256은 `e6d644c8e375896ee88729e3407e99d309fcdf53ea1a9f2e75b7ded879e705b6`이다.

`roads:rehearse`는 모의 저장소 업로드 후 25개 객체 전부 재사용, HTTP 검증, 첫 포인터 전환을 수행했다. 공개 방식의 HTTP 다운로드 → 압축·해시 검사 → 타일 병합을 거친 다음 전체 입력·그래프를 분할 전 기준과 대조했다.

측정 JSON은 [보관 결과](road-deployment-report.json)에 있다. 성능 수치가 아니라 공급 바이트·연결 검증이며 실제 CDN 가용성·속도 증거로 사용하지 않는다.

## 실패·복구 검사

전체 `node --test tests/*.test.mjs` **96개 통과**(배포 관련 12개 포함), `dev.ps1 check` 타입·린트 통과. 기존 Node의 TypeScript 파일 모듈 형식 경고는 남지만 검사 실패는 없다. 앱 코드 변경이 없어 Android 재빌드·기기 설치는 수행하지 않았다.

`tests/road-deployment.test.mjs`는 다음을 자동 검사한다.

- 재현 가능한 묶음과 gzip 보존, 손상·누락·출처 변경·상대 경로 이탈 거부.
- 업로드 중단 시 현재 버전 유지, 재실행 시 같은 파일 재사용, 다른 내용 덮어쓰기 거부.
- 같은 객체의 동시 업로드에서 412 응답 후 내용 확인.
- 공개 HTTP의 404·Content-Encoding·Content-Type·Cache-Control 오류 거부.
- 공개 파일 누락·변경된 현재 SHA-256·전환 직전 경합에서 현재 포인터 보호.
- 공식 SDK의 실제 HTTP 요청을 로컬 S3 모의 endpoint로 전송해 서명 헤더·조건부 쓰기·gzip 헤더 확인, 첫 배포 → 다음 버전 → 이전 버전 복구.
- 포인터 쓰기 후 잘못된 CDN 캐시 응답은 실패로 보고하고 자동 덮어쓰기 복구를 하지 않음.
- 응답 크기 제한·리다이렉트 거부, HTTPS 설정·명시적 자격 증명 검사, `--apply` 없는 계획 출력.

모의 S3는 실제 R2의 모든 동작을 재현하지 않는다. R2의 서명 인증·버킷 권한·리전·실제 조건부 쓰기와 도메인/TLS/CDN 규칙은 실환경 검증이 남았다. 로컬 테스트는 외부 자원을 생성하거나 변경하지 않았다.

## 남은 완료 조건

### 2026-10-01 개발용 주소 지원 검증

- `publicUrlMode: "r2-dev"`를 명시한 개발용 주소만 추가 허용한다. 기본 사용자 도메인 모드에서 `r2.dev` 차단, S3 endpoint·HTTP·포트·인증 정보·경로·쿼리·fragment 거부를 검사했다. 끝점의 후행 점으로 기본 정책을 우회하는 경우도 차단했다.
- 배포 관련 자동 검사 **14개 통과**. 개발용 CLI의 업로드 계획은 인증 없이 생성되고 `developmentOnly: true`로 표시된다. 모드 없는 개발용 URL은 실제 업로드 요청 전에 거부한다.
- 타입·린트 통과. 로컬 실제 표본 리허설에서 25개 / 1,206,038바이트의 업로드·재사용·공개 HTTP 검사·포인터 전환과 서울·부산·경계 전체 입력/그래프 대조를 다시 통과했다. 로컬 결과 시각은 `2026-10-01T13:15:53.798Z`다.
- R2 업로드·개발용 실제 주소 검증·운영 CDN·앱 공급 전환은 이 로컬 검사 결과에 포함하지 않는다. 실제 클라우드 결과는 아래 후속 기록 또는 [현재 상태](../handoff/status.md)를 따른다.

### 2026-10-01 실제 R2 개발용 배포 검증

사용자 확인 후 개발용 공개 URL 활성화를 확인하고 `running-art` 버킷 Object Read & Write·1주일 사용자 토큰을 발급했다. 비밀 값은 출력하지 않았고 현재 Windows 사용자 DPAPI로 암호화했으며 임시 평문 파일은 삭제했다. 샌드박스의 DPAPI 프로필·외부 HTTPS 제한은 허용된 사용자 프로필/네트워크 실행으로 처리했다.

- 시작 시 실제 원격 `current.json` 없음(`absent`) 확인.
- 실제 S3 API 업로드 25개 / 1,206,038바이트. 객체마다 원본을 재읽어 해시·크기·Content-Type·Cache-Control·Content-Encoding 부재 확인.
- 인증 없이 실제 `r2.dev` 주소에서 25개 전체 바이트·헤더 검증 통과.
- `If-None-Match: *`로 현재 포인터 733바이트를 처음 생성하고 S3 원본·공개 HTTP까지 검증. 현재 해시 `bee3509d90ace81ff74f9604554b8c77ca9896a61cfc37f05fb232f66dea320d`.
- 같은 배포 재실행: 새 업로드 0개·기존 25개 재사용·현재 포인터 변경 없음.
- 브라우저에서 Public Access Enabled와 `roads/` 폴더 확인. UI 용량 통계는 갱신이 늦어 0 B를 표시했으므로 정확한 바이트 수는 실제 S3/HTTP 결과를 기준으로 기록했다.

도메인 구매·운영 CDN 검증은 이후이며 개발용 결과와 구분한다. 첫 배포이므로 실제 이전 릴리스 복구는 검증하지 않았고 로컬 S3/HTTP의 복구 검사만 통과했다. 4-1 휴대폰 검증과 형식 결정은 완료됐으며 다음은 4-3 일반 앱 전환·휴대폰 영구 캐시 검증이다. CI/CD·회원 서버·전국 자료는 이번 범위 밖이다.
