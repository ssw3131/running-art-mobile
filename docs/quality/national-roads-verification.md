## SQLite·실패·용량

앱과 같은 채널/영구 캐시를 실제 SQLite에 연결했다. 첫 날짜 23개 사례를 저장한 후 새 프로세스에서 네트워크 0회로 전체 입력을 복원했다. [오프라인 결과](national-roads-offline-report.json).

실제 도로 내용이 바뀐 10km 사례로 이전 자료 수신 → 새 타일 손상 시 이전 전체 자료 유지 → 오프라인 유지 → 새 날짜 갱신 → 이전 날짜 복구 → 새 날짜 복귀 → 완전 오프라인을 통과했다. 이 검사는 로컬 파일 전송이며 실제 R2 포인터 전환과 구분한다. [날짜 갱신 리허설](national-roads-update-rehearsal-report.json).

3MiB 제한에서 LRU 정리·요청 중인 영역 보호·큰 요청의 용량 실패 후 이전 DB 보존을 확인했다. 기본 한도 64MiB는 gzip·매니페스트 논리 합계이며 SQLite 페이지·WAL·객체 메모리의 물리 상한이 아니다. 논리 자료 21,352,262바이트의 종료 후 DB는 21,741,568바이트, 3MiB 리허설의 종료 후 DB는 4,349,952바이트였다. [용량 결과](national-roads-capacity-report.json).

두 날짜의 타일·매니페스트·카탈로그 보존 합집합은 27,220개·388,647,266바이트다. 작은 출처 안내·현재 포인터·표본 경로는 제외한다. 현재/직전 정상 릴리스를 유지하고 다른 과거 릴리스도 공개 종료 후 최소 14일 보존하는 기준과 읽기 전용 참조 집합 도구를 준비했다. 실제 삭제나 예약 실행은 하지 않았다. [용량 계획](national-roads-storage-plan.json)·[운영 절차](../development/national-roads.md).

가공 공간은 서버 보관 용량보다 크다. 15:56 KST의 두 출력 폴더는 각각 약 1.77GB·1.76GB였으며 그 안의 공간 인덱스가 각각 약 1.37GB다. 원본 PBF·각 약 1.21GB의 추출 JSONL·Node/Android 도구·이전 임시 출력은 별도로 필요하다. 이 값은 현재 PC의 파일 길이 합계이며 디스크 할당량 상한이 아니다.
