## 최초 실패와 수정 이력

- 첫 UI 실행은 C 드라이브 공간 부족으로 임시 파일 생성 실패. D 드라이브 임시 폴더를 사용했다. mock factory 외부 변수·자산 alias·부분 문구 matcher를 수정했다. 이후 UI 22개를 통과했다.
- `.cache/s2a/fast`/`build-final.log` 병렬 전체 검사와 빌드는 PC 메모리 부족으로 종료됐다. 검사 기준을 완화하지 않고 작업 병렬도를 낮춰 순차 재검증했다.
- 최초 Android 전체 실행은 자원 부족 중 screencap 45초 제한과 뒤의 정리 응답 실패가 발생했다. 해당 보고서/로그를 보존하고 전용 AVD만 콜드 부팅했다. 기존 합성 코스/메모 및 전체 테이블 해시가 최초 기준과 같음을 `recovery/report.json`에서 확인했다. 이 실행을 통과로 세지 않는다.
- 생성 집중 검사의 큰 글씨 단계는 본문 밖 고정 취소 버튼을 스크롤 내부에서 찾는 QA 탐색 때문에 실패했다. PNG/XML에서 전체 버튼 표시를 확인하고 고정 버튼 직접 탭으로 수정했다. 제품 기준/터치 영역은 완화하지 않았다.
- 최신 APK 실도로 첫 시도도 고정 좌표 스와이프가 본문 아래 고정 버튼에서 시작해 개발 정보에 도달하지 못했다. 빈 시험 DB 원복은 통과했다. 첫 PNG/XML·실패 보고서를 `live-first`에 보존하고 실제 ScrollView 경계에서 스와이프하도록 로컬 검사를 수정했다. 두 번째 시도에서 실제 서버 계산·저장·러닝 준비와 정리를 통과했다.
- 시각 검토에서 토끼/집 미리보기의 범위·방향, 이용권 아이콘을 잘못 연결한 생성 버튼을 발견했다. 실제 좌표 경계와 입력/확인 각각의 원본 Figma 자산으로 수정했다. 앞선 화면을 최종 시각 통과로 재분류하지 않았다.
- 초기 PR 실행 `38378460167`은 fast/API 통과 후 확정 조건 전달 수정 커밋으로 취소됐다. 최종 PR 실행은 `38379886438`이다. 전달 검사 첫 기대값 null/undefined 차이는 matcher를 수정했고 최신 전체 UI 22개가 통과했다. 실패/취소 로그는 `.cache/s2a`에 보존하며 정제 결과에 해시를 남겼다.
