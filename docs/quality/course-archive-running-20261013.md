## 실패와 수정 이력

- 첫 UI 검사에서 러닝 설정 footer의 빈 문자열 View 자식이 실제 네이티브 렌더 오류를 발생시켰다. 제거 후 관련 UI 2개를 포함해 26개 통과했다.
- 강아지 홈 선택이 활성화되어 이전 ‘비활성’ 기대값을 새 입력 전달 검증으로 교체했다.
- OpenAPI 생성 시 --write 누락으로 drift 검사가 실패했다. 생성물을 명시적으로 갱신한 뒤 전체 qa:fast에서 통과했다.
- 첫 UI cold import의 제한 시간 실패는 네이티브 선택기 경계를 mock한 기존 생성 화면 테스트에서 재검사하여 통과했다. 실패 로그를 삭제하지 않았다.

- 첫 Android 전체 검사에서 조건 수정 후 스크롤 위치가 아래쪽에 남아 distance-3 탐색이 실패했다. 원본/시험 정리는 통과했다. 새 폼이 네이티브에 렌더된 다음 프레임에 스크롤을 초기화하도록 수정하고 UI 28개를 재검사했다. QA 탐색도 목록 끝에서 방향을 전환하도록 보완했다.

- Android 진단 2·3에서 지도 모드 일시정지는 통과했지만 터치 잠금을 길게 눌러 해제한 다음 일시정지가 동작하지 않았다. 손을 떼기 전에 Modal을 닫던 동작을 pressOut으로 옮겼다. 진단 4에서 잠금 해제 후 일시정지·프로세스 강제 종료/복원·옵션 보존과 종료 기록 화면까지 통과했다. 단순 대기 증가로 실패를 숨기지 않았고, 짧은 터치/긴 터치/해제 후 제어 UI 회귀를 추가했다.
- 집중 모드의 큰 방향 원 아래 안내가 기본 높이에서 잘려, 작은 화면의 숫자/방향 크기와 간격을 줄였다. 진단 4 실제 화면에서 안내·진행률·고정 제어가 함께 보인다. 확대 글씨는 스크롤을 유지한다.
- 실제 Android 사진 선택기→자르기→native PNG 변환→윤곽 미리보기→명시적 적용→생성 확인을 합성 단색 도형으로 통과했다. 원본은 서버에 전송하지 않는다. 시험 사진은 MediaStore와 파일에서 정리한다.
