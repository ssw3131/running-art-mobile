### Android 실제 회원 환경 소스 준비 완료 / 미실행

기존 모의 세션 주입을 실제 격리 Supabase Auth/정책/RPC 기반 소스로 교체했다. 가입 대기 계정은 앱의 두 체크와 완료 버튼으로만 동의하며, 홈/서비스 계정은 별도의 명시적 동의 RPC로 준비해 실제 영수증을 확인한다. `--signup-only`는 가입 검사 후 종료하고 전체/호환 검사는 별도 service 계정으로 전환한다. 초기화 뒤 위치/알림 권한 재부여와 실제 owner UUID 연결도 포함했다.

`tests/android-membership-environment.test.mjs`에 loopback 주소/키 경계 검사 소스를 추가했다. localhost TLS·ADB reverse·정상 issuer·공개키 adapter·계정/정책/세션/프록시/native trust 정리와 CI 호출부를 작성했다. `DisposableAuth` 운영 도구는 재사용하지 않는다. [준비/실행/정리 절차](../development/android-membership-qa-20261024.md)를 따른다. **서버 호출·계정 생성·정책 게시·도우미 빌드·테스트·CI는 모두 미실행**이며 Q01~Q04 상태는 그대로다.
