## 실제 휴대폰 후속 검증 — 2026-09-30 22:35~22:40 KST

### 형식 결정·취소·복원

- **v1 표본 공급은 0.02도 격자 + gzip level 6 JSON + 전체 way·OSM ID 보존으로 결정한다.** 파일 스키마·매니페스트·어댑터는 기존 구현을 유지한다. 0.01도보다 요청 파일이 20~30개에서 6~9개로 줄고, 0.04도의 큰 전송량·처리 비용을 피한다. 경계 표본은 0.01도가 더 빨랐으므로 모든 지역에서 가장 빠른 형식이라고 주장하지 않는다.
- 0.02도 재실행 중 취소 버튼을 눌러 “표본 검증을 취소했어요.”를 확인했고 추가 대기 후 완료 문구·완료 로그가 나타나지 않았다. 입력 전송부터 UI dump 관측까지 2.460초였으며 ADB·UI 수집 시간을 포함하므로 터치 응답 시간으로 해석하지 않는다.
