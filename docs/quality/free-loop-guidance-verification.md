## 구현 계약

중심 반경 2km 전체에서 양방향 보행 순환 경로를 추천한다. 기존 v0.2 기준 회귀 모드는 유지하고 일반 앱만 자유 순환 모드로 전환한다. OSM 연결·보행 제한·도형 점수·크기 85~115%·거리 75~125%·중복 구간 30%·최대 5개 후보 기준을 유지한다. 새 후보에는 중심 접근·왕복 경로를 붙이지 않는다.

실제 GPS는 접근→합류 위치 확인→이동 방향 인식→한 방향 한 바퀴→완주 확인을 따른다. 접근도 실제 러닝 거리/시간에 포함하되 완주 진행에서는 제외한다. 이탈·GPS 공백·중단 후 다른 지점 재개는 마지막 정상 진행 지점으로 복귀해야 이어진다. 계속 달리기는 완주를 유지하고 반복 자동 정지를 하지 않는다.

새 코스 JSON v2에 원본 OSM 구간 참조를 보존하고 안내 JSON v2에 실행 상태를 저장한다. 사용자 SQLite v7·서버 테이블·RLS·비공개 Storage 계약은 유지하며 이전 코스/러닝/진행 중 v1을 읽는다. 새 JSON은 이전 APK에서 읽지 못하므로 함께 사용하는 기기도 업데이트가 필요하다.

## 에뮬레이터 검증

- 기존 API 36의 앱 DB v4는 코스/러닝/GPS/메모 모두 0건, 동기화 켜진 계정 0건임을 확인하고 DB·테이블 내용 해시를 보존했다. 공개 OSM으로 생성한 약 907.56m 순환 코스만 시험에 사용한다.
- 최초 7m/s 주입에서는 1건의 순간 속도 이상치가 기록 필터에 거절됐고 안내가 마지막 정상 지점 복귀를 요구했다. 건너뛴 구간을 완주로 인정하지 않았으며 해당 시험은 완주 성공으로 세지 않는다. 이후 주입 간 이동을 4m로 고정한다.
- 코스 27% 지점에서 정방향 출발, 화면 잠금·오프라인 상태로 약 4분간 GPS를 수신해 완주 자동 일시정지·확인·저장을 통과했다. 61% 지점에서 역방향 출발도 약 4분간 주행 후 방향 -1·한 바퀴 완주·저장을 통과했다. 근거: `.cache/free-loop-qa/replay-forward.json`, `replay-reverse.json`, `arrived-forward.png`, `arrived-reverse.png`.
- 실제 R2 합류 경로를 UI로 준비한 뒤 러닝을 시작했다. 111.1708m 접근 중 실제 GPS 거리는 증가하고 한 바퀴 진행률은 0으로 유지됐다. 합류·방향 인식 뒤 앱 강제 종료→코스 밖 위치에서 재실행 시 중단 상태였으며 명시적 재개 후 마지막 진행 지점까지 보행 복귀 안내가 나왔다. 복귀 전후 코스 진행은 **44.169448m로 동일**, 접근/진행/복귀의 실제 기록은 **308.884833m**, 복귀 경로는 11좌표다. 시험 기록 종료·저장까지 통과했다. 근거: `.cache/free-loop-qa/approach-recovery.json`, `approach-ready.png`, `return-guidance.png`, 단계별 DB 사본.
- 서울 강남 하트 5km의 도로 조회·계산 취소·재계산→후보 5개→2순위 선택→저장→중복 저장 안내/개수 유지→러닝 준비 화면을 통과했다. 선택 코스는 **4.902383km·83점·217좌표·216개 양방향 도로 참조**, JSON v2다. 첫 화면 검증에서 코스 일부가 지도 밖에 있어 탐색 중심을 유지하며 후보 전체가 보이도록 배율을 수정했다. 최종 APK의 지도 표시·중심 좌표 유지와 준비 화면을 확인했다. 근거: `.cache/free-loop-qa/generation.json`, `generation-candidate.png`, `generation-preparation.png`.
- 최종 에뮬레이터 측정은 전체 50.28초(도로 캐시 3.66초·계산 46.61초), 이전 다운로드 실행은 48.75초(5.92초·42.83초)였다. PC Node 수치나 휴대폰 성능과 직접 비교하지 않는다. 초기 QA의 취소 상태·러닝 링크 확인은 화면 스크롤 때문에 실패했으며, 스크롤 간격을 보정해 최종 흐름을 통과했다.
- 최종 설치 APK 해시가 준비 파일과 같았다. 원래 DB v4·전체 테이블 내용 해시를 복구해 시험 코스/러닝을 제거했다. 앱 서비스 `(nothing)`·현재 wake lock 0개를 확인하고 이번 임시 UI 덤프를 제거했다. 기존 UI 도우미 파일은 유지했으며 직접 띄운 headless 에뮬레이터를 종료했다. 근거: `.cache/free-loop-qa/original.json`, `restored.json`.
