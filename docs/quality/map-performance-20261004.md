# 저장 코스 안내 지도 성능 — 2026-10-04 휴대폰 진단

사용자 보고: 일반 지도와 홈의 러닝 안내 시험은 부드럽지만 저장 코스에서 연 안내 지도는 **시작 전·일시정지 상태에서도** 확대/이동이 느리다. 사용자의 휴대폰 연결·확인 요청으로 2026-10-04 14:02~14:18 KST에 기기 비교를 수행했다. 앱 구현·APK 교체는 하지 않았다.

## 결론과 한계

**2026-10-04 14:35 KST 사용자 추가 관찰·결정:** 일정 수준 이상 확대해 지도가 상세해질 때, 실제 러닝 화면 수준의 확대율에서 느려진다고 보고했다. 이는 사용자 체감 관찰이며 정확한 확대율 임계값을 추가 측정한 결과는 아니다. MapTiler 자체 문제 가능성도 제기됐으나 공급 서비스·지도 스타일·MapLibre 렌더러·기기 중 원인은 미확정이다. 사용자는 기록만 남기고 개선은 나중에 하기로 결정했다. 추가 진단·수정·휴대폰 시험은 보류하고 [개선 계획](../planning/map-performance-improvement.md)을 후속용으로 보존한다.

동일 저장 코스의 **배경 지도를 표시하는 조건에서 지연이 재현**됐다. 앱 프로세스를 다시 시작하고 상세 화면을 거치지 않는 `guidance?courseId=…` 직접 진입에서도 동일했다. 같은 경로를 그대로 두고 배경을 끄면 지도 프레임 간격이 약 8.34ms로 안정적이며, 다시 켜면 지연이 재현됐다. 따라서 이전 상세 지도 누적이나 경로 좌표 수만을 주원인으로 단정하는 설명은 맞지 않는다. 이 지역·확대율에서의 배경 지도 렌더링을 우선 조사해야 한다.

MapTiler Streets v2 / MapLibre Android Vulkan 구성에서 관측한 결과다. 특정 건물·라벨 레이어, Vulkan 드라이버, 타일 로딩 중 어느 세부 요소가 병목인지는 분리하지 못했다. 일반 지도·홈 시험 지도와 저장 코스 지도는 표시 지역/확대율이 다르므로 화면 종류만으로 렌더러 성능을 비교한 결과가 아니다. 배경 OFF/ON은 지도 객체를 다시 만들며 follow 해제 후 초기 zoom 16으로 돌아가므로 최초 zoom 16.5와 완전히 같은 카메라 조건은 아니다. 배경을 다시 켠 zoom 16에서도 지연이 유지되어 배경 표시 조건과의 연관성을 확인했다.

## 환경과 방법

- SM-S942N / Android 16, USB ADB. 설치 시각 2026-10-04 13:18:40의 기존 통합 APK. 새로운 APK 설치 없음.
- 최초 실행 서비스 없음. 모의 재생과 실제 GPS 러닝은 시작하지 않았다.
- 저장된 하트 5.60km를 사용하고 코스/러닝 편집·생성·삭제·공유·로그아웃은 하지 않았다.
- Android SurfaceFlinger의 지도 SurfaceView 프레임 타임스탬프를 수집했다. 앱 전체 UI의 FPS로 지도 성능을 대체하지 않았다.
- 기본 드래그는 x=350↔750, y=1450, 1초씩 6회. 일반 지도는 실제 지도 영역에 맞춰 y=1000을 사용했다.
- 프레임 통계는 각 드래그 뒤 조회한 원본에서 타임스탬프를 중복 제거했다. 프레임 간격 중앙값과 P90을 보고한다. 긴 구간에는 ADB 호출·관성 이동·정지 간격이 포함될 수 있으므로 전체 실행 시간으로 정확한 평균 FPS를 확정하지 않는다.
- 온라인 지도의 일부 `--latency` 호출은 갱신된 행을 반환하지 않았다. **0행은 0fps가 아니며**, 프레임 API의 공백을 성능 수치로 사용하지 않는다. 별도 누적 TimeStats와 늦게 반환된 프레임 표본을 함께 확인했다.

## 관측 결과

| 조건 | 지도 프레임 간격/관측 | 근거 파일 (`.cache/map-perf/`) |
| --- | --- | --- |
| 홈 시험 지도, 최초 | 중앙값 8.343ms / P90 8.385ms | `demo-1.json` |

| 앱 재시작 → 저장 안내 직접 진입, 배경 ON | 지연 유지. 프레임 조회 공백으로 정확한 FPS 산출 제외 | `saved-direct-1.json`, `saved-direct-2.json` |

약 8.34ms는 프레임 간격이 약 120Hz라는 뜻이다. 입력부터 표시까지의 지연시간 수치는 아니다. 온라인의 긴 간격 표본은 조회 구간 밖의 늦은 보고/정지 구간을 포함할 수 있어 이를 그대로 1fps 평균으로 환산하지 않는다.

`ordinary-1.json`은 드래그 y가 지도 밖이므로 비교에서 제외한다. 두 손가락 축소용 임시 UiAutomator 도우미는 기기의 `android.test.RepetitiveTest` 누락으로 실행 실패했다. `saved-zoomed-out*` 파일은 실제 축소 성공 근거가 아니며 확대율 비교에서 제외한다. 자동화 출력의 `OK (1 test)`보다 예외/상태 코드 -1을 우선했다.

지도 스타일 세부 조회는 `.env.local`의 API 키를 MapTiler 요청에 사용하는 작업이어서 자동 승인 검토에서 거절됐다. 요청은 실행하지 않았으며 우회하지 않았다. 세부 레이어 원인과 스타일 변경 효과는 미검증이다.

## 보존과 후속

시험 후 기존 코스 1개·러닝 2건을 UI로 확인했다. 내부 DB/GPS/메모 내용 해시 재검증은 이번 범위에 포함하지 않는다. 배경 OFF는 화면의 임시 상태이며 다시 ON으로 복구했다. 실행 중인 앱 서비스 없음, 진단용 휴대폰 XML·제스처 JAR은 삭제했다. 앱 코드·설정·APK·계정 설정을 변경하지 않았다.

후속은 동일 지역·같은 확대율에서 배경 스타일/건물·라벨 레이어 및 렌더링 백엔드의 영향을 분리하는 것이다. 이번 결과만으로 경로를 단순화하거나 지도 누적 해제를 성능 해결책으로 확정하지 않는다. 배경 끄기는 경로만 보는 임시 회피 방법이며 성능 문제를 수정한 것은 아니다.
