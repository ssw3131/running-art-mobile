## 확인한 흐름

홈·코스 생성·실시간 러닝·기록 보관함·마이페이지의 5탭, 선택 상태와 공통 상하단을 확인했다. 서비스 메뉴 왕복, 3km·별 도형을 선택한 뒤 탭/메뉴 이동 후 유지, 기존 코스 상세·뒤로가기, GPX 공유 선택창 열기/취소, 기존 러닝 목록을 확인했다. 탭에 들어가기만 해서는 GPS 기록이 시작되지 않았다.

폰의 고정 지도 아래 스크롤 영역에서 도형 버튼이 위로 가려진 경우를 자동화 도구가 처음에는 처리하지 못했다. 실제 접근성 경계로 스크롤 방향을 정하고 거리·도형을 각각 노출한 뒤 검사해 통과했다. 이 실패는 최초 성공으로 덮어쓰지 않고 로컬 실행 증거에 보존했다.

화면 9개와 원본 비교 증거는 개인정보·실제 지도 위치가 포함되어 저장소의 무시된 `.cache/service-s0-phone-20261013/`에만 보관했다. `index.html`에서 확인할 수 있다. 공개 GitHub 아티팩트에는 올리지 않았다.
