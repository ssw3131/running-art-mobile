## 실패·수정 이력

1. 시스템 제공 Node의 npm 의존 파일 손상을 확인했다. 원본 도구를 수정하지 않고 가입 작업에서 검증한 별도 Node 24.21.0/npm 11.19.0을 사용했다.
2. 최초 Jest 실행은 임시 캐시 rename EPERM으로 실행되지 않았다. 작업 폴더 내 `.cache/jest`로 지정한 뒤 검사했다.
3. 최초 로직 검사는 오프라인 회원 영수증 추가에 따른 기존 ‘저장 항목 0개’ 기대가 실패했다. pending 없음/영수증 존재로 기대를 수정하고 전체 486개를 통과했다.
4. 기존 UI 테스트의 예전 경로와 보관함 repository mock을 새 화면 계약으로 갱신했다. 미완주/복구/사본 저장은 별도 의미 있는 테스트를 추가했다.
5. 네이티브 PostgreSQL 최초 실행은 빈 `PGSERVICE` 환경 변수로 접속에 실패했다. 해당 변수만 제거해 고정 loopback 주소로 검사했다. 실패 보고서도 보존했다.
6. sandbox 내부 로컬 HTTP listen EACCES는 코드 실패와 구분했다. 승인된 로컬 검사 실행에서 실제 HTTP 검사를 통과했다.
7. 전체 폴더에 직접 실행한 ESLint는 기존 Node 스크립트의 전역 선언 범위 오류를 보고했다. 프로젝트의 앱/서버 검사 범위로 실행한 린트 결과를 사용한다. 초기 로그를 지우지 않는다.
8. 최초 후속 APK 포장 중 ADB가 Gradle 출력 APK를 열어 둬 파일 잠금으로 실패했다(`build-final.log`). 이후 닫힌 별도 사본을 설치해 성공했다.
9. 화면에서 배지 전체 모음이 표시되는 문제를 발견했다. Figma의 개별 하트 마스킹 노드를 다시 내보내 교체했다. 흰 카드에서 보이지 않던 흰 화살표는 테마의 윤곽 색으로 수정했다.
10. 오프라인 지도 로딩이 끝나지 않는 경우를 보완했다. 저장 코스/러닝은 연결 실패 또는 제한 시간 뒤 빈 배경 위에 원래 경로를 표시하고 상태를 설명한다. 생성 화면에서 임의 지도를 사용해 계산하지 않는다.
11. 오프라인 신규 저장 오류가 화면 위쪽에만 표시되던 문제를 하단 동작 근처의 오류 안내와 15초 요청 제한으로 보완했다. 미확정 작업 ID는 유지해 응답 유실 복구를 보존한다.
12. 긴 목록 자동 탐색의 큰 스와이프가 목표 행을 지나쳐 검사에 실패했다. 느린 500px 이동과 화면 경계 판별로 도우미를 수정했다. 첫 실패 로그는 보존한다. API29 후속의 ADB 데몬 연결 실패도 앱 판정과 분리해 기록했다.
13. 다크 모드 보관함 탭 뒤의 밝은 기본 배경을 테마 배경으로 수정했다.
14. 초기 회원 영수증 복원 도중 보호된 상세 딥링크가 가입/홈 경로로 교체되는 문제를 수정했다. 복원 전에는 navigator를 열지 않고 URL을 보존한다. 계정 전환 때의 이력 제거와 미가입 차단은 유지하며 회귀 검사를 추가했다.
15. 이전 생성 화면의 기기 계산/오프라인 fallback 안내 및 개발 표본 선택을 서비스 화면에서 제거했다. 새 생성은 온라인 서버만 사용하며 엔진 자체 로컬 검사와 별도 개발 모의 주행은 유지한다.
16. API29 첫 20km 입력 자동 검사는 OS 위치 권한 팝업에 가려 목표를 찾지 못했다. 실제 위치/GPS를 사용하지 않는 검사이므로 팝업을 명시적으로 거절한 뒤 같은 APK에서 통과했다(`android29-generation-permission.log`, `android29/generation-checks.json`). 최초 로그 `android29-generation-contract.log`를 보존한다.

## 운영 후속

새 usage migration/Edge Function/인증 필수 계산 서버는 아직 운영에 반영하지 않았다. 따라서 준비 APK의 신규 생성/저장 성공에는 운영 전환이 필요하며 앱은 연결 실패 시 로컬 계산으로 우회하지 않는다. 정책 및 개인정보 변경 초안은 미게시다. [운영 전환 절차](../development/archive-usage-20261024.md)·[문안 초안](../product/usage-privacy-draft-20261024.md).
