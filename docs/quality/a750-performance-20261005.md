# SM-A750N 설치와 실내 계산 성능 — 2026-10-05

상태: **설치·실내 계산 성능·입력/취소/재계산 검증 완료.** 새 폰에서는 정상 결과를 만들지만 강남 5km 캐시 계산도 전체 약 87초여서 계산 대기 시간 개선이 필요하다. 야외 GPS·장시간 잠금/배터리는 이번 시험 범위가 아니다.

## 방법

각 정규 실행은 앱 프로세스를 종료하고 다시 열어 하트·목표 거리를 선택한다. 앱 내부 `ROUTE_LAB_METRICS`의 도로 조회·코스 계산·전체 시간과 노드/도로 수·후보 점수·탐색량을 수집한다. 실제 도로 최초 다운로드 실행과 영구 캐시의 새 프로세스 반복을 구분한다. `offline`은 앱 도로 공급 모드이며 기기 통신 자체를 끈 시험이 아니다.

합성 격자 5km와 강남 자유 순환 5km는 각각 새 프로세스에서 3회 반복했다. 부산 시청 3km는 같은 APK로 측정한 [기존 폰의 실내 증거](indoor-phone-validation-20261005.md)와 제한적으로 비교한다. 부산 최초/캐시 시간에 편차가 보여 캐시 실행 1회를 더 추가했다. [10월 2일 자료](phone-performance-20261002.md)의 합성 격자는 입력·탐색량·전체 후보 점수가 같은지 검사하며, 당시 실제 도로는 중심 출발 규칙이어서 새 자유 순환 시간과 직접 배율 비교하지 않는다.

메모리는 실행 전/후와 긴 계산 중 약 30초 간격의 `dumpsys meminfo` PSS 표본이다. 연속 최대 메모리나 누수를 확정하지 않는다. USB 충전·배터리 상태·백그라운드 앱/CPU 주파수를 통제하지 않았으므로 장시간 배터리 소모·통계적 기기 성능비·야외 GPS 정확도로 확대하지 않는다.

## 입력·취소·최종 정리

설치본 SHA-256 일치, 비로그인, 저장 코스 0건·러닝 0건, 앱 실행 서비스 없음, crash 버퍼에 앱 패키지 없음까지 확인했다. 임시 UI JAR·XML을 제거하고 첫 화면을 열어 두었다. 공개 도로 캐시는 재사용할 수 있도록 유지하며 **USB 분리 가능**하다. 기존 SM-S942N의 계정/기록과 서버 자료는 이번 작업에서 조작하지 않았다.

정규/보조 시간 측정 10회와 별도 입력/취소/재계산 증거의 대조 검사를 통과했다. 최종 기기 상태는 배터리 47%·34.5℃·USB 충전이다. 요약 원자료는 [JSON](a750-performance-20261005.json), 로컬 검증 명령은 `.cache/a750-performance/report.py`이며 기기별 식별값·인증 값·개인 위치는 공유 보고서에 넣지 않았다. 제품 코드가 바뀌지 않아 기존 앱 단위 검사·빌드는 재실행하지 않았다.
