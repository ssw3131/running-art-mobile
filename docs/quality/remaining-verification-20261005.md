## 휴대폰·에뮬레이터 동기화

실제 Supabase와 제품 repository/engine으로 합성 코스 3개·연결 러닝 1건(좌표 1개)을 준비했다. 동일 계정의 휴대폰과 에뮬레이터에서 복원·대기 0건을 확인했다.

1. 에뮬레이터 오프라인 코스 수정 → 대기 1건 유지.
2. 휴대폰에서 같은 코스 수정/동기화 → 에뮬레이터 온라인 복귀 → 수정 충돌 1건 표시.
3. 에뮬레이터에서 서버 내용 선택 → 휴대폰 수정 이름으로 복원.
4. 다른 코스를 에뮬레이터에서 오프라인 수정, 휴대폰에서 삭제/동기화 → 서버 삭제 대 기기 수정 충돌 표시.
5. 기기 수정본 유지 선택 → 서버에 다시 반영 → 휴대폰 복원, 두 인스턴스 대기 0건.
