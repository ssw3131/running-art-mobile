## 실패·진단 이력

1. 제한 환경의 GitHub DNS 실패 후 같은 저장소의 네트워크 가능한 실행에서 최신 main을 확인했다.
2. 새 패키지 회귀 검사의 최초 로컬 HTTP 연결이 제한 환경에서 EACCES로 차단됐다. 같은 소스의 정상 네트워크 환경 실행과 정규 fast 검사는 통과했다.
3. 실제 도로 대조 첫 실행은 2건 성공 뒤 HTTP keep-alive 연결의 ECONNRESET으로 종료됐다. 같은 프로세스에서 기준 엔진을 동기 실행하는 검증 도구가 연결 종료 처리를 지연할 수 있어 요청마다 Connection: close로 바꾸고 같은 패키지의 새 실행15건을 통과했다. 제품 서버 재시도 로직은 변경하지 않았다.
4. SQL 본문 해시의 최초 전부 불일치는 E문자열의 공백 정규식 이스케이프 오류였다. POSIX 공백 클래스로 바꾼 조회에서 18개 모두 일치했다. 운영 함수는 수정하지 않았다.
5. 브라우저의 오래된 탭/CSV 다운로드 대기 실패 후 새 조회 탭에서 이어갔다. 다운로드 성공으로 기록하지 않았다.
