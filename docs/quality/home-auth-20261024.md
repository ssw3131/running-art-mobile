## 화면 비교 기준 검토

위 실행의 필수 게이트는 **화면 비교에서 실패**했다. 기존 저장 코스 fixture도 재방문으로 분류하는 새 홈은 614,156픽셀, 게스트 진입이 막혀 로그인 fixture로 바꾼 마이페이지는 223,137픽셀이 달랐다. 러닝·보관함은 각각 0이었다. 이전/현재/차이 PNG를 직접 보고 홈의 실제 저장 경로·빈 러닝 통계/목록, 로그인한 계정 화면·기존 프로필/약관 링크를 검토했다. 홈 처음 이용·두 테마·실제 지도는 별도 원본 갤러리 검수도 통과했다.

검토한 홈/마이페이지 PNG 두 장과 출처만 갱신했다. 기존 마스크·임계값·환경·assertion은 바꾸지 않았으며 이전 차이 보고서를 `baseline.json`의 `homeAuthReview`에 보존했다. 같은 네 화면을 새 기준으로 대조한 결과는 모두 0픽셀이다. 이는 검토한 기준 재대조이며 **새 커밋의 원격 필수 CI 통과를 대신하지 않는다.** 최종 PR 게이트·병합 후 main 검사는 이어서 수행한다.

API 29 다크 원본을 추가 검수하면서 작은 카드의 SVG 아래쪽 끝을 출처 행이 일부 덮는 것을 발견했다. 경로 영역 아래에 글꼴 배율에 맞춘 출처 높이를 별도로 확보해 SVG와 네이티브 지도 모두 출처와 겹치지 않도록 보완했다. `afd053d`의 진행 중 CI는 이 후속 수정으로 대체하며, 실제 지도/오프라인 화면과 최종 기준을 다시 검토한다.

## Android 검증 방식과 한계

기존 게스트 기반 스크립트는 새 접근 정책에 맞춘다. 앱에는 테스트 인증 우회나 fixture API를 넣지 않는다. 제품과 동일 서명인 별도 instrumentation 도우미는 전용 emulator 이름과 Android emulator 지문을 검사하고, `https://runpen-ci.invalid`의 단기 합성 세션만 SecureStore에 저장한다. 실제 계정/유효한 서버 토큰이 아니며 OAuth 제공자·운영 서버 로그인을 검증했다고 주장하지 않는다. 실제 OAuth 취소/실패/중복 콜백 등은 기존 인증 컨트롤러 검사와 앱 콜백 검사로 구분한다. 세션 JSON·도우미는 정리하며 APK 포함 금지 검사에 도우미 식별자를 추가했다.

휴대폰 접근·설치, 운영 배포는 하지 않는다. 운영 약관/문의 정상 조회·실제 동의와 기존 야외/장시간 후속은 이 작업의 완료로 덮지 않는다.

실제 지도 타일 검증용 빌드의 기존 MapTiler 키 사용은 처음 자동 승인 검토에서 차단됐다. 사용자에게 구체적인 용도를 설명했고 사용자가 “허용: 실제 지도까지 검증”으로 승인했다. 승인 후 키를 출력·커밋하지 않고 로컬 격리 에뮬레이터 APK에만 적용했다. CI는 계속 실제 키 없이 SVG 대체를 검증하며, 로컬 `--map-previews`는 실제 지도 위 분홍 경로 픽셀을 요구한다. 두 검증을 서로 대체하지 않는다.

기존 미종료 게스트 러닝은 삭제·자동 귀속하지 않는다. 게스트의 이 기록 때문에 로그인 자체가 막히던 계정 변경 사전 검사는 해제했지만, DB의 기기당 미종료 러닝 1개 제약은 유지한다. 따라서 해당 자료가 남아 있으면 새 러닝 시작은 기존 제약에 막힌다. 별도 사용자 선택을 통한 게스트 미종료 기록 정리/이관은 이 작업에서 자동 수행하지 않는다.
