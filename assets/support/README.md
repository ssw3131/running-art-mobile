# S6 Figma 원본

2026-10-14 서비스 메뉴·소개·사용법·문의·공지·탈퇴의 design-context 원본을 내려받았다. 출처 노드·원본 해시는 [manifest.json](manifest.json)에 보존한다.

메뉴 아이콘은 원본 24×24, 탈퇴 경고는 64×64다. `intro.png`, `scenes.png`, `guide-scenes.png`는 Figma 원본 일러스트 이미지다. `SupportArt`의 명시적 crop으로 필요한 그림만 표시하고 원본에 포함된 샘플 문구/인터페이스는 제외한다. 서비스 문구·FAQ·입력·공지·정책은 별도 네이티브 컴포넌트로 렌더링한다. 임시 다운로드 주소나 화면 캡처를 런타임 UI로 사용하지 않는다.
