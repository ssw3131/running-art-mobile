# S5 Figma 원본

2026-10-14 Figma UI RUN-4·MY-1·공유 카드의 design-context 원본을 내려받았다. 출처 노드·원본 해시는 [manifest.json](manifest.json)에 보존한다. 임시 다운로드 주소는 런타임에서 사용하지 않는다.

트로피는 26×26, sparkles 24×24, sparkle 20×20, 거리/시간/페이스 아이콘은 20×20 원본 SVG 크기로 표시한다. confetti는 완주 배경 장식이며 브랜드 이미지 두 개는 원본 이미지 슬롯 비율로 표시한다. 실제 카드의 경로·통계·닉네임·날짜는 기록에서 생성하는 네이티브 텍스트/벡터다. 화면 캡처를 UI로 사용하지 않는다. 칼로리는 사용자 결정으로 제외했다.
