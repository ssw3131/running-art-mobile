# 기록·뱃지·계정 Figma 원본

2026-11-08 지정된 Figma 화면의 원본 아이콘과 개별 뱃지 노드를 내려받았다. 전체 화면 이미지를 UI로 사용하지 않는다. 출처·원본 크기·SHA-256은 manifest.json에 기록한다. SVG는 원본 루트 크기를 유지한다.

큰 뱃지 PNG는 170px 노드를 그림자와 함께 190px로 내보낸 원본이다. BadgeImage에서 그림자 여백을 유지하며 배치한다. 나머지 뱃지는 기존 achievements/badges 원본을 재사용한다. 미달성 상태는 원본을 변경하지 않고 화면에서 회색으로 표현한다.

기존 confetti.png와 archive/trophy.png는 현재 Figma 원본과 SHA-256이 일치해 재사용한다. 칼로리는 사용자가 설정한 체중과 실제 러닝 거리로 추정한다. 체중을 설정하지 않으면 —로 표시하며 현재 체중 기준의 참고용 추정치임을 알린다. 누적 거리 기준은 기존에 적용된 10·50·100·300km, 누적 시간은 사용자가 확정한 5·50·100·500시간이다.
